# Автоматичне перейменування сесій: фрагмент для CLAUDE.md

Додайте цей блок до глобального `~/.claude/CLAUDE.md`, щоб Claude автоматично перейменовував сесії на описові назви після 2-3 обмінів повідомленнями. Це надзвичайно допомагає, коли ви запускаєте паралельні сесії (WebStorm, розділені термінали, кілька проєктів).

## Проблема

Коли ви запускаєте кілька сесій Claude Code паралельно, у списках вибору сесій усі вони показуються як "claude" або як обрізаний перший prompt. Пошук потрібної сесії для `/resume` перетворюється на вгадування.

## Рішення

Поведінкова інструкція в CLAUDE.md — жодних скриптів, hooks чи plugins. Claude рано розуміє тему сесії та проактивно викликає `/rename`.

## Фрагмент

```markdown
# Іменування сесій (автоматичне перейменування)

## Очікувана поведінка

1. **Раннє перейменування**: щойно основна тема сесії стане зрозумілою (після 2-3 обмінів),
   виконай `/rename` з короткою описовою назвою (максимум 50 символів)
2. **Оновлення наприкінці сесії**: якщо обсяг роботи суттєво змістився порівняно з початковою назвою,
   запропонуй перейменувати сесію перед закриттям

## Формат назви

`[дія] [предмет]` — приклади:
- "fix whitepaper PDF build"
- "add auth middleware + tests"
- "refactor hook system"
- "research terminal tab rename"
- "update CC releases v2.2.0"

## Правила

- Максимум 50 символів
- Без префікса "Session:", без дати
- Спочатку дієслово дії (fix, add, refactor, update, research, debug...)
- Кілька тем: використовуй домінантну тему, а не вичерпний список
- НЕ питай підтвердження для раннього перейменування (просто зроби це)
- Пропонуй підтвердження лише для перейменування наприкінці сесії, якщо назва змінилася
```

## Використання

**Глобально** (усі проєкти): додайте до `~/.claude/CLAUDE.md`

**На рівні проєкту**: додайте до `.claude/CLAUDE.md` або `CLAUDE.md` у корені проєкту

## Як це працює

Це суто поведінкова інструкція — жодних інструментів не потрібно. Claude:
1. Визначає основну тему сесії з перших 2-3 обмінів
2. Автоматично викликає `/rename "fix auth middleware"` (без запиту на підтвердження)
3. Якщо робота суттєво змінює напрям, пропонує перейменування наприкінці сесії

Іменовані сесії з'являються у списку вибору `/resume` під своїми описовими назвами, тож потрібну сесію легко знайти й продовжити.

## Обмеження

- **Перейменування вкладок**: назви вкладок термінала (WebStorm, iTerm2) НЕ перейменовуються. JetBrains фільтрує ANSI escape-послідовності, що використовуються для зміни назви вкладки. Перейменовується сама сесія Claude, а не вкладка термінала.
- **Час**: Claude перейменовує сесію після того, як зрозуміє тему, а не одразу після першого повідомлення.

## Перевірка

```bash
# After a session with this configured:
claude --resume
# → Session list shows descriptive names like "fix auth middleware"
# instead of timestamps or truncated prompts
```

## Компроміси

| Підхід | Переваги | Недоліки |
|----------|------|------|
| Цей (поведінкова інструкція) | Жодних інструментів, працює всюди | Claude має сам визначити момент |
| Ручний `/rename` | Повний контроль | Потребує дії користувача |
| Hook (подія Stop) | Автоматично | Немає доступу до контексту розмови |

Поведінкова інструкція виграє простотою та переносністю.
