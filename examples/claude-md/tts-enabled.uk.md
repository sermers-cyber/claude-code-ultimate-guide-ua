# Проєкт з увімкненим TTS

Це шаблон файлу `CLAUDE.md` для проєктів, що використовують TTS Agent Vibes.

## Конфігурація TTS

**Провайдер**: Piper TTS
**Голос**: fr_FR-tom-medium (французький чоловічий)
**Детальність**: низька (рекомендовано)
**Ефекти**: легка реверберація
**Фонова музика**: вимкнено

## Налаштування TTS для цього проєкту

### Вимкнення звуку під час зосередженої роботи

Коли працюєте над завданнями, що потребують глибокої концентрації, вимикайте TTS:

```bash
# Mute for this session
/agent-vibes:mute

# Unmute when done
/agent-vibes:unmute
```

### Вибірковий TTS (лише помилки)

У цьому проєкті TTS озвучує лише повідомлення про помилки:

- ✅ Помилки, збої, винятки
- ❌ Звичайні відповіді, підтвердження
- ❌ Інформаційні повідомлення

**Причина**: це критична продакшн-система, де звукові сповіщення про помилки цінні, а постійне озвучування відволікає.

## Вподобання щодо голосу

| Тип завдання | Рекомендований голос | Причина |
|-----------|-------------------|--------|
| Рев'ю коду | fr_FR-tom-medium | Професійний, чіткий |
| Документація | fr_FR-siwis-medium | Теплий, навчальний тон |
| Налагодження | fr_FR-tom-medium (низька детальність) | Лише критичні сповіщення |

## Довідник команд

Швидка довідка для учасників команди:

```bash
# Check current voice
/agent-vibes:whoami

# Switch voice
/agent-vibes:switch fr_FR-tom-medium

# Mute/unmute
/agent-vibes:mute
/agent-vibes:unmute

# Adjust verbosity
/agent-vibes:verbosity low

# Disable effects (faster)
/agent-vibes:effects off
```

## Настанови для команди

### Коли вимикати звук

- Сесії парного програмування (людина пояснює, TTS відволікає)
- Відеозустрічі (щоб уникнути накладання звуку)
- Глибока зосереджена робота (пріоритет — стан потоку)
- Громадські місця (щоб не заважати іншим)

### Коли вмикати

- Самостійне рев'ю коду (слухайте, переглядаючи диффи)
- Довготривалі завдання (звукові сповіщення про завершення)
- Фоновий моніторинг (сповіщення про помилки)
- Режим навчання (практика двох мов)

## Встановлення для учасників команди

Нові учасники команди мають виконати:

1. **Посібник зі встановлення**: [Встановлення Agent Vibes](../integrations/agent-vibes/installation.uk.md)
2. **Вибір голосу**: використовуйте `fr_FR-tom-medium` для одноманітності
3. **Конфігурація**: скопіюйте налаштування з цього файлу

## Усунення несправностей

Типові проблеми:

- **Немає звуку**: перевірте `cat .claude/tts-provider.txt` → має бути `piper`
- **Не той голос**: виконайте `/agent-vibes:switch fr_FR-tom-medium`
- **Забагато озвучування**: виконайте `/agent-vibes:verbosity low`

**Повний посібник з усунення несправностей**: [Усунення несправностей Agent Vibes](../integrations/agent-vibes/troubleshooting.uk.md)

## Примітки

- TTS **необов'язковий** - для внеску в проєкт він не потрібен
- Стан вимкнення звуку **окремий для кожного проєкту** (`.claude/agentvibes-muted`)
- Голосові моделі **спільні глобально** (`~/.claude/piper-voices/`)
