Онови наявний документ передачі прогресом цієї сесії.

## Крок 1: Визначити файл handoff

Визнач, який файл оновлювати, у такому порядку пріоритету:

1. Якщо надано `$ARGUMENTS[0]`, використай його як шлях до файлу.
2. Якщо цю сесію запущено через `/handoff:resume`, знайди в історії розмови аргумент, що йому передавався.
3. Якщо жодного не знайдено, створи новий файл: `claudedocs/handoffs/handoff_YYYYMMDD_HHMMSS.md`. Повідом користувача, що наявного handoff не знайдено.

## Крок 2: Прочитати наявний файл

Прочитай визначений файл повністю. Розбери всі розділи як базову лінію для злиття.

## Крок 3: Застосувати правила злиття розділів

Перепиши файл з оновленим вмістом за такими правилами злиття:

| Розділ | Правило | Примітки |
|---------|------|-------|
| **Task** | Залишити оригінал | Оновлюй лише якщо обсяг докорінно змінився |
| **Scope** | Залишити або уточнити | Збережи виключення, критерії приймання, авторизацію та відповідальних; запиши нову ревізію контракту для суттєвих змін |
| **Files** | Злити | Додай нові файли, чіпані в цій сесії. Збережи оригінальні. Використовуй шляхи й символи; додавай рядки лише тоді, коли їх перевірено на зафіксованій ревізії |
| **Discoveries** | Додати | Додай нові знахідки під наявним списком. Ніколи не видаляй попередні відкриття |
| **Work Done** | **Лише додавати** | Додай нові виконані пункти під наявним списком. Ніколи не видаляй записи. Вказуй хеші комітів |
| **Status** | **Замінити** | Запиши спостережену ревізію й час, перевірки та їхній обсяг, перешкоди й наступного відповідального; розрізняй стан завдання, запуску та приймання |
| **Next Steps** | **Замінити** | Запиши оновлений практичний чекліст |
| **Code** | Оновити | Заміни найрелевантнішими фрагментами з поточного стану |

**Правило «лише додавати» для Work Done є суворим.** Навіть якщо попередній запис описує роботу, яку згодом переглянули, залиш його. Історія фіксує попередні твердження; актуальні докази визначають, що правда зараз. Додай виправлення з доказами замість видалення старого запису.

## Крок 4: Підтвердити

Після збереження підтвердь:
- Шлях до оновленого файлу
- Скільки нових пунктів Work Done додано
- Оновлений Status (один рядок)
- Скільки Next Steps лишилося
