# Етап 1 доповіді: Extract

Перетворює сирий матеріал (статтю, транскрипт, нотатки або їх суміш) на структурований підсумок, готовий для наступних етапів конвеєра. Автоматично визначає тип джерела.

## Коли використовувати цей skill

- Початок нової доповіді з будь-якого вихідного матеріалу
- Перший крок конвеєра доповіді (завжди запускайте перед іншими етапами)
- Перевірка наявного вихідного матеріалу, перш ніж братися за доповідь

## Що робить цей skill

1. **Збирає метадані**: запитує slug, подію, дату, тривалість, аудиторію, режим, якщо їх не надано
2. **Читає джерело**: завантажує файл джерела або вбудований вміст
3. **Визначає тип джерела** (REX із реальними доказами чи Concept з ідеями/тезою) за ознаками вмісту
4. **Витягує наративну дугу** (хронологічну для REX, тематичну для Concept)
5. **Витягує метрики**: кожне вимірюване число з його джерелом
6. **Визначає основні теми** (3-7 тем)
7. **Позначає прогалини**: чого бракує для повної доповіді
8. **Записує `{slug}-summary.md`**

## Вхідні дані

Обов'язково:
- Шлях до файлу джерела або вбудований вміст (стаття `.mdx`, транскрипт `.md`, нотатки)
- Метадані: `slug`, `event`, `date`, `duration`, `audience`, `type` (--rex або --concept)

Якщо метаданих бракує -> `AskUserQuestion`, перш ніж продовжувати.

## Вивід

`talks/{YYYY}-{slug}-summary.md`

## Визначення типу джерела

| Ознаки REX | Ознаки Concept |
|------------|----------------|
| Конкретні дати | Тези, аргументи |
| Виміряні метрики | Загальні спостереження |
| Назви проєктів/інструментів | Спостереження про тренди |
| Коміти, релізи, PR | Аналогії, метафори |
| "I shipped", "We built" | "I think", "In my opinion" |

Якщо гібрид -> зазначте обидва складники в підсумку.

## Формат виводу

```markdown
# Talk Summary: {Provisional Title}

**Slug** : {slug}
**Event** : {event}
**Date** : {date}
**Duration** : {duration} min
**Audience** : {audience description}
**Type detected** : REX | Concept | Hybrid
**Source** : {source file path}

---

## Narrative Arc

{Arc description: 3-5 sentences. Chronological if REX, thematic if Concept.}

## Main Themes

| # | Theme | Short description | Weight |
|---|-------|------------------|--------|
| 1 | {theme} | {description} | High/Medium/Low |
...

## Key Metrics Extracted

{All measurable numbers found in the source}

Format: `{value}`: {context} (Source: {section/page/git})

Examples:
- `1,200 commits` over 7 months (Source: "acceleration" section)
- `-97% traffic` after SSE migration (Source: CHANGELOG v1.1.0)

If none -> "No verifiable metrics found (Concept mode)"

## Narrative Potential

{3-5 sentences on the strengths and possible narrative angles.
What makes this talk potentially strong. What might be missing.}

## Gaps Identified

- [ ] {gap 1}: {how to fill it}
- [ ] {gap 2}: {how to fill it}

If no obvious gaps -> "No major gaps identified."

## Recommendations for next stages

- **Research**: {recommended / not applicable (Concept mode)}: {why}
- **Concepts**: {priority themes to explore}
- **Position**: {angles already visible from the source material}

---

*Generated by talk-stage1-extract: {date}*
*Source: {source path}*
```

## Правила витягу метрик

- Не округлюйте без зазначення цього
- Завжди додавайте джерело метрики
- Якщо два джерела суперечать одне одному, позначте обидва, не обираючи жодного
- Жодних вигаданих метрик для заповнення прогалин
- Для змін використовуйте формат `{before} -> {after}`

## Антипатерни

- Розмитий підсумок («Цей текст про ШІ...»)
- Пропуск метрик, навіть приблизних, із зазначенням джерела
- Приховування прогалин (краще назвати їх, ніж удавати, що їх немає)
- Зміна визначеного типу без обґрунтування
- Вигадування наративної дуги, якої немає в джерелі

## Контрольний список валідації

- [ ] Тип джерела визначено й обґрунтовано
- [ ] Наративна дуга в 3-5 чітких реченнях
- [ ] Усі вимірювані метрики витягнуто з їхніми джерелами
- [ ] Основні теми перелічено (максимум 3-7)
- [ ] Прогалини явно визначено
- [ ] Файл збережено в `talks/{YYYY}-{slug}-summary.md`

## Поради

- Запустіть це перед оркестратором, якщо хочете переконатися, що вихідний матеріал придатний
- Підсумок є фундаментом: його читає кожен наступний етап
- Гібридні джерела (частково REX, частково Concept) цілком прийнятні, просто чітко назвіть обидва складники
