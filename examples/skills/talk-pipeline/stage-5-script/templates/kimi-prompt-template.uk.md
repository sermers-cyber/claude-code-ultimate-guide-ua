## Вимоги до дизайну

**Візуальний стиль**:
- Темна тема, сучасна й мінімалістична
- Максимальний візуальний ефект за мінімуму тексту
- Крупна типографіка для ключових чисел (щонайменше 48pt для метрик)
- Іконки замість маркерів списку, де це можливо
- Чисті шрифти без засічок (Inter, SF Pro або подібні)
- Достатньо вільного простору навіть на темному тлі
- Високий контраст для читабельності на екранах проєкторів

**Кольорова палітра**:
- Основний фон: майже чорний (#0a0a0a)
- Фон поверхонь: темно-сірий (#141414) — для карток, блоків вмісту
- Піднесений фон: (#1e1e1e) — для виділених секцій
- Межа: (#2a2a2a) — ненав'язливий поділ між елементами
- Основний текст: майже білий (#e5e5e5)
- Другорядний текст: середньо-сірий (#a3a3a3)
- Приглушений текст: (#8a8a8a) — для підписів і міток
- Акцент — помаранчевий: (#f97316) — для ключових чисел, виділень, закликів до дії
- Акцент при наведенні — світло-помаранчевий: (#fb923c) — для другорядних виділень
- Успішний зелений: (#22c55e) — лише для позитивних метрик
- Попереджувальний червоний: (#ef4444) — лише для проблем, помилок, негативних метрик

**Побажання до макета**:
- 1 ідея на слайд — ніколи більше
- Єдиний футер із номером слайда (ненав'язливий, унизу праворуч)
- Вирівнювання тексту ліворуч для читабельності
- Максимум 30 слів на слайд (без урахування заголовків)
- Числа відображаються надвеликими й по центру, коли вони є головною думкою
- Блоки коду з трохи світлішим фоном (#1e293b) і моноширинним шрифтом
- Діаграми з простих блоків, стрілок і кольорів акцентної палітри

## Настанови щодо нотаток доповідача

Для кожного слайда нотатки доповідача містять:
- Ключовий наративний удар (яку емоцію/реакцію викликати)
- Точне формулювання для критичних моментів (пуанти, переходи)
- Орієнтири щодо таймінгу
- Позначки пауз для драматичного ефекту

Ключові сторітелінг-моменти, що потребують навмисних пауз:
1. {PAUSE_MOMENT_1} — {WHY_PAUSE}
2. {PAUSE_MOMENT_2} — {WHY_PAUSE}
3. {PAUSE_MOMENT_3} — {WHY_PAUSE}

## Додаткові вимоги

- Загальна кількість слайдів: рівно {SLIDE_COUNT} слайдів
- Номери сторінок на всіх слайдах, крім слайда 1 (титульного)
- Додайте ненав'язливі маркери переходу між діями (маленький номер дії в куті)
- Темне тло скрізь (#0a0a0a як база, #141414 для карток) — зручно для проєктора
- Усі діаграми використовують акцентну палітру (помаранчевий #f97316 на темному, #1e1e1e для піднесених елементів)
- Числа є героями цієї презентації — зробіть їх неможливими для непоміченості
- Без анімацій і складних переходів — просте згасання між слайдами
- Футер: ненав'язливий номер слайда внизу праворуч, ім'я доповідача внизу ліворуч
- Загальне враження має бути таким: {TONE_DESCRIPTION}

## Доступність

- Переконайтеся, що коефіцієнт контрасту тексту відповідає стандартам WCAG AA (мінімум 4.5:1)
- Використовуйте великі читабельні шрифти (мінімум 20pt для основного тексту, 28pt+ для заголовків, 48pt+ для ключових чисел)
- Не покладайтеся лише на колір для передавання інформації (використовуйте іконки + колір)
- Перевірте читабельність за типової роздільності проєктора (1920x1080)
