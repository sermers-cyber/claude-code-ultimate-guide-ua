# Виконуваний навчальний шлях Claude Code

Цей прототип без залежностей перетворює наявний [навчальний шлях із семи модулів](../../../guide/learning-path/README.uk.md) на локальну послідовність проходження. Він зберігає лише стан, що належить учневі, у `.claude/learning/claude-code-guide-progress.json` у цільовому проєкті.

## Що він робить

- створює один із чотирьох треків: Beginner, Practitioner, Production або Maintainer;
- розблоковує модулі лише після того, як для їхніх передумов записано докази;
- вимагає непорожню примітку з доказом для кожного завершення;
- видає детермінований наступний модуль, поточний статус і список повторень, що настали;
- планує повторення через 1, 3, 7, 14, 30, 60 і 90 днів;
- записує JSON-стан атомарно й відмовляється працювати з пошкодженим станом.

Це локальний навчальний засіб. Він не доводить компетентність, не вивантажує докази й не замінює людського рев'ю вправи.

## Швидкий старт

Спершу скористайтеся публічним робочим процесом самооцінювання:

```text
/self-assessment quick
```

Потім почніть із найнижчого треку, що відповідає вашій найближчій меті:

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" init --track Beginner
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" next
```

Виконавши вправу, запишіть доказ:

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" complete module-01 \
  --evidence "Installed Claude Code, ran /help, and recorded the version."
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" status
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" due
```

Skill працює зі стороннього проєкту, оскільки звертається до свого встановленого скрипта через `CLAUDE_SKILL_DIR` і записує стан у поточну директорію. Наприклад:

```bash
cd /path/to/project
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" init --track Practitioner
```

## Треки

| Трек | Очікуваний результат | Обов'язкові модулі |
| --- | --- | --- |
| Beginner | Безпечно пройти перший робочий процес із Claude Code | 01, 02, 03 |
| Practitioner | Побудувати багаторазові локальні воркфлоу з агентами й skills | з 01 до 05 |
| Production | Додати hooks, верифікацію та просунуту координацію | з 01 до 07 |
| Maintainer | Підтримувати спільні практики й операційні запобіжники | з 01 до 07 |

Діагностика допомагає обрати початковий трек, але не скасовує перевірок передумов. Учень, що обрав Production, усе одно проходить послідовність по порядку.

### Відповідність самооцінюванню

| Результат самооцінювання | Оберіть цей трек |
| --- | --- |
| Beginner | Beginner |
| Intermediate | Practitioner |
| Advanced | Production |

Maintainer обирається вручну і не є результатом самооцінювання. Використовуйте його лише тоді, коли мета включає спільне управління, наприклад підтримку командних інструкцій, засобів контролю чи практик збору доказів.

## Стан і відновлення

Файл стану містить лише обраний трек, дати завершення модулів і примітки з доказами. `init` його не перезаписує. Кожне збереження записує повний тимчасовий файл у тій самій директорії, скидає буфер на диск і атомарно замінює старий файл.

Якщо `status`, `next`, `complete` або `due` повідомляють про пошкоджений стан, зупиніться. Збережіть копію `.claude/learning/claude-code-guide-progress.json` для огляду, виправляйте її вручну лише після з'ясування причини або свідомо видаліть її й почніть новий профіль. Прототип не вгадуватиме, як відновити докази учня.

## Тести

```bash
python3 -m unittest -v examples/skills/learning-path/tests/test_progress.py
```

Цільовий набір тестів охоплює створення профілю, атомарне збереження, примусове дотримання передумов, перевірки доказів, вибір наступного модуля, інтервали повторень і відмову за пошкодженого стану.

## Межа валідації skill

`path.yaml` є валідним JSON і тому валідним YAML. Середовище виконання без залежностей валідує саме цю підмножину JSON за допомогою стандартної бібліотеки Python. Вбудований валідатор skills `quick_validate.py` потребує PyYAML, бо імпортує `yaml` до розбору frontmatter у `SKILL.md`. Якщо PyYAML відсутній, валідація frontmatter має статус `UNKNOWN`. Не повідомляйте її як пройдену валідацію skill. Локальний набір юніт-тестів усе одно перевіряє, що середовище виконання здатне завантажити поставлене визначення шляху.
