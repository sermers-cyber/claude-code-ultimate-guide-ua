# Навчальний шлях Claude Code

Використовуйте цей skill, щоб пройти обмежену локальну послідовність через наявний посібник із семи модулів. Рушій обирає лише ті модулі, чиї передумови виконано, нічого не зберігає поза директорією `.claude/learning/` поточного проєкту, вимагає непорожню примітку з доказом і відхиляє пошкоджений стан.

## Почніть з діагностики

Запустіть `/self-assessment quick`, перш ніж обирати трек. Це допоміжний засіб самооцінки, а не сертифікація. Зіставте результат свідомо:

| Результат самооцінювання | Трек навчального шляху |
| --- | --- |
| Beginner | Beginner |
| Intermediate | Practitioner |
| Advanced | Production |

Maintainer не є результатом самооцінювання. Обирайте його вручну лише тоді, коли мета полягає в спільному управлінні, наприклад підтримці командних інструкцій, засобів контролю чи практик збору доказів.

Оберіть найнижчий трек, що покриває вашу найближчу мету:

| Трек | Результат | Модулі |
| --- | --- | --- |
| Beginner | Безпечний перший щоденний воркфлоу | з 01 до 03 |
| Practitioner | Багаторазові проєктні воркфлоу | з 01 до 05 |
| Production | Автоматизація з контролем верифікації | з 01 до 07 |
| Maintainer | Спільна практика та управління | з 01 до 07 |

Визначення модулів, посилання на посібник, вправи, передумови та інтервали повторень містяться в [assets/path.yaml](assets/path.yaml). Джерельна програма: наявний [навчальний шлях із семи модулів](../../../guide/learning-path/README.uk.md).

## Команди

Запускайте команди з репозиторію чи проєкту, що вивчається. `CLAUDE_SKILL_DIR` це директорія встановленого skill, яку надає Claude Code. `--root "$PWD"` робить єдиною ціллю для стану поточний проєкт учня, а не встановлений skill.

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" init --track Beginner
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" status
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" next
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" complete module-01 \
  --evidence "Installed Claude Code, ran /help, and recorded the version."
python3 "${CLAUDE_SKILL_DIR}/scripts/progress.py" --root "$PWD" due
```

Файл стану: `.claude/learning/claude-code-guide-progress.json`. Він належить проєкту учня, а не цьому встановленому skill. `init` відмовляється перезаписувати наявний файл стану. Зберігайте стан локально, якщо свідомо не вирішили поділитися доказами.

## Бар'єр завершення

Перш ніж завершити модуль:

1. Прочитайте пов'язану сторінку посібника.
2. Виконайте пов'язану вправу в реальному проєкті.
3. Запишіть конкретну примітку з доказом, яку може перевірити інша людина, наприклад команду, змінений файл, результат тесту чи артефакт рев'ю.
4. Скористайтеся `next`, щоб отримати наступний розблокований модуль.

Порожня примітка, невиконана передумова, невідомий модуль, модуль поза обраним треком або пошкоджений стан є помилкою. Інструмент не виводить завершення з відсотка, коду виходу команди чи твердження учня.

## Повторення

Кожне завершення планує повторення рівно через 1, 3, 7, 14, 30, 60 і 90 днів після записаної дати завершення. `due` повертає всі заплановані повторення, що настали на сьогодні або раніше. Поверніться до пов'язаної вправи й оновіть окремий артефакт-доказ, якщо знання змінилися.

## Межа безпеки

Усі записи локальні й атомарні. Пошкоджений файл стану призводить до безпечної відмови й залишається недоторканим для огляду чи відновлення. Прототип не звертається до мережевих сервісів, не встановлює пакетів, не оцінює компетентність автоматично й не редагує посібник.

## Межа валідації

Середовище виконання валідує `path.yaml` парсером JSON з Python, бо файл використовує підмножину JSON мови YAML. Вбудований валідатор skills `quick_validate.py` імпортує PyYAML до розбору frontmatter у `SKILL.md`. Якщо цей імпорт не вдається, валідація frontmatter має статус `UNKNOWN`, а не успішної валідації skill. Тести середовища виконання без залежностей усе одно можуть підтвердити, що це визначення шляху завантажується.
