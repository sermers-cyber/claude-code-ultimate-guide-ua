# Assets

Цей каталог містить шаблони, зображення та шаблонний код.

**Примітка**: Assets НЕ завантажуються в контекст автоматично. На них треба посилатися явно.

## Рекомендації

- Використовуйте описові імена файлів
- Додавайте інструкції з використання в заголовки файлів
- Робіть шаблони мінімальними та придатними для налаштування

## Файли

Додайте свої assets сюди. Приклади:
- `template.md` - шаблон виводу
- `boilerplate.ts` - шаблонний код
- `config.json` - шаблон конфігурації
