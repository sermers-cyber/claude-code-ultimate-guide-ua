# Scripts

Цей каталог містить виконувані скрипти для детермінованих, повторюваних завдань.

## Рекомендації

- Скрипти мають бути самодостатніми та добре задокументованими
- Додавайте приклади використання в заголовки скриптів
- Обробляйте помилки коректно з чіткими повідомленнями
- Використовуйте відповідні коди виходу (0 для успіху, 1 для збою)

## Файли

Додайте свої скрипти сюди. Приклади:
- `generate.py` - основний скрипт генерації
- `validate.py` - утиліти валідації
- `transform.py` - помічники для трансформації даних
