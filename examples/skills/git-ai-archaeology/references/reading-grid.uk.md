# Сітка читання для археології harness

Кожен індикатор береться з `{slug}-harness.json`. Пороги є орієнтирами для читання, а не вердиктами: репозиторій-каталог, де кожен коміт є конфігурацією, читається інакше, ніж продуктовий монорепозиторій.

| Індикатор | Як обчислити | На що вказує | Зверніть увагу |
| --- | --- | --- | --- |
| Частка комітів harness | коміти harness / коміти репозиторію | Вага роботи з AI-конфігурацією в репозиторії | У каталозі skills близько 100 % за задумом |
| Перша поява для кожної родини | перший коміт для кожної родини | Порядок упровадження інструментів | Перейменування зберігає первісну дату |
| Частка головного учасника | коміти головного автора / коміти harness | Понад 60 %: harness тримається на одній людині | Малі репозиторії досягають 100 % з одним автором |
| Учасники з одним комітом | автори з одним комітом harness | Багато: конфігурацію написали один раз випадкові люди | Масові імпорти завищують показник |
| Ніколи не редаговані після створення | наявні файли з одним комітом / наявні файли | Понад 50 %: конфігурація «написав і забув», ймовірно, розходиться з кодом | Згенеровані файли й мають лишатися незмінними |
| Не чіпані 180 днів | наявні файли, останній коміт яких старший за 180 днів | Застарілі інструкції | Стабільні довідкові матеріали цілком легітимні |
| Видалені файли і медіанний час життя | файли, відсутні в ref; останній мінус створений | Час життя менше 14 днів: спроби й помилки в основній гілці | Переміщення між інструментами показуються як перейменування, а не видалення |
| Ідентичні копії в ref | групи файлів з однаковим blob | Розповсюдження копіюванням без єдиного джерела | Симлінки не рахуються як копії |
| Поширення копіюванням | той самий blob доданий за новим шляхом | Як і коли файл поширювався між модулями | Видно лише точні копії |
| Незлиті коміти harness | `--remotes --not ref` | Робота, що живе поза основною гілкою | Гілки, злиті через squash, все одно з'являються |
| Частка AI-трейлерів за місяць | коміти з трейлером / коміти | Нижня межа AI-асистованих комітів | Inline-автодоповнення не залишає трейлера |
| Використання проти harness | порівняйте два місячні ряди | Використання без harness: інструменти використовують «як є». Harness без використання: конфігурація, яку ніхто не підписує | Трейлери залежать від налаштувань інструмента за замовчуванням |
