# Контракт обмеженого агентного циклу

Використовуйте цей патерн, коли один агент може виконати роботу через повторювані дії та перевірки. Він зберігає потік керування явним без запровадження воркфлоу-фреймворку.

Запускний супутній приклад: [`bounded-loop-example.py`](./bounded-loop-example.py).

## Контракт

| Поле | Потрібне рішення |
| --- | --- |
| Мета (Goal) | Який результат запитано? |
| Дія (Action) | Що може змінюватися за кожної спроби? |
| Спостереження (Observation) | Які докази створило виконання? |
| Верифікатор (Verifier) | Яка незалежна перевірка приймає або відхиляє докази? |
| Бюджет (Budget) | Скільки спроб або вартості може спожити цикл? |
| Правило зупинки (Stop rule) | Яка точна умова повертає прийнятий результат? |
| Ескалація (Escalation) | Що відбувається, коли бюджет вичерпано? |

Приклад записує кожен перехід. Відхилена спроба повертається до `act`; перевірена спроба переходить до `accepted`; вичерпання бюджету переходить до `escalated`.

```text
act -> verify -> accepted
 ^        |
 |        v
 +----- rejected

act or verify -> escalated  when the attempt budget is exhausted
```

## Запуск

```bash
python3 examples/workflows/bounded-loop-example.py
```

Очікуваний результат:

```text
accepted after 2 attempts
```

## Коли переходити до графа

Лишайте цикл, доки кожен відхилений результат повертається до однієї наступної дії. Запроваджуйте явний граф, коли воркфлоу потребує кількох гілок, паралельної роботи, з'єднань, постійних контрольних точок або різних повноважень для різних переходів.

Правила проєктування дивіться в [Loop & Graph Engineering](../../guide/core/loop-graph-engineering.uk.md), а межу виконання навколо циклу в [Agent Harness Engineering](../../guide/core/agent-harness.uk.md).
