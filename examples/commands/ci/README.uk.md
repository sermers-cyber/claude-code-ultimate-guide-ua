# Команди CI

Slash-команди для воркфлоу CI/CD. Автоматично визначають стек (Python/Node/Rust) і підтримують як GitLab CI, так і GitHub Actions.

## Команди

| Команда | Опис |
|---------|-------------|
| `/ci:all` | Повний конвеєр: тести + перевірка типів + push + URL конвеєра. Єдина команда, потрібна перед PR. |
| `/ci:tests` | Запускає набір тестів. Автоматично визначає pytest, vitest, cargo test. |
| `/ci:pipeline` | Робить push поточної гілки й повертає URL для відстеження конвеєра. |
| `/ci:status` | Показує поточний статус конвеєра для активної гілки. |

## Схема використання

```
# Перед кожним PR:
/ci:all

# Запустити лише тести:
/ci:tests
/ci:tests tests/test_billing.py   # конкретний файл

# Перевірити конвеєр після push:
/ci:status
/ci:status 42   # конкретний номер MR/PR

# Push без повторного запуску тестів (наприклад, зміна лише в документації):
/ci:all --skip-tests
```

## Підтримка стеків

| Стек | Команда тестів | Перевірка типів |
|-------|-------------|------------|
| Python + uv | `uv run pytest --tb=short -q` | mypy (необов'язково) |
| Node + pnpm | `pnpm vitest run` | `pnpm tsc --noEmit` |
| Node + npm | `npm test` | `npx tsc --noEmit` |
| Rust | `cargo test --quiet` | `cargo clippy` |

## Підтримка CI-платформ

Обидві команди підтримують **GitLab CI** (через CLI `glab`) і **GitHub Actions** (через CLI `gh`).
Якщо жоден із CLI не встановлено, команди просто показують URL конвеєра.
