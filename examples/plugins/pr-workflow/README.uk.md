# Плагін PR workflow

Автоматизована система рев'ю та валідації pull request.

## Встановлення

```bash
bash install.sh
```

## Компоненти

- **Агент code-reviewer**: автоматизовані перевірки якості коду та безпеки
- **Команда /review-pr**: аналізує PR і надає детальний зворотний зв'язок
- **Команда /pr**: швидкий воркфлоу підготовки PR
- **Hook pre-pr-check**: валідує зміни перед створенням PR

## Швидкий старт

```bash
# Review an existing PR
/review-pr 123

# Prepare a new PR
/pr

# Check what will be submitted
/validate-changes
```

## Можливості

✓ Аналіз якості коду
✓ Сканування безпеки
✓ Перевірка покриття тестами
✓ Перевірки відповідності
✓ Автоматизовані пропозиції
✓ Сповіщення команди
