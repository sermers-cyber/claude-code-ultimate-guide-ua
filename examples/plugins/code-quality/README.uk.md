# Плагін Code quality suite

Аналіз коду, рефакторинг і дотримання принципів чистого коду.

## Встановлення

```bash
bash install.sh
```

## Компоненти

- **Агент refactoring-specialist**: автоматизоване покращення коду
- **Агент clean-code-reviewer**: контроль стандартів якості коду
- **Команда /refactor**: безпечний рефакторинг із валідацією
- **Команда /optimize**: оптимізація продуктивності

## Швидкий старт

```bash
# Refactor a file or folder
/refactor src/auth/

# Analyze code quality
/audit-codebase

# Get design pattern suggestions
/design-patterns
```

## Можливості

✓ Аналіз складності
✓ Пропозиції щодо рефакторингу
✓ Рекомендації щодо патернів проєктування
✓ Оптимізація продуктивності
✓ Оцінка зручності супроводу
