**Натхненно**: підходом Context Engineering від Робіна Лоренца (оригінальний допис у LinkedIn недоступний) (лют. 2026)

## ✅ Виконана робота

Перелічіть усю роботу, завершену в цій сесії, з посиланнями на коміти:

- **[Завдання 1]**: опис того, що було зроблено
  - Коміт: `abc123`
  - Файли: `src/feature.ts`, `tests/feature.test.ts`

- **[Завдання 2]**: ще один виконаний пункт
  - Коміт: `def456`
  - Файли: `config/settings.json`

**Перевірка стану git**:
```bash
# Run before handoff to capture state
git status
git log -5 --oneline
```

## 🔄 Відкладені завдання

Завдання, розпочаті, але не завершені, із відсотком виконання та блокерами:

- **[Завдання 3]**: короткий опис
  - **Прогрес**: виконано на 80%
  - **Блокер**: очікування API-ключа / потрібно уточнити вимоги
  - **Наступна дія**: [конкретний наступний крок]
  - **Зачеплені файли**: `src/pending-feature.ts`

- **[Завдання 4]**: ще один відкладений пункт
  - **Прогрес**: фаза дослідження (20%)
  - **Блокер**: потрібне архітектурне рішення щодо X
  - **Наступна дія**: переглянути варіанти A і B

## 🚧 Блокери та проблеми

Критичні блокери, які потрібно розв'язати перед продовженням:

1. **[Блокер 1]**: докладний опис того, що блокує прогрес
   - **Вплив**: що це блокує
   - **Обхідний шлях**: тимчасове рішення, якщо є
   - **Шлях розв'язання**: як розблокувати

2. **[Проблема 1]**: виявлений технічний борг або баг
   - **Серйозність**: висока/середня/низька
   - **Обхідний шлях**: поточне пом'якшення

## 💡 Чому цей шаблон?

**Обґрунтування на основі досліджень**:

- **Автокомпактизація погіршує якість**: продуктивність LLM падає на 50-70% на складних завданнях за високого контексту ([Context Rot Research](https://research.trychroma.com/context-rot))
- **Ручна передача зберігає намір**: структурована документація фіксує «що важливо» замість «погіршеної версії всього»
- **Поріг 85% запобігає автокомпактизації**: автокомпактизація спрацьовує на ~75% (VS Code) або ~95% (CLI), тож 85% дає запас міцності
- **Логічна точка зупинки > автоматичне стиснення**: консенсус спільноти віддає перевагу ручному `/compact` у точках зупинки

**Ключовий принцип**: «Передача дає вам чисту версію того, що важливо» — Робін Лоренц
