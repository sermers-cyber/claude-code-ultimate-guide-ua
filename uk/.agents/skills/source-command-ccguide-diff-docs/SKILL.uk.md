# source-command-ccguide-diff-docs

Використовуй цей skill, коли користувач просить виконати мігровану вихідну команду `ccguide-diff-docs`.

## Command Template

Використай MCP-інструмент `diff_official_docs`.

Без мережевих викликів: читає лише локальні індексні файли (~50KB кожен). Миттєво.

Подай результати чітко:
- Додані розділи (нові сторінки в офіційній документації)
- Видалені розділи
- Змінені розділи з дельтою рядків і першим зміненим рядком
- Кількість незмінених

Якщо базового знімка немає, скажи користувачеві спочатку виконати /ccguide:init-docs.
Якщо поточного знімка немає, скажи користувачеві спочатку виконати /ccguide:refresh-docs.
Якщо змін немає, підтверди, що все синхронізовано, і запропонуй виконати /ccguide:refresh-docs для оновлення.
