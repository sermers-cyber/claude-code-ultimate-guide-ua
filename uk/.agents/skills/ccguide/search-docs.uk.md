description: Шукати в офіційній документації Anthropic Claude Code за ключовим словом
---

Використай MCP-інструмент `search_official_docs` із query: $ARGUMENTS

Якщо запит не вказано, запитай користувача, що він хоче знайти.

Ліміт за замовчуванням: 5 результатів.

Для кожного результату покажи:
- Назву розділу
- URL джерела (відтвори дослівно)
- Уривок із відповідним вмістом

Якщо знімка немає, скажи користувачеві спочатку виконати /ccguide:init-docs.
