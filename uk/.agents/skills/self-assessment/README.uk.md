# Skill самооцінювання

Інтерактивний інструмент оцінювання навичок, який визначає ваш рівень володіння Claude Code та створює персоналізовані шляхи навчання.

## Огляд

Цей skill має два режими оцінювання:

- **Quick** (5 хв): 10 питань, по одному на тему, швидка перевірка навичок
- **Comprehensive** (20 хв): 20 питань, по два на тему, глибокий аналіз рівня володіння

Після оцінювання ви отримуєте:
- ✓ Свій профіль рівня володіння (Beginner/Intermediate/Advanced)
- ✓ Розбивку балів за темами
- ✓ Виявлені прогалини, ранжовані за важливістю
- ✓ Персоналізований шлях навчання (з урахуванням залежностей)
- ✓ 3 практичні проєкти, підібрані під ваш рівень

## Використання

### Швидке оцінювання
```bash
/self-assessment quick
```
Швидка оцінка за всіма темами. Показує загальний рівень + 2-3 головні прогалини.

### Комплексне оцінювання
```bash
/self-assessment comprehensive
```
Глибоке занурення в кожну тему. Показує детальні бали за темами + повний шлях навчання + практичні проєкти.

### Опції
```bash
/self-assessment quick --verbose        # Show detailed explanations
/self-assessment comprehensive --save   # Save results to assessment-results.json
```

## Як це працює

### Потік взаємодії

1. **Оберіть режим:** Quick або Comprehensive
2. **Відповідайте на питання:** вибір із 4 варіантів (A-D)
3. **Дивіться відгук:** пояснення + посилання на посібник для кожної відповіді
4. **Отримайте профіль:** оцінка рівня володіння за всіма темами
5. **Отримайте шлях навчання:** персоналізована послідовність з урахуванням залежностей
6. **Оберіть дію:** вчитися, практикуватися, пройти знову або заглибитися в окрему тему

### Підрахунок балів

**Режим Quick:**
- Усього 10 балів (по 1 на тему)
- Рівні: 0-3 (Beginner), 4-7 (Intermediate), 8-10 (Advanced)

**Режим Comprehensive:**
- Усього 20 балів (по 2 на тему)
- Рівні: 0-6 (Beginner), 7-13 (Intermediate), 14-20 (Advanced)

### Охоплені теми

1. Quick Start — Встановлення та базовий воркфлоу
2. Core Concepts — Цикл взаємодії, контекст, сесії
3. Memory & Settings — Конфігурація CLAUDE.md
4. Agents — Створення та використання спеціалізованих агентів
5. Skills — Створення багаторазових можливостей
6. Commands — Slash-команди та автоматизація
7. Hooks — Тригери за подіями та валідація
8. MCP Servers — Інтеграція протоколу та конфігурація
9. Advanced Patterns — Оркестрація кількох агентів, композиція
10. Security & Production — Посилення захисту, управління, масштабування

## Шлях навчання

Після комплексного оцінювання ви отримуєте:

### Структуровані фази навчання
- **Phase 1:** Спершу закрийте критичні прогалини (з урахуванням залежностей)
- **Phase 2:** Розвивайте проміжні навички
- **Phase 3:** Опануйте просунуті шаблони та продакшен
- **Бонус:** Глибоке занурення в окремі слабкі теми

Кожна фаза містить:
- 📖 Завдання для читання (посилання на конкретні розділи посібника)
- 🔨 Практичну роботу (шаблони з examples/)
- 📝 Перевірку знань (/lesson-quiz [topic])

### 3 практичні проєкти
Отримайте реальні сценарії, підібрані під ваш рівень:

1. **Проєкт 1:** Поєднайте 2-3 теми, у яких ви слабкі (2-3 години)
2. **Проєкт 2:** Реальний воркфлоу (3 години)
3. **Проєкт 3:** Продакшен-налаштування або конфігурація команди (3 години)

Кожен проєкт містить:
- Чіткі критерії успіху
- Покрокові інструкції
- Очікувані результати

## Інтеграція із системою навчання

Цей skill працює разом із `/lesson-quiz` для глибшого навчання:

```bash
# After comprehensive assessment, drill down:
/lesson-quiz 05-skills          # 5 questions on Skills topic
/lesson-quiz 07-hooks           # 5 questions on Hooks topic
/lesson-quiz 09-advanced        # 5 questions on Advanced Patterns
```

- **comprehensive-assessment-prompt.txt** — Питання для режиму Comprehensive (20 питань)
- **README.md** — Цей файл

## Поради для найкращих результатів

1. **Відповідайте чесно** — не вгадуйте; пропускайте, якщо не впевнені (це впливає на якість шляху навчання)
2. **Переглядайте пояснення** — кожна відповідь містить чому + посилання на посібник
3. **Проходьте повторно після навчання** — ваш профіль покращується з кожною опанованою темою
4. **Діліться результатами** — використовуйте профіль для узгодження навчання команди
5. **Підлаштовуйте під свою мету** — Quick для швидкості, Comprehensive для глибини

## Розподіл балів

### Режим Quick (10 питань, по 1 на тему)
- Ідеальний результат: 10/10 (100%) — рівень Master
- Advanced: 8-10/10 (80-100%)
- Intermediate: 4-7/10 (40-70%)
- Beginner: 0-3/10 (0-30%)

### Режим Comprehensive (20 питань, по 2 на тему)
- Ідеальний результат: 20/20 (100%) — рівень Expert
- Advanced: 14-20/20 (70-100%)
- Intermediate: 7-13/20 (35-65%)
- Beginner: 0-6/20 (0-30%)

Рівень володіння за темами:
- 0/2 (0%) — Володіння відсутнє, почніть із цього
- 1/2 (50%) — Базове розуміння, потрібна практика
- 2/2 (100%) — Впевнене володіння, готові до просунутого рівня

## Приклади

### Для нового розробника
```
Quick assessment → Identifies gaps in Core Concepts + Commands
→ Recommended: Read Part 2 + Part 6 of guide
→ Then try Quick assessment again
→ Move to Comprehensive assessment
```

### Для розробника середнього рівня
```
Comprehensive assessment → Shows 50% on MCP + 0% on Hooks
→ Recommended learning path: Hooks Phase (4h) → MCP Phase (3h)
→ Practice Project: Automation workflow combining both
→ Then retry assessment to track improvement
```

### Для впровадження в команді
```
All team members take comprehensive assessment
→ Aggregate results show:
  • 80% need Hooks training
  • 50% need Advanced Patterns
  • 20% ready for security hardening
→ Create team learning plan from individual gaps
→ Monthly re-assessments track progress
```

## Майбутні покращення

Заплановані можливості:
- [ ] Звітність по команді в цілому (бачити прогалини команди з першого погляду)
- [ ] Відстеження прогресу (порівняння з попереднім оцінюванням)
- [ ] Питання з адаптованою складністю (складніші, якщо ви отримуєте високі бали)
- [ ] Пояснення, налаштовані ШІ (пояснення вашими словами)
- [ ] Експорт результатів (PDF-профіль, яким можна ділитися з тімлідами)

- **Хочете краще зрозуміти прогалини?** → Дивіться персоналізований шлях навчання
