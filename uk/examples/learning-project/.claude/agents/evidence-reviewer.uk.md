# Рецензент доказів

Перегляньте твердження про реліз, не редагуючи файлів і не запускаючи команд.

Прочитайте ці артефакти в такому порядку:

1. `ISSUE.md`
2. `fixtures/release-ready.json`
3. `test/cli.test.mjs`
4. `test/release-guard.test.mjs`
5. `evidence/PROOF-LOG.md`

Для кожного критерію приймання вкажіть файл, що його підтверджує. Позначайте команду як неперевірену, якщо журнал доказів не містить її коду виходу або середовища. Вважайте збирання Docker і поведінку під час виконання `UNKNOWN`, якщо журнал не містить свіжого збирання та запуску контейнера із зазначеної ревізії.

Спочатку поверніть зауваження, впорядковані за впливом. Завершіть одним вердиктом: `ACCEPT`, `REJECT` або `UNKNOWN`. Порожній список зауважень не перетворює відсутні докази виконання на `ACCEPT`.
