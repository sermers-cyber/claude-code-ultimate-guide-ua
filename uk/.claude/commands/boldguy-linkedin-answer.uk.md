# Bold Guy LinkedIn Answer

Підготувати коментар у LinkedIn у відповідь на допис, із посиланнями на відповідні розділи Claude Code Ultimate Guide, написаний голосом Florian "Flow" Bruniaux без жодних ознак AI.

## Використання

```
/boldguy-linkedin-answer https://www.linkedin.com/posts/...
```

## Крок 1: Прочитати допис у LinkedIn

1. Розбери `$ARGUMENTS`, щоб отримати URL LinkedIn. Якщо його немає, запитай: "Який допис у LinkedIn?"
2. Отримай вміст допису через WebFetch
3. Витягни: ім'я автора, головний аргумент, ключові тези, тон

## Крок 2: Визначити відповідні розділи посібника

Знайди в посібнику вміст, що стосується теми допису:

1. Пошукай у `guide/ultimate-guide.md` та інших файлах `guide/*.md` ключові слова з допису
2. Пошукай у `machine-readable/reference.yaml` відповідні розділи
3. Перевір, чи існує окрема сторінка лендінгу (напр. `/learning`, `/quiz`)
4. Віддавай пріоритет розділам, де посібник додає унікальну цінність (протоколи, інструменти, дані, методологія)

**Результат цього кроку**: Список із 2-4 відповідних елементів для посилання (назва розділу, ключове поняття, URL лендінгу, якщо застосовно).

## Крок 3: Написати коментар

Напиши коментар у LinkedIn за такими правилами:

### Правило мови (КРИТИЧНО)
- **Збігайся з мовою допису**: якщо допис англійською, пиши коментар англійською; якщо французькою, пиши французькою.
- Ніколи не змішуй мови в одному коментарі.

### Правила голосу (голос Florian, а НЕ команди)
- Завжди "I've" / "I" — ніколи "we've" / "we" (Florian працює над посібником сам)
- Позиція: "I share what I learn" — ніколи "I teach you"
- Практик, а не гуру
- Французькою: "j'ai" / "je" — ніколи "on a" / "nous avons"

### Правила платформи (коментар у LinkedIn)
- **Звертання на ім'я** до автора допису (tutoiement французькою, ім'я англійською)
- Розмовний стиль, як розмова в коридорі
- **Максимум 1200 символів** (жорстке обмеження)
- Жодних хештегів
- Жодних емодзі (або максимум 1, якщо справді виправдано)
- Посилання лише якщо воно дає пряму цінність (розділ посібника, сторінка лендінгу)

### Структура вмісту
```
[Підтвердити/визнати думку автора — 1 речення]

[Зв'язок із вмістом посібника — що я задокументував, що кажуть дані]

[1-2 конкретні елементи: протокол, метрика, інструмент, методологія]

[Завершення: посилання на відповідний розділ посібника/лендінгу АБО розмовне запитання]
```

### Що включати
- Конкретні елементи посібника: протоколи (UVAL тощо), інструменти (`--learn` тощо), методології
- Реальні дані, якщо вони є (академічні дослідження, цитовані в посібнику, виміряні метрики)
- Правильний URL лендінгу/посібника, щоб читач міг заглибитися

## Крок 4: Прохід проти ознак AI

Запусти skill /boldguy-adapt на чернетці, щоб прибрати ознаки AI.

Зокрема перевір:

### Чек-ліст (кожен пункт має бути пройдений)
- [ ] Жодного em dash (`—`) — використовуй кому, дужки або перебудуй речення
- [ ] Жодного staccato (3+ речення поспіль коротші за 5 слів)
- [ ] Патерн "C'est pas X. C'est Y." максимум 1 раз, з комою, а не крапкою
- [ ] Різна довжина речень у кожному абзаці
- [ ] Жодної надто симетричної/досконалої завершальної фрази-удару
- [ ] Абзаци пов'язують ідеї (не «1 ідея = 1 ізольований абзац»)
- [ ] Жодного паралелізму жирних пунктів (напр. 4x "Un **X** qui...")
- [ ] Жодних стрілок `→` у списках (розмовний стиль, а не слайд-дек)

### Перевірка ритму
Коментар має читатися як розмова в кав'ярні між практиками:
- Змішуй короткі й довгі речення в одному абзаці
- Ідеї перетікають одна в одну, а не лежать окремо
- Завершення природне (запитання або просте твердження), а не гасло

## Крок 5: Підрахунок символів і фінальна перевірка

1. Порахуй символи (має бути <= 1200)
2. Якщо перевищено: виріж найменш суттєвий елемент, об'єднай речення, ущільни формулювання
3. Якщо помітно менше (~800): добре, не набивай обсяг

### Фінальний чек-ліст
- [ ] "je" скрізь (ніколи "on" щодо роботи над посібником)
- [ ] <= 1200 символів
- [ ] Tutoiement з автором
- [ ] Чек-ліст проти AI пройдено
- [ ] Щонайменше 1 конкретне посилання на посібник (протокол, інструмент, дані)
- [ ] Максимум 1 посилання (посібник або лендінг)
- [ ] Жодної маркетингової мови
- [ ] Читається як людина-практик, а не пітч

- **URL не надано** → Попроси його
