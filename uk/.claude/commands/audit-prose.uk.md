# Audit Prose — Збагачення «голих» розділів

Додає описову прозу (2-4 речення) перед кожним «голим» розділом whitepapers.
«Голий» розділ = заголовок, одразу за яким іде таблиця, блок коду або список без вступного абзацу.

## Використання

```
/audit-prose        # Усі WP (00-08), FR + EN
/audit-prose 07     # Лише WP07 (FR + EN)
/audit-prose 03 07  # Лише WP03 і WP07
```

## Визначення «голого розділу»

Розділ (`##` або `###`), за яким БЕЗПОСЕРЕДНЬО йде:
- Markdown-таблиця (`|`)
- Блок коду (` ``` `)
- Маркований (`-`) або нумерований список

Без вступного абзацу (мінімум 2 речення).

## Суворі правила (не підлягають обговоренню)

1. **НІКОЛИ** не завершуй абзац знаком `:` перед маркованим списком → баг Typst, що зливає пункти списку в один рядок
2. **НЕ ВИГАДУЙ** цифр, метрик чи цитат
3. **НЕ ДОДАВАЙ** callouts (`:::`), Mermaid чи персона-сценаріїв
4. **НЕ ПЕРЕВИЩУЙ** +15% рядків на файл
5. Версії залишаються на **3.27.6**
6. Проза EN = природна англійська, **не** дослівний переклад із FR
7. Кожне доповнення = **мінімум 2 речення, максимум 4 речення**

Для кожного цільового WP запусти агента з таким промптом:

## Визначення «голого розділу»
Розділ (## або ###), за яким БЕЗПОСЕРЕДНЬО йде таблиця, блок коду або
маркований список, БЕЗ вступного абзацу (2+ речення).

## Що ти робиш
Для КОЖНОГО виявленого «голого розділу»:
1. Додай 2-4 речення ПЕРЕД структурованим вмістом
2. Кожне речення несе НОВУ ІНФОРМАЦІЮ: чому, коли використовувати,
   наслідки, дизайнерський вибір або практичний контекст
3. НЕ переформульовуй те, що йде далі — ДОПОВНЮЙ відсутнім контекстом

## Процес
1. ПРОЧИТАЙ reference.yaml (розділи, релевантні для WP)
2. ПРОЧИТАЙ повний WP FR
3. ВИЯВИ всі «голі» розділи
4. ВІДРЕДАГУЙ файл FR (інструмент Edit, розділ за розділом)
5. ПРОЧИТАЙ повний WP EN
6. ВІДРЕДАГУЙ файл EN
7. ПЕРЕВІР: жоден абзац не закінчується на ":" перед списком
8. Звітуй: оброблені розділи, дельта рядків FR/EN
```

### Очікування та звітування

Дочекайся відповідей усіх агентів. Для кожного завершеного WP виведи:

```
WP[XX] ✅ — [N] розділів, +[X]% FR/EN
```

### Завершення роботи

Коли всі агенти завершили, надішли shutdown_request кожному, потім TeamDelete.

## Перевірка після збагачення

```bash
# 1. Дельта рядків (макс. +15%)
for f in whitepapers/fr/*.qmd; do
  echo "$(wc -l < "$f") $(basename $f)"
done

# 2. Перевірити баг Typst: абзац, що закінчується на ":" перед списком
grep -n ':$' whitepapers/fr/*.qmd whitepapers/en/*.qmd | head -20

# 3. Версії не змінилися
grep "^version:" whitepapers/fr/*.qmd whitepapers/en/*.qmd

# 4. Перебудувати PDF
for f in whitepapers/fr/*.qmd whitepapers/en/*.qmd; do
  quarto render "$f"
done
```
