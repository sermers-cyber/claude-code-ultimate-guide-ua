---
description: Повторно отримати офіційну документацію Anthropic з Claude Code й оновити поточний знімок (базовий не змінюється)
---

Використай MCP-інструмент `refresh_official_docs`.

Він завантажує ~1.2MB з Anthropic (займає ~5 с) і оновлює лише "поточний" знімок.
Базовий знімок (встановлений через init_official_docs) ніколи не змінюється.

Після успіху покажи короткий попередній diff проти базового знімка, який повертає інструмент.
Нагадай користувачеві виконати /ccguide:diff-docs, щоб отримати повний докладний diff.
