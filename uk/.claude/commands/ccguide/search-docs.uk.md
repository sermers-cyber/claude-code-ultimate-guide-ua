---
description: Шукати в офіційній документації Anthropic з Claude Code за ключовим словом
---

Використай MCP-інструмент `search_official_docs` із запитом: $ARGUMENTS

Якщо запит не вказано, запитай користувача, що він хоче знайти.

Ліміт за замовчуванням: 5 результатів.

Подай кожен результат із:
- Заголовком розділу
- URL джерела (відтвори дослівно)
- Уривком із відповідним вмістом

Якщо знімка немає, скажи користувачеві спершу виконати /ccguide:init-docs.
