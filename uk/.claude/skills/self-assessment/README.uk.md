# Skill самооцінювання

Інтерактивний інструмент оцінювання навичок, що визначає ваш рівень володіння Claude Code і створює персоналізовані шляхи навчання.

## Огляд

Цей skill пропонує два режими оцінювання:

- **Швидкий** (5 хв): 10 питань, по одному на тему, швидка перевірка навичок
- **Комплексний** (20 хв): 20 питань, по два на тему, глибокий аналіз володіння

Після оцінювання ви отримуєте:
- ✓ Ваш профіль володіння (Початківець/Середній/Просунутий)
- ✓ Розбивку балів за темами
- ✓ Виявлені прогалини, ранжовані за важливістю
- ✓ Персоналізований шлях навчання (з урахуванням залежностей)
- ✓ 3 практичні проєкти, підібрані під ваш рівень

## Використання

### Швидке оцінювання
```bash
/self-assessment quick
```
Швидка оцінка за всіма темами. Показує загальний рівень + 2-3 головні прогалини.

### Комплексне оцінювання
```bash
/self-assessment comprehensive
```
Глибоке занурення в кожну тему. Показує детальні бали за темами + повний шлях навчання + практичні проєкти.

### Опції
```bash
/self-assessment quick --verbose        # Show detailed explanations
/self-assessment comprehensive --save   # Save results to assessment-results.json
```

## Як це працює

### Потік взаємодії

1. **Оберіть режим:** Швидкий чи Комплексний
2. **Відповідайте на питання:** вибір із 4 варіантів (A-D)
3. **Дивіться відгук:** пояснення + посилання на посібник для кожної відповіді
4. **Отримайте профіль:** оцінка володіння за всіма темами
5. **Отримайте шлях навчання:** персоналізована послідовність з урахуванням залежностей
6. **Оберіть дію:** вчитися, практикуватися, пройти знову чи заглибитися в конкретну тему

### Оцінювання

**Швидкий режим:**
- 10 балів загалом (1 за тему)
- Рівні: 0-3 (Початківець), 4-7 (Середній), 8-10 (Просунутий)

**Комплексний режим:**
- 20 балів загалом (2 за тему)
- Рівні: 0-6 (Початківець), 7-13 (Середній), 14-20 (Просунутий)

### Охоплені теми

1. Quick Start — Встановлення та базовий робочий процес
2. Core Concepts — Цикл взаємодії, контекст, сесії
3. Memory & Settings — Конфігурація CLAUDE.md
4. Agents — Створення та використання спеціалізованих агентів
5. Skills — Створення багаторазових можливостей
6. Commands — Slash-команди та автоматизація
7. Hooks — Тригери за подіями та валідація
8. MCP Servers — Інтеграція протоколу та конфігурація
9. Advanced Patterns — Оркестрація кількох агентів, композиція
10. Security & Production — Посилення безпеки, керування, масштабування

## Шлях навчання

Після комплексного оцінювання ви отримуєте:

### Структуровані фази навчання
- **Фаза 1:** спершу закрити критичні прогалини (з урахуванням залежностей)
- **Фаза 2:** розвинути середні навички
- **Фаза 3:** опанувати просунуті патерни та продакшен
- **Бонус:** поглиблений розбір конкретних слабких тем

Кожна фаза містить:
- 📖 Завдання для читання (посилання на конкретні розділи посібника)
- 🔨 Практичну роботу (шаблони з examples/)
- 📝 Перевірку знань (/lesson-quiz [topic])

### 3 практичні проєкти
Отримайте реальні сценарії, підібрані під ваш рівень:

1. **Проєкт 1:** об'єднайте 2-3 теми, у яких ви слабкі (2-3 години)
2. **Проєкт 2:** реальний робочий процес (3 години)
3. **Проєкт 3:** продакшен-налаштування або конфігурація команди (3 години)

Кожен проєкт містить:
- Чіткі критерії успіху
- Покрокові інструкції
- Очікувані результати

## Інтеграція із системою навчання

Цей skill працює з `/lesson-quiz` для глибшого навчання:

```bash
# After comprehensive assessment, drill down:
/lesson-quiz 05-skills          # 5 questions on Skills topic
/lesson-quiz 07-hooks           # 5 questions on Hooks topic
/lesson-quiz 09-advanced        # 5 questions on Advanced Patterns
```

## Поради для найкращих результатів

1. **Відповідайте чесно** — не вгадуйте; пропускайте, якщо не впевнені (це впливає на якість шляху навчання)
2. **Читайте пояснення** — кожна відповідь містить чому + посилання на посібник
3. **Проходьте знову після навчання** — ваш профіль покращується з кожною опанованою темою
4. **Діліться результатами** — використовуйте профіль, щоб узгодити навчання команди
5. **Підлаштовуйте під мету** — Швидкий для швидкості, Комплексний для глибини

## Розподіл балів

### Швидкий режим (10 питань, по 1 на тему)
- Ідеальний результат: 10/10 (100%) — рівень Майстра
- Просунутий: 8-10/10 (80-100%)
- Середній: 4-7/10 (40-70%)
- Початківець: 0-3/10 (0-30%)

### Комплексний режим (20 питань, по 2 на тему)
- Ідеальний результат: 20/20 (100%) — рівень Експерта
- Просунутий: 14-20/20 (70-100%)
- Середній: 7-13/20 (35-65%)
- Початківець: 0-6/20 (0-30%)

Володіння за темами:
- 0/2 (0%) — Немає володіння, зосередьтеся тут спершу
- 1/2 (50%) — Базове розуміння, потрібна практика
- 2/2 (100%) — Вправність, готовність до просунутого рівня

## Приклади

### Для нового розробника
```
Швидке оцінювання → Виявляє прогалини в Core Concepts + Commands
→ Рекомендовано: прочитати Part 2 + Part 6 посібника
→ Потім спробувати Швидке оцінювання ще раз
→ Перейти до Комплексного оцінювання
```

### Для розробника середнього рівня
```
Комплексне оцінювання → Показує 50% з MCP + 0% з Hooks
→ Рекомендований шлях навчання: фаза Hooks (4 год) → фаза MCP (3 год)
→ Практичний проєкт: автоматизований робочий процес, що поєднує обидва
→ Потім повторити оцінювання, щоб відстежити покращення
```

### Для впровадження в команді
```
Усі члени команди проходять комплексне оцінювання
→ Агреговані результати показують:
  • 80% потребують навчання з Hooks
  • 50% потребують Advanced Patterns
  • 20% готові до посилення безпеки
→ Створити план навчання команди з індивідуальних прогалин
→ Щомісячні повторні оцінювання відстежують прогрес
```
