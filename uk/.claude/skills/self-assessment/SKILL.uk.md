# Самооцінювання Claude Code

**Опануйте навички Claude Code завдяки персоналізованому навчальному шляху.**

Це інтерактивне оцінювання визначає ваш поточний рівень експертизи та створює власний шлях навчання, підлаштований під ваші прогалини й цілі.

---

## Як це працює

### Крок 1: Оберіть режим

**Швидкий режим** (5 хв)
- 10 питань за 10 темами
- Найкраще для: швидкої перевірки навичок, розуміння загального рівня
- Результат: загальний профіль (Початківець/Середній/Просунутий) + 2-3 головні прогалини

**Комплексний режим** (20 хв)
- 20 питань (по 2 на тему)
- Найкраще для: детального оцінювання володіння, планування навчання команди
- Результат: бали за темами + детальний шлях навчання + 3 практичні проєкти

### Крок 2: Відповідайте на питання

Питання охоплюють:
- Практичне використання (як щось робити)
- Ухвалення рішень (коли що використовувати)
- Архітектурні патерни (чому речі працюють)
- Найкращі практики продакшену (безпека, продуктивність, масштабування)

Кожне питання має:
- 4 варіанти (A-D)
- Негайний відгук щодо правильної відповіді
- Посилання на відповідний розділ посібника

### Крок 4: Отримайте шлях навчання

На основі ваших балів ви отримуєте:

**Пріоритезовану послідовність навчання** (з урахуванням залежностей):
1. Теми впорядковано за слабкістю + важливістю
2. Показано передумови (фундамент пропускати не можна)
3. Оцінки часу для кожної теми (сума лише того, що вам потрібно)
4. Шаблони й приклади, прив'язані до кожної теми

**Приклад шляху для розробника середнього рівня:**
```
Фаза 1: Основи Hooks (2 години)
  → Читати: guide/ultimate-guide.md#7-hooks
  → Спробувати: examples/hooks/event-driven-formatting.sh
  → Вікторина: /lesson-quiz 07-hooks

Фаза 2: Інтеграція MCP (3 години)
  → Читати: guide/ultimate-guide.md#8-mcp-servers
  → Спробувати: examples/mcp-configs/github-integration.json
  → Вікторина: /lesson-quiz 08-mcp-servers

Фаза 3: Advanced Patterns (4 години)
  → Читати: guide/ultimate-guide.md#9-advanced-patterns
  → Практика: 3 реальні проєкти (див. нижче)
  → Вікторина: /lesson-quiz 09-advanced-patterns
```

**3 практичні проєкти**
На основі вашого профілю ви отримуєте цільові вправи:
- Проєкт 1: об'єднайте 2-3 теми, у яких ви слабкі
- Проєкт 2: інтеграція реального робочого процесу
- Проєкт 3: сценарій для команди/продакшену

## Чого ви навчитеся

Це оцінювання призначене, щоб виявити:

### Фундаментальні прогалини
- Базові цикли взаємодії, які ви не пробували
- Важливі функції, які ви пропустили
- Хибні уявлення в ментальній моделі

### «Сліпі зони» ухвалення рішень
- Коли використовувати агентів, skills чи команди
- Яку подію hook використовувати для якої проблеми
- Вибір MCP-сервера під ваші потреби

### Готовність до продакшену
- Найкращі практики безпеки
- Патерни оптимізації продуктивності
- Масштабування систем із кількома агентами
- Конфігурація команди та керування

## Після оцінювання

### Негайні дії
1. **Перегляньте свій профіль** — зрозумійте поточний рівень володіння
2. **Визначте прогалини** — знайте точно, що вчити далі
3. **Отримайте шлях навчання** — персоналізована послідовність з урахуванням залежностей
4. **Практикуйтеся** — 3 цільові проєкти, що відповідають вашому рівню

### Рекомендовані подальші skills
- `/lesson-quiz [topic]` — перевірте себе з конкретних тем
- `/audit-agents-skills` — аудит якості вашої власної конфігурації
- `/claude-md` — керуйте конфігурацією вашого CLAUDE.md

### Інтеграція зі шляхом навчання

Після оцінювання skill `/lesson-quiz` забезпечує перевірку по модулях:
- Відповідайте на 5 питань на модуль
- Отримуйте миттєвий відгук щодо слабких місць
- Відкривайте наступний модуль, коли будете готові

---

## Оцінювання та профілі

### Junior-розробник (0-6 балів)
- Щойно встановив Claude Code
- Знає базові команди та робочі процеси
- Ще не торкався пам'яті/агентів/hooks
- **Наступний крок:** Core Concepts + модуль Memory

### Розробник середнього рівня (7-13 балів)
- Використовує Claude Code щодня
- Упевнено користується CLAUDE.md і базовими агентами
- Досліджує skills і команди
- Певне використання hooks, без MCP-серверів
- **Наступний крок:** Поглиблений MCP + Advanced Patterns

### Просунутий розробник (14-20 балів)
- Володіє оркестрацією кількох агентів
- Безпека та масштабування продакшен-рівня
- Власні skills і складні hooks
- Експертиза з MCP-серверів
- **Наступний крок:** навчання команди, патерни для підприємств

---

## Поради для кращих результатів

1. **Відповідайте чесно** — не вгадуйте, пропускайте невідомі питання
2. **Читайте пояснення** — кожне питання має посилання на посібник
3. **Поверніться перед підвищенням рівня** — пройдіть оцінювання знову після вивчення нових тем
4. **Діліться результатами** — використовуйте профіль для координації з командою
