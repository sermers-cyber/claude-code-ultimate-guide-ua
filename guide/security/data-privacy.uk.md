# Посібник із конфіденційності та зберігання даних

> [!IMPORTANT]
> Усе, чим ви ділитеся з Claude Code, надсилається на сервери Anthropic. Цей посібник пояснює, які саме дані залишають ваш комп'ютер і як захистити конфіденційну та чутливу інформацію.

## TL;DR - Підсумок зберігання даних

| Конфігурація | Термін зберігання | Навчання моделей | Як увімкнути |
|---------------|------------------|----------|---------------|
| **Споживча (за замовчуванням)** | 5 років | Так | (стан за замовчуванням) |
| **Споживча (з відмовою)** | 30 днів | Ні | [claude.ai/settings](https://claude.ai/settings/data-privacy-controls) |
| **Team / Enterprise / API** | 30 днів | Ні (за замовчуванням) | Використовуйте плани Team, Enterprise або API-ключі |
| **ZDR (Нульове зберігання)** | 0 днів на сервері | Ні | Належним чином налаштовані API-ключі |

**Негайна дія**: [Вимкніть використання даних для навчання моделей](https://claude.ai/settings/data-privacy-controls), щоб скоротити термін зберігання на серверах з 5 років до 30 днів.

## 1. Розуміння потоку даних

### Що залишає вашу машину

Коли ви використовуєте Claude Code, наступні дані надсилаються до Anthropic:

```
┌─────────────────────────────────────────────────────────────┐
│                    ВАШ ЛОКАЛЬНИЙ КОМП'ЮТЕР                  │
├─────────────────────────────────────────────────────────────┤
│  • Промпти, які ви вводите                                  │
│  • Файли, які читає Claude (і .env, якщо не виключені!)     │
│  • Результати MCP (SQL-запити, відповіді API)               │
│  • Результати виконання команд Bash                         │
│  • Повідомлення про помилки та стеки викликів               │
└───────────┬──────────────────┬──────────────┬───────────────┘
            │                  │              │
            ▼ HTTPS/TLS       ▼ HTTPS        ▼ HTTPS
┌───────────────────┐ ┌──────────────┐ ┌─────────────────────┐
│   API ANTHROPIC   │ │   STATSIG    │ │       SENTRY        │
├───────────────────┤ ├──────────────┤ ├─────────────────────┤
│ • Ваші промпти    │ │ • Затримка,  │ │ • Логи помилок      │
│ • Відповіді моделі│ │   надійність │ │ • Без коду й        │
│ • Термін зберіг.  │ │ • Без коду й │ │   шляхів            │
│   згідно тарифу   │ │   шляхів     │ │                     │
└───────────────────┘ └──────────────┘ └─────────────────────┘
                       (вимкнення:      (вимкнення:
                       DISABLE_         DISABLE_ERROR_
                       TELEMETRY=1)     REPORTING=1)
```

### Що це означає на практиці

| Сценарій | Дані, що надсилаються до Anthropic |
|----------|------------------------------------|
| Ви просите Claude прочитати `src/app.ts` | Повний вміст файлу |
| Ви запускаєте `git status` через Claude | Вивід команди |
| MCP виконує запит `SELECT * FROM users` | Результати запиту, включно з даними користувачів |
| Claude зчитує файл `.env` | API-ключі, паролі, секрети |
| У вашому коді виникає помилка | Повний стек викликів (stack trace) із шляхами |

## 2. Політики зберігання даних Anthropic

### Рівень 1: Споживчий за замовчуванням (Навчання увімкнено)

- **Термін зберігання**: 5 років
- **Використання**: Покращення моделей, дані для навчання ШІ
- **Застосовується до**: Планів Free, Pro, Max з увімкненим налаштуванням навчання моделей

### Рівень 2: Споживчий з відмовою (Навчання вимкнено)

- **Термін зберігання**: 30 днів
- **Використання**: Виключно моніторинг безпеки та запобігання зловживанням
- **Як увімкнути**:
  1. Перейдіть на сторінку https://claude.ai/settings/data-privacy-controls
  2. Вимкніть опцію "Allow model training on your conversations" (Дозволити навчання моделей на ваших діалогах)
  3. Зміни застосовуються миттєво

### Рівень 3: Комерційний (Team / Enterprise / API)

- **Термін зберігання**: 30 днів
- **Використання**: Виключно моніторинг безпеки та запобігання зловживанням
- **Навчання**: За замовчуванням дані не використовуються для навчання моделей (додаткова відмова не потрібна)
- **Застосовується до**: Планів Team, Enterprise, користувачів API, сторонніх інтегрованих платформ, Claude Gov

### Рівень 4: Нульове зберігання даних (Zero Data Retention — ZDR)

- **Термін зберігання**: 0 днів на стороні сервера (локальний кеш клієнта може зберігатися до 30 днів)
- **Використання**: Жодні дані не зберігаються на серверах Anthropic
- **Вимоги**: Належним чином налаштовані API-ключі (див. [документацію Anthropic](https://www.anthropic.com/enterprise))
- **Сценарії використання**: HIPAA (потребує окремої угоди BAA), GDPR, відповідність PCI-DSS, державні та оборонні контракти

> [!WARNING]
> Дані шифруються під час передачі через TLS, але **не шифруються у стані спокою (at rest)** на серверах Anthropic. Враховуйте це під час оцінки безпеки вашої інфраструктури.

## 3. Відомі ризики

### Ризик 1: Автоматичне читання файлів

Claude Code самостійно зчитує файли для розуміння контексту проєкту. За замовчуванням сюди можуть потрапити:

- Файли `.env` та `.env.local` (API-ключі, паролі)
- Файли `credentials.json`, `secrets.yaml` (облікові записи служб)
- Ключі SSH, якщо вони опинилися в межах робочої директорії
- Рядки підключення до баз даних

**Як запобігти**: Налаштуйте правила виключення (див. Розділ 4).

### Ризик 2: Доступ до бази даних через MCP

Коли ви налаштовуєте сервери MCP для доступу до баз даних (Neon, Supabase, PlanetScale):

```
Ваш запит: "Покажи мені останні замовлення"
            │
            ▼
MCP виконує: SELECT * FROM orders LIMIT 100
            │
            ▼
Надсилаються результати: 100 рядків із іменами клієнтів, адресами, поштою
            │
            ▼
Зберігається в Anthropic: Відповідно до вашого рівня зберігання даних
```

**Як запобігти**: Ніколи не підключайте продакшн-бази даних. Використовуйте локальні бази для розробки (dev/staging) зі знеособленими (анонімізованими) даними.

### Ризик 3: Вивід команд в терміналі

Виконувані команди Bash та весь їхній вивід автоматично додаються до вікна контексту:

```bash
# Цей вивід буде переданий до Anthropic:
$ env | grep API
OPENAI_API_KEY=sk-abc123...
STRIPE_SECRET_KEY=sk_live_...
```

**Як запобігти**: Використовуйте хуки безпеки для фільтрації конфіденційного виводу команд.

### Ризик 4: Команда `/bug` відправляє ВСЕ (зберігання 5 років)

Коли ви виконуєте команду `/bug` у Claude Code, вся **повна історія вашої поточної розмови** (включаючи весь код, вміст прочитаних файлів і потенційні секрети) надсилається до Anthropic для аналізу та виправлення помилок CLI. Ці дані зберігаються **5 років**, незалежно від вашої відмови від навчання моделей.

Це правило є незалежним від інших ваших налаштувань приватності: навіть за вимкненого навчання та 30-денного терміну зберігання, повідомлення про баги підпадають під власну 5-річну політику зберігання.

**Як запобігти**: Повністю вимкніть цю команду, якщо ви працюєте з чутливими або комерційними кодовими базами:

```bash
export DISABLE_BUG_COMMAND=1
```

Або додайте цей рядок до файлу конфігурації вашої оболонки (`~/.zshrc`, `~/.bashrc`), щоб зробити обмеження постійним.

### Ризик 6: Інтеграція Claude Desktop з браузером — Тихе встановлення Native Messaging Host

Додаток Claude Desktop встановлює маніфести нативного хоста обміну повідомленнями у системні директорії браузерів `NativeMessagingHosts`, щоб увімкнути функцію "Claude in Chrome". Станом на квітень 2026 року це відбувається без будь-якого явного запиту на згоду з боку користувача.

**Що саме встановлюється:**

```
~/Library/Application Support/Google/Chrome/NativeMessagingHosts/
  com.anthropic.claude_browser_extension.json

/Applications/Claude.app/Contents/MacOS/
  claude_browser_native_host  (допоміжний бінарний файл)
```

Claude Desktop записує ці файли для **всіх виявлених у системі Chromium-браузерів** — Chrome, Brave, Edge, Arc, Vivaldi, Opera, Chromium — включно з тими браузерами, які на момент встановлення Claude Desktop навіть не були запущені. Налаштування відмови від цієї функції ("Don't ask") у меню Claude Desktop не завжди запобігає цьому процесу ([GitHub #53864](https://github.com/anthropics/claude-code/issues/53864), квітень 2026).

**Що нативна інтеграція робить насправді (і чого НЕ робить):**

Нативна інтеграція (Native messaging) — це стандартний і безпечний механізм Chrome, який використовується менеджерами паролів, сервісами VPN та багатьма іншими легітимними додатками. Нативний хост може приймати повідомлення лише від того розширення Chrome, яке явно вказане як його ціль. Він не може самостійно ініціювати підключення до браузера, зчитувати вміст вкладок чи несанкціоновано збирати дані. З архітектурної точки зору це не є шпигунським ПЗ (spyware).

Справжня проблема полягає у **відсутності інформованої згоди**, а не в самому механізмі. Коли додаток тихо модифікує системні директорії стороннього софту, це порушує принцип найменшого подиву (least surprise), незалежно від намірів розробника.

**Як перевірити наявність нативних хостів, якщо ви занепокоєні:**

```bash
# Список усіх встановлених нативних хостів для Chrome
ls ~/Library/Application\ Support/Google/Chrome/NativeMessagingHosts/

# Перевірка наявності маніфесту Anthropic
cat ~/Library/Application\ Support/Google/Chrome/NativeMessagingHosts/com.anthropic.claude_browser_extension.json

# Перевірка для інших браузерів
ls ~/Library/Application\ Support/BraveSoftware/Brave-Browser/NativeMessagingHosts/
ls ~/Library/Application\ Support/Microsoft\ Edge/NativeMessagingHosts/
```

**Як видалити:**

```bash
# Видалення для Chrome (повторіть для кожного браузера за потреби)
rm ~/Library/Application\ Support/Google/Chrome/NativeMessagingHosts/com.anthropic.claude_browser_extension.json

# Перезапустіть Chrome після видалення
```

Видалення Claude Desktop вилучає допоміжний бінарний файл, але може залишити застарілі файли маніфестів у деяких директоріях браузерів. Перезапустіть браузери після очищення.

**Конфлікт із Claude Code CLI**: Коли у системі встановлені одночасно і Claude Desktop, і Claude Code CLI, розширення Chrome завжди намагається зв'язатися з нативним хостом Claude Desktop. Через це інструменти MCP `claude-in-chrome` для CLI-версії стають недоступними ([GitHub #51949](https://github.com/anthropics/claude-code/issues/51949)). Станом на квітень 2026 року це відомий баг, єдиним вирішенням якого є повне видалення Claude Desktop.

**Як діяти:**

Якщо ви не використовуєте функцію інтеграції з браузером, ви можете безпечно видалити файли маніфестів. Anthropic поки не надав офіційного та надійного механізму відмови від встановлення цієї інтеграції. Слідкуйте за оновленнями у гілці [GitHub #53864](https://github.com/anthropics/claude-code/issues/53864).

## 4. Захисні заходи

### Негайні дії

#### 4.1 Відмова від навчання моделей

1. Перейдіть на сторінку https://claude.ai/settings/data-privacy-controls
2. Переведіть перемикач "Allow model training" у стан **ВИМКНЕНО (OFF)**
3. Термін зберігання ваших даних скоротиться з 5 років до 30 днів

#### 4.2 Налаштування блокування файлів

У `.claude/settings.json` використовуйте розділ `permissions.deny` для обмеження доступу до конфіденційних файлів:

```json
{
  "permissions": {
    "deny": [
      "Read(./.env*)",
      "Edit(./.env*)",
      "Write(./.env*)",
      "Bash(cat .env*)",
      "Bash(head .env*)",
      "Read(./secrets/**)",
      "Read(./**/credentials*)",
      "Read(./**/*.pem)",
      "Read(./**/*.key)",
      "Read(./**/service-account*.json)"
    ]
  }
}
```

> [!NOTE]
> Застарілі параметри `excludePatterns` та `ignorePatterns` були повністю скасовані у жовтні 2025 року. Завжди використовуйте `permissions.deny`.

> [!WARNING]
> Механізм `permissions.deny` має [відомі технічні обмеження](./security-hardening.uk.md#known-limitations-of-permissionsdeny). Для надійного захисту комбінуйте його з безпековими хуками (hooks) та зовнішнім керуванням секретами.

#### 4.3 Використання хуків безпеки

Створіть файл `.claude/hooks/PreToolUse.sh`:

```bash
#!/bin/bash
INPUT=$(cat)
TOOL_NAME=$(echo "$INPUT" | jq -r '.tool.name')

if [[ "$TOOL_NAME" == "Read" ]]; then
    FILE_PATH=$(echo "$INPUT" | jq -r '.tool.input.file_path')

    # Блокування читання файлів із секретами
    if [[ "$FILE_PATH" =~ \.env|credentials|secrets|\.pem|\.key ]]; then
        echo "BLOCKED: Спроба читання конфіденційного файлу: $FILE_PATH" >&2
        exit 2  # Блокування операції
    fi
fi
```

#### 4.4 Відмова від телеметрії та звітів про помилки

Claude Code зв'язується із зовнішніми сервісами для збору метрик роботи (Statsig) та відстеження помилок (Sentry). Вони не передають ваш код чи шляхи до файлів, але ви можете повністю вимкнути будь-яку мережеву активність такого роду:

| Змінна середовища | Що вона вимикає |
|----------|-----------------|
| `DISABLE_TELEMETRY=1` | Збір оперативних метрик Statsig (затримки, надійність роботи, патерни використання) |
| `DISABLE_ERROR_REPORTING=1` | Надсилання звітів про помилки до Sentry |
| `DISABLE_BUG_COMMAND=1` | Команду `/bug` (запобігає випадковому відправленню повної історії сесії) |
| `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` | Увесь другорядний мережевий трафік одночасно |
| `CLAUDE_CODE_DISABLE_FEEDBACK_SURVEY=1` | Опитування про якість сесії (вони відправляють лише оцінку, але не історію) |

Додайте ці змінні до конфігурації вашої оболонки для постійного ефекту:

```bash
# У ~/.zshrc або ~/.bashrc
export DISABLE_TELEMETRY=1
export DISABLE_ERROR_REPORTING=1
export DISABLE_BUG_COMMAND=1
```

> [!NOTE]
> Під час використання провайдерів Bedrock, Vertex або Foundry увесь другорядний трафік (телеметрія, звіти Sentry, опитування, команда /bug) вимкнений за замовчуванням на рівні платформи.

### Кращі практики для роботи з MCP

| Правило | Обґрунтування |
|------|-----------|
| **Ніколи не підключайте реальні бази (production)** | Усі результати запитів передаються на сервери Anthropic |
| **Використовуйте користувачів із правами Read-only** | Захищає від випадкових або зловмисних `DROP`/`DELETE`/`UPDATE` |
| **Деперсоналізуйте (анонімізуйте) дані для розробки** | Мінімізує ризики витоку персональних даних (PII) |
| **Створюйте мінімальні тестові вибірки даних** | Менше даних у базі = менший ризик компрометації |
| **Ретельно перевіряйте джерела серверів MCP** | Сторонні сервери MCP можуть містити критичні вразливості |

### Поради для команд

| Середовище | Рекомендація |
|-------------|----------------|
| **Розробка (Development)** | Відмова від навчання + блокування файлів + анонімізовані дані |
| **Тестування (Staging)** | Розгляньте плани Enterprise API, якщо працюєте з реальними даними |
| **Продакшн (Production)** | НІКОЛИ не підключайте Claude Code безпосередньо |

## 5. Порівняння з іншими інструментами

| Функція | Claude Code + MCP | Cursor | GitHub Copilot |
|---------|-------------------|--------|----------------|
| Обсяг даних, що передається | Повні результати SQL-запитів, файли | Фрагменти коду | Фрагменти коду |
| Доступ до прод-баз | Так (через сервери MCP) | Обмежений | Не передбачений архітектурно |
| Зберігання за замовчуванням | 5 років | Змінне | 30 днів |
| Навчання за замовчуванням | Так | Лише за згодою (Opt-in) | Лише за згодою (Opt-in) |

**Головна відмінність**: Використання протоколу MCP створює унікальний вектор атак, оскільки сервери MCP працюють як окремі процеси з власним доступом до мережі та файлової системи.

## 6. Корпоративні аспекти

### Коли слід переходити на Enterprise API (ZDR)

## 9. Управління та цінності Anthropic

### Фреймворк конституційного ШІ (Constitutional AI)

У січні 2026 року компанія Anthropic опублікувала "Конституцію" Claude під ліцензією CC0 (суспільне надбання). Цей документ встановлює чітку ієрархію цінностей, яка визначає поведінку Claude:

**Пріоритетність цінностей** (використовується для вирішення конфліктів):

1. **Загальна безпека (Broadly safe)** - Ніколи не компрометувати людський контроль та нагляд
2. **Загальна етика (Broadly ethical)** - Чесність, уникнення нанесення шкоди, гідна поведінка
3. **Дотримання правил Anthropic (Anthropic compliance)** - Внутрішні інструкції та корпоративні політики
4. **Справжня корисність (Genuinely helpful)** - Реальна цінність для користувача та суспільства

### Що це означає для користувачів Claude Code

| Сценарій | Очікувана поведінка Claude |
|----------|-------------------|
| Запити, пов'язані з безпекою | Claude ставить безпеку вище за корисність (може поводитися консервативно і відмовляти) |
| Граничні питання біології/хімії | Може відхилити запит або вимагати додаткового невинного контексту |
| Етичні дилеми | Буде суворо слідувати ієрархії: безпека > етика > комплаєнс > корисність |

### Чому це важливо

- **Джерело навчальних даних**: Конституція використовується для генерації синтетичних прикладів під час навчання моделі (RLAIF).
- **Специфікація поведінки**: Еталонний документ, що пояснює очікувані дії та причини відмов моделі.
- **Аудит та комплаєнс**: Забезпечує етичну основу для проведення перевірок відповідності.
- **Ваші власні агенти**: Ліцензія CC0 дозволяє вам вільно брати Конституцію Anthropic як базу для налаштування власних систем ШІ.
