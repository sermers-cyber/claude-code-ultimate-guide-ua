# Переклади та мовне врядування

Англійська є канонічною мовою Claude Code Ultimate Guide. Французький повний посібник — єдиний переклад, який підтримує сам проєкт. Репозиторії китайською, українською та іспанською (Латинська Америка), перелічені тут, — це незалежні спільнотні адаптації. Вони не є офіційними виданнями проєкту й не підтримуються Anthropic.

Машинозчитуваним джерелом істини є [`machine-readable/translations.json`](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/machine-readable/translations.json). Його офлайн-валідатор перевіряє записані версії, хеші джерел, коміти джерел, відставання за Git і метадані парних публікацій:

```bash
python3 scripts/check-translations.py --check
```

Ця команда перевіряє докази в реєстрі. Вона не оцінює якість перекладу й не оновлює віддалені репозиторії.

## Перевірений перелік

Англійський і французький повні посібники, які підтримуються проєктом, було переглянуто **2026-09-26** у версії **3.43.0**. Оновлення французької версії узгодило зміни джерела з 3.41.1 та виправило давніші пропуски й блоки коду. Записаний хеш її джерела збігається з англійським посібником у записаному коміті. Пізніші зміни в англійській версії роблять французький повний посібник **застарілим щодо поточного канонічного джерела** станом на 2026-10-01. Це був огляд Codex, а не редакторське схвалення людиною; див. [запис огляду](../../docs/audits/2026-09-26-bilingual-publications.uk.md).

Спільнотні репозиторії востаннє перевіряли **2026-08-31**. Їхній поточний віддалений стан у цьому оновленні публікації повторно не перевірявся. [Реєстр](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/machine-readable/translations.json) зберігає для кожного супровідника, коміт джерела або `UNKNOWN`, спостереження щодо охоплення, дату перевірки та виміряне відставання. Пізніша зміна в англійській версії скасовує актуальність підтримуваного перекладу, доки її не переглянуть і не запишуть.

Кількість символів з аудиту спільноти — це індикатори мови, а не семантичні оцінки охоплення. Файл може містити перекладені слова, але зберігати англійські уривки, а файлам лише з кодом не потрібні символи цільової мови.

Усі 13 англійсько-французьких пар джерел whitepaper і 58 пар recap-карток тепер є в репозиторії разом з обома щоденними шпаргалками та обгорткою експорту французького повного посібника. Друкарський огляд охоплює команди, конфігурацію, моделі, безпеку й приватність у цих адаптаціях. Вони підсумовують теми й не є рядок-у-рядок перекладами повного посібника. Завершення збірки та перевірка публічних завантажень записуються окремо в аудиті публікації.

## Китайська атрибуція та виправлення джерела

README китайського репозиторію прямо називає роботу китайським перекладом, віддає належне Florian Bruniaux, посилається на оригінальний репозиторій і зберігає ліцензію CC BY-SA 4.0. Отже, атрибуція присутня.

Його файл `TRANSLATION_STATUS` позначає `dbeb30c` як коміт upstream. Історія Git показує, що `dbeb30c` — це перший коміт із перекладом README китайською в спільнотному репозиторії. Батьківський коміт `7b43b9c10b241f8e196e27651e3fea6079a48d26` є відповідною англійською базою джерела. Реєстр фіксує батьківський коміт і зберігає цю примітку-доказ, щоб неправильну мітку не повторювали як факт.

Атрибуція й актуальність — окремі питання. Правильна атрибуція не робить видання офіційним чи актуальним.

## Пріоритет офіційних перекладів

Наступна інвестиція в переклади — це підтримка французької версії, а не офіційне китайське видання. Перш ніж стартує ще одна офіційна локалізація, французький повний посібник має пройти обидва бар'єри:

1. Записана версія джерела й SHA-256 мають збігатися з англійським канонічним посібником.
2. Задокументований огляд має охоплювати навігацію, приклади, посилання, термінологію та видимі неперекладені розділи.

Запускайте суворий бар'єр, плануючи реліз або нову офіційну локалізацію:

```bash
python3 scripts/check-translations.py --check --require-current-maintained
```

Збірка релізу запускає цей суворий бар'єр перед рендерингом французького повного посібника. Нова зміна англійського джерела має бути переглянута у французькій версії, перш ніж бар'єр знову пройде.

## Мітки «офіційний» і «спільнотний»

У цьому реєстрі `official` означає «підтримується цим проєктом посібника». Це ніколи не означає офіційну документацію Anthropic. Спільнотна адаптація залишається `community`, доки її супровідника, процес огляду, базу джерела, процес релізу та поточну відповідальність явно не передано й не прийнято.

Посилання на спільнотні видання мають показувати цільову мову, незалежного супровідника, неофіційний статус, дату останньої перевірки, версію, коміт джерела або `UNKNOWN`, межу охоплення та відоме відставання.

## Мовна навігація та SEO

Читачі можуть користуватися звичайними посиланнями між цією сторінкою, англійським канонічним посібником, французьким файлом, що підтримується проєктом, і спільнотними репозиторіями. Сайт не публікує `hreflang` для спільнотних адаптацій, бо вони міждоменні, не доведено, що сторінки еквівалентні, вони не синхронізовані й не мають перевірених взаємних анотацій.

Кожна локально розміщена сторінка зберігає самопосилальний канонічний URL. Додавайте `hreflang` лише тоді, коли існують еквівалентні індексовані сторінки, перевірено взаємні посилання, а для пари локалей скоординовано супровід. Не використовуйте `x-default` замість такого доказу.

XML-карта сайту лендингу має містити локальну сторінку стану перекладів після розгортання. URL спільнотних репозиторіїв не належать до локальної карти сайту.

## Межа доказів

Пошук у публічних репозиторіях охоплював назви репозиторіїв GitHub і атрибуцію в README, після чого було досліджено знайдені репозиторії. Він виявив три спільнотні адаптації, наведені вище. Приватні, перейменовані, неіндексовані та не розміщені на GitHub переклади лишаються поза виміряним обсягом.

Дата останньої перевірки — це не твердження про синхронізацію. Стан віддалених репозиторіїв і спостереження щодо охоплення можуть змінитися після знімка. Перш ніж оновлювати їх, дотримуйтеся процесу оновлення з [`docs/workflows/translations.md`](../../docs/workflows/translations.uk.md).
