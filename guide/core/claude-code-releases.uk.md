### v2.1.129 (2026-05-06)

> Прапорець --plugin-url, CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE, відновлення історії Ctrl+R, виправлення skillOverrides, понад 20 виправлень помилок.

- **Нове**: Прапорець `--plugin-url <url>` для завантаження `.zip` архіву плагіна за URL для поточної сесії.
- **Нове**: Змінна оточення `CLAUDE_CODE_FORCE_SYNC_OUTPUT=1` для примусового ввімкнення синхронізованого виводу в терміналах, де автовизначення не працює (наприклад, Emacs `eat`).
- **Нове**: `CLAUDE_CODE_PACKAGE_MANAGER_AUTO_UPDATE`: якщо встановлено, інсталяції Homebrew або WinGet запускають команду оновлення у фоновому режимі та пропонують перезапуск.
- **Змінено**: Оголошення `themes` та `monitors` у маніфесті плагіна тепер мають бути у `"experimental": { ... }` — верхній рівень все ще працює, але `claude plugin validate` видаватиме попередження.
- **Змінено**: Gateway-виявлення моделей через `/v1/models` тепер є опціональним та вмикається через `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` (було автоматичним у версіях 2.1.126–2.1.128).
- **Покращено**: Вибір історії Ctrl+R знову за замовчуванням показує всі проекти (поведінка до v2.1.124) — натисніть Ctrl+S, щоб звузити до поточного проекту або сесії.
- **Покращено**: Сторонні розгортання (Bedrock, Vertex, Foundry, шлюз `ANTHROPIC_BASE_URL`) більше не бачать підказок спіннера, що вказують на власні ресурси Anthropic.
- **Виправлено**: Налаштування `skillOverrides` тепер працює: `off` приховує від моделі та `/`, `user-invocable-only` приховує лише від моделі, `name-only` згортає опис.
- **Виправлено**: Метрика OpenTelemetry `claude_code.pull_request.count` тепер враховує PR/MR, створені через інструменти MCP (а не лише через консольні команди).
- **Виправлено**: Повідомлення про відмову через політику тепер містять API Request ID для спрощення діагностики.
- **Виправлено**: Помилки API з нерозпізнаними кодами 400 тепер відображають оригінальне повідомлення про помилку замість сирого JSON.
- **Виправлено**: Команда `/clear` не скидала назву вкладки терміналу після завершення розмови.
- **Виправлено**: Плашка назви сесії з команди `/rename` зникала, коли було активне діалогове вікно дозволу чи інше вікно.
- **Виправлено**: Панель агента під промптом приховувалася під час роботи субагентів (регресія у версії 2.1.122).
- **Виправлено**: Передача в зовнішній редактор (Ctrl+G) очищала історію розмови над промптом.
- **Виправлено**: Команда `/context` виводила свою ASCII-сітку візуалізації в розмову (близько 1.6k марно витрачених токенів на виклик).
- **Виправлено**: Навігація стрілками в списку бібліотеки `/agents` — виділений агент залишається видимим, коли список перевищує розмір екрана.
- **Виправлено**: Повідомлення про успіх `/branch` не містило ID сесії нової гілки для команди `/resume`.
- **Виправлено**: Жирні заголовки з emoji втрачали кінцеві символи у повноекранному режимі.
- **Виправлено**: Політика налаштувань, що керується сервером, не застосовувалася для корпоративних користувачів, якщо збережені облікові дані OAuth не мали області `user:inference`.
- **Виправлено**: Стан гонитви при оновленні OAuth після виходу комп'ютера з режиму сну, що міг розлогінити всі активні сесії.
- **Виправлено**: 1-годинний TTL кешу промптів мовчки знижувався до 5 хвилин.
- **Виправлено**: Попередження про промах кешу з'являлося помилково після `/clear` або стиснення при зміні `/effort` чи `/model`.
- **Виправлено**: Правила дозволів `Bash(mkdir *)`, `Bash(touch *)` та подібні не враховувалися для шляхів всередині проекту.
- **Виправлено**: Шаблони `deniedMcpServers` зі схемою `*://` не збігалися з іменами хостів у різному регістрі.
- **Виправлено**: Нешкідливе попередження WebSocket логувалося як помилка в `--debug` під час голосового режиму.
- **Виправлено**: [VSCode] Команда `/clear` не очищала контекст розмови та відображуваний транскрипт.

### v2.1.128 (2026-05-05)

> Розгалуження EnterWorktree з локального HEAD, підтримка .zip для --plugin-dir, консольна авторизація --channels, кількість інструментів /mcp, виправлення паралельних викликів bash, виправлення кешу промптів субагентів, понад 35 виправлень помилок.

- **Виправлено**: `EnterWorktree` тепер створює нову гілку з локального `HEAD`, як і задокументовано — невідправлені коміти більше не втрачаються при розгалуженні.
- **Нове**: Параметр `--plugin-dir` тепер приймає `.zip` архіви плагінів нарівні з директоріями.
- **Нове**: Параметр `--channels` тепер працює з консольною авторизацією (через API-ключ) — керовані організації повинні встановити `channelsEnabled: true` у керованих налаштуваннях.
- **Покращено**: `/mcp` показує кількість інструментів для кожного підключеного сервера та виділяє сервери, які підключилися з 0 інструментів.
- **Покращено**: Повторне підключення MCP-серверів більше не забиває розмову повними списками інструментів — повторно оголошені інструменти групуються за префіксом сервера.
- **Покращено**: SDK-хости отримують стійку рекомендацію `localSettings` для запитів дозволів Bash, тому вибір "Завжди дозволяти" записується в `.claude/settings.local.json`.
- **Покращено**: Виклик `/color` без аргументів тепер обирає випадковий колір сесії.
- **Покращено**: Вибір `/model` групує дубльовані записи Opus 4.7; поточний Opus відображається просто як "Opus" замість "Opus 4.7".
