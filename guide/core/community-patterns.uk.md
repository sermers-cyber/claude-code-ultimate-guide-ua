# Патерни спільноти та довідник

Короткий довідник із патернів спільноти Claude Code, термінів робочих процесів і словника ШІ-інженерії. Стандартні терміни CS/DevOps (JWT, CI/CD, REST) сюди не входять; шукайте їх в інших джерелах.

**Формат**: Термін | Визначення | Категорія | Підкатегорія

---

| Термін | Визначення | Категорія | Підкатегорія |
|------|-----------|----------|-------------|
| ! (префікс shell) | Префікс для запуску shell-команд безпосередньо, без участі Claude, наприклад, `! git status`. Вивід потрапляє в розмову. | Claude Code | Взаємодія |
| @ (посилання на файл) | Синтаксис для посилання на конкретні файли в prompt, наприклад, `@src/auth.tsx`. Claude негайно завантажує цей файл у контекст. | Claude Code | Взаємодія |
| Папка .claude/ | Директорія рівня проєкту, що містить agents, skills, команди, hooks, правила та налаштування. `settings.local.json` за домовленістю додається до gitignore. | Claude Code | Конфігурація |

| /clear | Slash-команда, що повністю скидає сесію, відкидаючи всю історію розмови. Контекст падає до 0%. | Claude Code | Команди |
| /compact | Slash-команда, що стискає контекст розмови, підсумовуючи попередні обміни, і звільняє запас контексту без втрати стану. | Claude Code | Команди |
| Стеля 150K | Практичний ефективний ліміт контексту, за яким якість виводу падає, навіть якщо номінальне вікно більше. Див. [context-engineering.md](./context-engineering.uk.md). | Архітектура | Контекст |

| Native sandbox | Вбудована ізоляція Claude Code на рівні ОС: Seatbelt на macOS, bubblewrap на Linux. Обмежує доступ до файлової системи та мережі. | Безпека | Sandbox |

| Prompt injection | Атака, де зловмисний текст у файлах чи зовнішніх вхідних даних намагається перевизначити інструкції Claude або викрасти інформацію. | Безпека | Атака |

| Semantic anchors | Назви усталених методів чи патернів, що використовуються в prompt як стислі посилання, з інструкціями та перевірками для конкретного завдання. | ШІ-інженерія | Контекст |

| Skill | Повторно використовуваний модуль знань (папка + точка входу SKILL.md), що надає за потреби експертизу в галузі або поведінкові інструкції. | Claude Code | Розширюваність |

| Skills 2.0 | Еволюція системи skills, що запроваджує типи Capability Uplift, типи Encoded Preference, evals і керування життєвим циклом. | Claude Code | Skills |
| Slash command | Власні команди, визначені як markdown-файли в `.claude/commands/`, що викликаються через `/command-name`. Підтримують підстановку `$ARGUMENTS`. | Claude Code | Розширюваність |
