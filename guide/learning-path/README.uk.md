# Claude Code Learning Path

**Опануйте Claude Code за 8-11 годин. Заглиблюйтеся в те, що важливо для вас, за допомогою додаткових детальних розборів (deep dives).**

Це ваша структурована точка входу. Проходьте модулі по порядку, а потім переходьте до повного посібника для детального вивчення.

---

## The 7-Module Path

| Модуль | Час | Фокус | Складність |
|--------|-----|-------|------------|
| **[01-Installation & Setup](01-installation.uk.md)** | 15 хв | Запуск Claude Code | ⭐ Beginner |
| **[02-Core Loop](02-core-loop.uk.md)** | 45 хв | Як насправді працює Claude Code | ⭐ Beginner |
| **[03-Memory & Config](03-memory.uk.md)** | 1 година | CLAUDE.md та settings | ⭐⭐ Intermediate |
| **[04-Agents & Specialization](04-agents.uk.md)** | 1.5 години | Створення спеціалізованих agents | ⭐⭐ Intermediate |
| **[05-Skills & Automation](05-skills.uk.md)** | 1.5 години | Reusable capabilities | ⭐⭐ Intermediate |
| **[06-Hooks & Events](06-hooks.uk.md)** | 1 година | Тригери для автоматизації | ⭐⭐ Intermediate |
| **[07-Advanced Patterns](07-advanced.uk.md)** | 2-3 години | Multi-agent orchestration | ⭐⭐⭐ Advanced |

**Разом: 8-11 годин базового навчання** + додаткові глибокі занурення.

## Як використовувати цей шлях

### Крок 1: Оцініть свій рівень

**Beginner** (день 1 із Claude Code):
- Пройдіть швидкий шлях: 01 → 02 → 03 (2 години)
- Потім переходьте до повного посібника `Part 1: Quick Start`

**Intermediate** (використовуєте Claude Code 1-4 тижні):
- Пройдіть повний шлях: 01 → 07 (8-11 годин)
- Зосередьтеся на модулях 04, 05, 06, 07 для глибини

**Advanced** (використовуєте Claude Code 1+ місяців):
- Швидко перегляньте 01-03, глибоко зануртеся в 04-07
- Перейдіть до розділу посібника Part 9: Advanced Patterns для orchestration

### Крок 2: Оберіть свій трек

**Трек A: Опанування основ** (11 годин)
- Проходьте модулі з 01 по 07 по порядку
- Виконуйте всі вправи
- Запускайте `/lesson-quiz [topic]` після кожного модуля
- Завершіть за допомогою `/self-assessment comprehensive`

**Трек B: Глибоке занурення у конкретні навички** (4-6 годин)
- Модулі 01-02 (основи)
- Перейдіть одразу до модуля 04, 05 або 06 залежно від вашої мети
- Глибоко вивчіть обраний модуль
- За потреби переходьте до advanced patterns

**Трек C: Впровадження в команді** (5-7 годин)
- Модулі 01-02 (навчання основ)
- Модуль 03 (командна конфігурація)
- Модулі 04-07 (командні workflows)
- Запустіть `/self-assessment` для всієї команди, виявіть прогалини
- Створіть план подальшого навчання на основі виявлених прогалин

### Крок 3: Навчання та валідація

Кожен модуль містить:
- 📖 **Читання** (10-30 хв): концепції та ментальні моделі
- 🔨 **Практична робота** (20-45 хв): реальні приклади з `examples/`
- 📝 **Валідація**: `/lesson-quiz [topic]` для перевірки розуміння

### Крок 4: Заглиблення

Після цього шляху у вас є варіанти:

**Варіант A: Глибокий довідник**
→ Перейдіть до відповідного розділу в `guide/ultimate-guide.md`

**Варіант B: Опанування домену**
→ Читайте спеціалізовані посібники (наприклад, `guide/security/`, `guide/ops/`)

**Варіант C: Розробка з плагінами**
→ Встановіть набір плагінів з `examples/plugins/`

**Варіант D: Самооцінка**
→ Запустіть `/self-assessment comprehensive`, щоб виявити прогалини, що залишилися

### Крок 5: Зберігайте прогрес у проєкті

[Встановлюваний skill learning-path](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/examples/skills/learning-path/SKILL.md) перетворює сім модулів на локальну послідовність навчання. Він обирає лише ті модулі, чиї передумови виконано, вимагає непорожню нотатку-підтвердження (evidence) і записує стан у `.claude/learning/claude-code-guide-progress.json` у проєкті того, хто навчається.

Використовуйте цей skill, коли шлях читання охоплює кілька сесій або коли хтось інший має перевірити, що вже пройдено. Графік повторень: 1, 3, 7, 14, 30, 60 і 90 днів. Ці інтервали є політикою проєкту, а не твердженням, що один графік оптимальний для кожного, хто навчається.

[Супровідний проєкт Proofpack](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/examples/learning-project/README.md) проводить одну задачу (issue) через конфігурацію, реалізацію, тести, захищену перевірку релізу, перегляд доказів, пакування та необов'язкову межу Docker. Використовуйте його, коли потрібна одна наскрізна вправа на всі сім модулів.

[Слайди шляху навчання](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/docs/distribution/claude-code-learning-path-slides.pptx) дають коротку версію для воркшопу. [Брифи для відеовиробництва](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/docs/distribution/quick-win-video-series.md) пов'язують окремі вправи зі спостережуваними перевірками.

## Деталі модулів

### Модуль 01: Installation & Setup (15 хв)
**Мета:** Запустити Claude Code та переконатися, що він працює

- Встановлення для вашої платформи (macOS/Linux/Windows)
- Запуск першої команди
- Розуміння циклу prompt → output
- **Вправа:** Виконайте workflow "Перші 5 хвилин"

**Складність:** ⭐ (Beginner)
**Читати:** [Модуль 01: Installation & setup](01-installation.uk.md)
**Потім:** Part 1: Quick Start у головному посібнику

---

### Модуль 02: Core Loop (45 хв)
**Мета:** Зрозуміти, як Claude Code працює на системному рівні

- Цикл взаємодії (prompt → tool → decision → feedback)
- Context та sessions
- Plans та thinking modes
- **Вправа:** Використайте `/plan` для планування реального task, спостерігайте за процесом

**Складність:** ⭐ (Beginner)
**Читати:** [Модуль 02: Core loop](02-core-loop.uk.md)
**Потім:** Part 2: Core Concepts у головному посібнику

---

### Модуль 03: Memory & Config (1 година)
**Мета:** Налаштувати Claude Code під свій workflow

- Структура та ієрархія CLAUDE.md
- Пріоритет settings (global → project → session)
- Environment variables
- **Вправа:** Створіть свій перший CLAUDE.md, налаштуйте settings

**Складність:** ⭐⭐ (Intermediate)
**Читати:** [Модуль 03: Memory & config](03-memory.uk.md)
**Потім:** Part 3: Memory & Settings у головному посібнику

---

### Модуль 04: Agents & Specialization (1.5 години)
**Мета:** Створити спеціалізовані agents для конкретних завдань

- Коли використовувати agents замість однієї session
- Обмеження та ізоляція tools
- Створення agents (формат AGENT.md)
- **Вправа:** Створіть 2 agents (загальний + спеціалізований), протестуйте їх

**Складність:** ⭐⭐ (Intermediate)
**Читати:** [Модуль 04: Agents & Specialization](04-agents.uk.md)
**Потім:** Part 4: Agents у головному посібнику

---

### Модуль 05: Skills & Automation (1.5 години)
**Мета:** Створити reusable capabilities, які запускаються автоматично

- Життєвий цикл skill та frontmatter
- Шаблони автоматичного виклику (auto-invocation)
- Об'єднання скриптів зі skills
- **Вправа:** Створіть skill, який вирішує повторювану проблему

**Складність:** ⭐⭐ (Intermediate)
**Читати:** [Модуль 05: Skills & Automation](05-skills.uk.md)
**Потім:** Part 5: Skills у головному посібнику

---

### Модуль 06: Hooks & Events (1 година)
**Мета:** Автоматизувати реагування на системні події

- Події hook та їх відповідність (matching)
- Pre-validation проти post-execution
- Написання безпечних hooks
- **Вправа:** Додайте й протестуйте один вузький hook валідації `PreToolUse`

**Складність:** ⭐⭐ (Intermediate)
**Читати:** [Модуль 06: Hooks and events](06-hooks.uk.md)
**Потім:** Part 7: Hooks у головному посібнику

---

### Модуль 07: Advanced Patterns (2-3 години)
**Мета:** Оркеструвати multi-agent workflows

- Multi-agent команди та залежності
- Шаблони оркестрації
- Обробка помилок та відновлення
- **Вправа:** Спроектуйте workflow з 3 agents для реалістичного сценарію

**Складність:** ⭐⭐⭐ (Advanced)
**Читати:** [Модуль 07: Advanced Patterns](07-advanced.uk.md)
**Потім:** Part 9: Advanced Patterns у головному посібнику

## Оцінка часу

**Для різних цілей:**

- **Лише початок роботи:** 2 години (лише модулі 01-02)
- **Щоденне використання:** 6 годин (модулі 01-05)
- **Впровадження в команді:** 8-11 годин (модулі 01-07)
- **Глибоке освоєння:** 15-20 годин (шлях + детальні розбори посібника)
- **Спеціалізація:** 20-30+ годин (шлях + експертиза в конкретному домені)

## Що ви зможете робити

Після завершення цього навчання ви зможете:

✓ Навігувати в Claude Code без документації
✓ Створювати власні agents та skills під свій workflow

✓ Будувати multi-agent orchestration
✓ Автоматизувати рутинні завдання за допомогою hooks
✓ Знати, куди звертатися для поглиблення експертизи
