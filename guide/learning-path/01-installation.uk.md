# Module 01: Installation & setup

**Час**: 15 хвилин | **Складність**: ⭐ Beginner

## Мета

Встановити та запустити Claude Code у вашій системі. Перевірити його роботу за допомогою першої команди.

---

## Що ви дізнаєтеся

- Як встановити Claude Code для вашої платформи (macOS / Linux / Windows)
- Зрозуміти базовий цикл prompt → response
- Запустити свою першу команду
- Отримати доступ до довідкової системи

---

## Встановлення

### macOS (Рекомендовано)

```bash
brew install anthropic/tap/claude-code
```

Перевірка:
```bash
claude --version
```

### Linux

```bash
curl -sSL https://dl.claudecode.com/install.sh | bash
```

Перевірка:
```bash
claude --version
```

### Windows

Завантажте інсталятор з https://dl.claudecode.com/windows або виконайте:

```powershell
iex ((New-Object System.Net.WebClient).DownloadString('https://dl.claudecode.com/install.ps1'))
```

### Docker (Будь-яка платформа)

```bash
docker run -it anthropic/claude-code:latest
```

## Перший запуск

Перейдіть до будь-якої директорії проєкту та запустіть Claude:

```bash
cd ~/my-project
claude
```

Ви побачите:

```
Claude Code v2.x.x ready
Project: ~/my-project (git: main)
Context: 0% · Tokens available: 200,000

Type /help for commands or ask me anything
>
```

---

## Основні команди

| Команда | Призначення |
|---------|-------------|
| `/help` | Показати всі доступні команди |
| `/status` | Перевірити використання context та стан session |
| `/clear` | Почати заново (очистити історію розмови) |
| `Ctrl+C` | Скасувати поточну операцію |
| `/exit` | Закрити Claude Code |

---

## Ваші перші 5 хвилин

### Вправа 1: Перегляд доступних команд
```bash
/help
```

Перегляньте список команд. Зверніть увагу на:
- **Workflow**: `/plan`, `/rewind`, `/think`
- **Navigation**: `/goto`, `/read`
- **Memory**: завантаження memory під час запуску
- **Advanced**: `/model`, `/mode`

### Вправа 2: Перевірка стану сесії
```bash
/status
```

Ви побачите:
- Відсоток використання context
- Доступні tokens
- Поточний проєкт
- Гілку git

### Вправа 3: Запитайте Claude про щось

```
What files are in my project?
```

Claude прочитає структуру проєкту та відповість. Це ядро циклу (core loop):

```
Ваш prompt → Claude читає файли → Claude пропонує зміни → Ви переглядаєте → Застосувати
```

### Вправа 4: Перегляд запропонованої зміни

Якщо Claude пропонує зміни у коді, ви побачите:
1. Опис зміни
2. Вікно перегляду `diff` (що додається/видаляється)
3. Запит на підтвердження або відхилення

**Правило**: Завжди перевіряйте diff перед підтвердженням. Це захистить вас від неочікуваних змін.

## Головна концепція: Цикл (The Loop)

Кожна взаємодія відбувається за такою схемою:

```
┌──────────────────┐
│ Ви запитуєте     │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Claude           │
│ читає файли      │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Claude           │
│ пропонує         │
│ зміни            │
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Ви переглядаєте  │
│ diff та схвалюєте│
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│ Зміни застосовано│
│ до ваших файлів  │
└──────────────────┘
```

## Ключові концепції

### Sessions

Кожного разу, коли ви запускаєте `claude`, ви починаєте нову **session**. Session — це розмова з Claude, яка триває, поки ви використовуєте Claude Code.

- Sessions **не зберігаються** за замовчуванням (вони завершуються, коли ви виходите)
- Sessions **обмежені одним проєктом** одночасно
- Ваш context зростає в міру того, як ви ставите більше запитань (макс. ~200K tokens)

### Context

**Context** — це обсяг розмови, який пам'ятає Claude. Він відображається у відсотках (0-100%).

- 0-50%: Достатньо місця, працюйте вільно
- 50-70%: Будьте вибірковими, `/compact` за бажанням
- 70%+: Запустіть `/compact`, щоб звільнити місце
- 90%+: Вас змусять зробити очищення

### Git awareness

Claude Code інтегрований з **git**. Він:
- Визначає вашу поточну гілку
- Показує незбережені (uncommitted) зміни
- Допомагає зі створення commits та reviews
- Запобігає випадковим критичним змінам

## Усунення несправностей

### "claude: command not found"
Встановлення не завершилося. Спробуйте:
- **macOS**: Запустіть знову `brew install anthropic/tap/claude-code`
- **Linux**: Запустіть інсталяційний скрипт повторно
- **Windows**: Завантажте інсталятор з https://dl.claudecode.com/windows

### "Project not found"
Переконайтеся, що ви перебуваєте в директорії з файлом `package.json`, `.git` або іншим файлом проєкту. Claude Code найкраще працює всередині проєктів.

### "Permission denied" (macOS)
Спробуйте:
```bash
chmod +x /usr/local/bin/claude
```
