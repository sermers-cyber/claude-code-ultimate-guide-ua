## Докази за принципом test-first

Перший запуск цільових тестів завершився помилкою, бо файлу `scripts/progress.py` не існувало. Помилка мала вигляд `FileNotFoundError` для цього файлу. Після цього додали реалізацію, яка задовольняє тести.

Цільовий набір тестів після реалізації:

```text
python3 -m unittest -v examples/skills/learning-path/tests/test_progress.py

Ran 11 tests in 0.029s
OK
```

Покрита поведінка:

1. Новий профіль Beginner записує стан поза встановленим skill.
2. Атомарне збереження залишає коректний повний JSON без тимчасового файлу.
3. Штучно спричинений збій `os.replace` залишає старі байти стану недоторканими й видаляє тимчасовий файл.
4. Незавершені передумови блокують завершення.
5. Порожній доказ блокує завершення.
6. Вибір наступного модуля повертає перший розблокований модуль.
7. Планування повторень повертає сім потрібних дат.
8. Пошкоджений JSON-стан призводить до безпечної відмови (fail closed).
9. Булеві значення версії, невідомі треки, невідомі модулі та модулі поза вибраним треком призводять до безпечної відмови.
10. `status`, `next`, `due` і `complete` відхиляють пошкоджений стан до виконання.
11. Шістнадцять паралельних спроб `init` дають рівно один успішний профіль і п'ятнадцять відхилених спроб.

## Виправлення за результатами незалежного рев'ю

- `_validate_state` тепер отримує довірені `path_data`. Вона вимагає, щоб `version` був справжнім цілим числом, визнає лише визначені треки й приймає лише відомі модулі, що належать до вибраного треку. Вона також відхиляє запис про завершення, для якого відсутні передумови.
- Кожна CLI-команда, що читає стан, завантажує та перевіряє його щодо `path_data` до вибору, планування, завершення чи звітування про роботу.
- Команди skill тепер виконуються через `${CLAUDE_SKILL_DIR}/scripts/progress.py` з `--root "$PWD"` перед підкомандою. Тому вони працюють із проєктом стороннього учня, а не припускають, що це checkout цього посібника.
- Відображення самооцінки спочатку робило Maintainer варіантом лише для управління; фінальне виправлення повністю прибирає його з результатів оцінювання.
- Формулювання тепер каже, що для завершення потрібна непорожня примітка-доказ. Воно більше не натякає, що довільний доказ можна визнати неповним.
- Початкову примітку щодо валідатора замінено нижченаведеною точною межею валідації frontmatter у `quick_validate.py`.

## Виправлення за результатами фінального рев'ю

- `init` більше не перевіряє наявність цілі перед записом. Він записує та виконує fsync тимчасового файлу в тій самій директорії, а потім публікує його через `os.link`. Цей примітив успішний рівно для одного учасника й ніколи не перезаписує наявну ціль. Кожен учасник, що програв, видаляє лише власний тимчасовий файл.
- Тест паралельності запускає шістнадцять викликів на бар'єрі та перевіряє: один переможець, п'ятнадцять відхилених викликів і читабельний кінцевий стан.
- Відображення самооцінки тепер містить лише Beginner, Intermediate і Advanced. Maintainer описано окремо як ручний вибір для цілі спільного управління.
- Межа валідації тепер називає реальну поведінку `quick_validate.py`: він імпортує PyYAML перед розбором frontmatter у `SKILL.md`. У системному Python немає PyYAML, тому виникає `ModuleNotFoundError`, але доступний pyenv Python успішно запускає цей валідатор.

## Додаткова перевірка

- Звичайний цільовий набір unit-тестів пройшов після фінального коміту: 11 тестів за 0.029s.
- Ізольований цільовий набір unit-тестів пройшов після фінального коміту з `python3 -I -B`: 11 тестів за 0.029s.
- Компіляція Python пройшла з тимчасовим кешем байткоду поза worktree під час попереднього запуску з виправленнями.
- Відносні Markdown-посилання в новому SKILL і README розв'язалися успішно.
- Усі сім фрагментів вправ розв'язуються до заголовків у наявних сторінках посібника.
- Smoke-тест CLI для стороннього проєкту з `CLAUDE_SKILL_DIR` пройшов: створення профілю, отримання першого модуля, запис доказу та перелік першого повторення, що настав.
- `rg` не знайшов жодного довгого тире (em dash) у нових файлах прототипу.
- `git diff --check` пройшов до та після фінального коміту.
- `/Users/florianbruniaux/.pyenv/shims/python3 /Users/florianbruniaux/.codex/skills/.system/skill-creator/scripts/quick_validate.py examples/skills/learning-path` пройшов із повідомленням `Skill is valid!`. Виклик із системним Python, як і раніше, завершується на `import yaml` з `ModuleNotFoundError: No module named 'yaml'`. Середовище виконання без залежностей також завантажило постачуване JSON-сумісне YAML-визначення під час тестового набору.

## Межа та застереження

Прототип свідомо записує докази завершення, але не оцінює їхню якість і не позначає повторення як виконані. Повторення, чия дата минула, залишаються видимими. Чи було повторення виконане по суті, мають вирішувати люди або майбутня продуктова логіка. Прототип не виконував жодних мережевих дій, встановлення пакетів, змін посібника, оновлення навігації чи каталогу, змін changelog, зміни версії та зовнішніх записів.
