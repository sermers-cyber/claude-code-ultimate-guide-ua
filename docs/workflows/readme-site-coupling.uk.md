# Контракт між README та вебсайтом

Вебсайт відповідає за перегляд людьми та пошук потрібного. Репозиторій посібника відповідає за Markdown-джерела, файли для повторного використання, машинозчитувані індекси та історію внесків. `machine-readable/navigation.json` з'єднує ці поверхні.

## Відповідальність

| Поверхня | Відповідальність | Канонічне розташування |
|---|---|---|
| Навігація для людей | Маршрути за наміром, пошук, відрендерені сторінки, завантаження | `https://cc.bruniaux.com/` |
| Вміст посібника | Довгі Markdown-матеріали та приклади | `guide/`, `examples/`, `docs/` |
| Кураторська модель намірів | `Start`, `Build`, `Scale`, `Resources`, `Updates` | `machine-readable/navigation.json` |
| Підсумок репозиторію | Короткий вхід у проєкт і доступ до джерел | `README.md` |
| Історія посібника | Зміни в репозиторії | `CHANGELOG.md` та `/changelog/` |
| Історія Claude Code | Версії продукту та вплив на роботу | `machine-readable/claude-code-releases.yaml` та `/releases/` |

README не повинен дублювати мапу сайту. Він показує згенерований уривок із намірами, короткий швидкий старт, специфічний для репозиторію, та посилання на джерела для контриб'юторів або офлайн-читачів.

## Порядок внесення змін

1. Відредагуйте `machine-readable/navigation.json` у репозиторії посібника.
2. Запустіть `python3 scripts/sync-navigation.py --write`.
3. Перегляньте згенерований блок README і результат перевірки шляхів до джерел.
4. Зберіть лендінг, маючи репозиторій посібника як сусідній каталог або через `GUIDE_REPO_PATH`.
5. Перевірте `/sitemap/`, `/guide/`, навігацію в шапці, пошук і публічний маршрут, на який вказує кожен змінений запис.
6. Залишайте маршрути, що існують лише на лендінгу, у спільному маніфесті зі `source_path: null`.

## Критерії приймання

- П'ять груп намірів лишаються впорядкованими як `Start`, `Build`, `Scale`, `Resources` і `Updates`.
- Ідентифікатори елементів і публічні маршрути унікальні.
- Кожен `source_path`, що не дорівнює null, існує всередині репозиторію посібника.
- Кожен заявлений якір джерела розв'язується в Markdown-заголовок.
- Позначений блок README збігається з маніфестом байт у байт після рендерингу.
- Копія лендінгу збігається з маніфестом посібника до запуску збірки Astro.
- Публічні посилання для читання ведуть на `cc.bruniaux.com`; посилання на репозиторій вказують на джерела або файли для завантаження.
- Лічильники генеруються на поверхні-споживачі або опускаються.
