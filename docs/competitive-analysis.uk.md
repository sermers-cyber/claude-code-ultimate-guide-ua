### 3. Аналіз глибини контенту

**Посібник Shorthand** (проаналізовано 430 рядків):
- Ціль: налаштування та основи для практиків
- **Охоплені теми**:
  - Skills і Commands (визначення воркфлоу, навігація за codemap)
  - Hooks (6 типів: PreToolUse, PostToolUse, UserPromptSubmit, Stop, PreCompact, Notification)
  - Subagents (делегування з обмеженими інструментами/дозволами)
  - Rules і Memory (CLAUDE.md проти модульних правил)
  - MCPs (Model Context Protocol для зовнішніх сервісів)
  - Керування контекстним вікном (критично: <10 увімкнених MCP, <80 активних інструментів)
  - Plugins (встановлення, керування екосистемою)

**Показники глибини**:
- Практичні приклади (hook для tmux, Supabase MCP, ланцюжки команд)
- Візуальні скріншоти (термінал, інтерфейс плагінів, цикли зворотного зв'язку)
- Реальні конфігурації (структура агента, організація skills)
- Критичні попередження (деградація контекстного вікна через забагато MCP)

**Посібник Longform** (проаналізовано 354 рядки):
- **Охоплені теми**:
  - Оптимізація токенів (заміна MCP на CLI, lazy loading)
  - Збереження пам'яті (файли сесій, hooks: PreCompact, Stop, SessionStart)
  - Безперервне навчання (автоматичне вилучення патернів із сесій)
  - Цикли верифікації (checkpoint проти безперервних evals)
  - Паралелізація (Git worktrees, метод cascade)
  - Оркестрація subagents (проблема контексту, ітеративне отримання)

**Показники глибини**:
- Просунуті техніки (динамічне впровадження системного prompt, hooks збереження пам'яті)
- Патерни з реального світу (економіка токенів, запобігання context rot)
- Орієнтація на продакшн (оптимізація витрат, патерни верифікації)

**НЕ охоплено** (прогалини порівняно з нашим посібником):
