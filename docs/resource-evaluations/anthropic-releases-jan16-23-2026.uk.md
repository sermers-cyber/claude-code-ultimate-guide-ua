## Огляд

Цей тиждень приніс Anthropic значні зрушення: великі розгортання продуктових інструментів і масштабну публікацію щодо врядування ШІ.

## 1. Конституція Claude: велика редакція

**Дата:** 21 січня 2026 року
**Тип:** оголошення / документ врядування

### Головне

- Опубліковано нову конституцію для Claude, переосмислену як документ врядування, що спрямовуватиме поведінку моделі в усіх майбутніх версіях
- Переглянуто структуру: від переліку принципів до детального наративного підходу, що пояснює «чому» за кожною настановою, сприяючи узагальненню, а не механічному застосуванню правил
- Чотири ієрархічні пріоритети: загальна безпека → широка етика → дотримання настанов Anthropic → справжня корисність
- Документ опубліковано у відкритому доступі (ліцензія CC0 1.0), він призначений для використання майбутніми моделями й ітеративного оновлення
- Ключові розділи: Helpfulness, Claude's Ethics, Anthropic's Guidelines, Being Broadly Safe, Claude's Nature (зокрема роздуми про можливу свідомість Claude)

### Джерела

- https://www.anthropic.com/news/claude-new-constitution
- https://www-cdn.anthropic.com/f83650a21e480136866a3f504deb76e346f689d4/claudes-constitution.pdf

## 2. Claude Code: оновлення продукту

**Дати:** 9-22 січня 2026 року
**Тип:** продуктові релізи
**Охоплені версії:** від 2.1.9 до 2.1.17

### Ключові функції за версіями

**Версія 2.1.17 (22 січня)**
- Виправлено збій на процесорах без підтримки AVX

**Версія 2.1.16 (22 січня)**
- Система керування задачами з відстеженням залежностей
- Нативне керування плагінами VSCode
- Відновлення віддалених сесій OAuth

**Версія 2.1.15 (21 січня)**
- Покращення продуктивності UI завдяки React Compiler
- Сповіщення про застарілість для npm install

**Версія 2.1.14 (20 січня)**
- Автодоповнення з історії bash із синтаксисом bang
- Пошук у плагінах
- Закріплення за конкретними версіями git

**Версія 2.1.9 (16 січня)**
- Налаштовуваний автопоріг MCP із синтаксисом auto:N
- Розширена підтримка PreToolUse hooks
- Змінна середовища CLAUDE_SESSION_ID

**Версії 2.1.6-2.1.7 (13-14 січня)**
- Покращений пошук у конфігурації
- Відфільтрована статистика за 7/30 днів
- Атрибути URL сесії для комітів і PR

### Несумісні зміни

- **Застарілість npm install** → рекомендовано перейти на `claude install` або нативне встановлення
- **Міграція URL OAuth** → console.anthropic.com стає platform.claude.com
- **Вилучення @-згадок MCP** → натомість використовуйте `/mcp enable <name>`

### Покращення безпеки/стабільності

- Виправлено вразливість через надто дозвільні правила з wildcard у командах оболонки
- Виправлено витік пам'яті tree-sitter і накопичення WASM у довгих сесіях
- Виправлено ризик ін'єкції команд під час парсингу bash
- Збільшено тайм-аут hooks інструментів: 60 с → 10 хвилин

### Джерела

- https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md
- https://www.gradually.ai/en/changelogs/claude-code/
- https://releasebot.io/updates/anthropic/claude-code

## 3. Cowork: розширення попереднього доступу

**Дати:** 12 і 16 січня 2026 року
**Тип:** реліз функції (research preview)

### Головне

**12 січня**
- Запуск попереднього доступу до Cowork у Claude Desktop (лише macOS) для планів Max
- Переносить агентні можливості Claude Code на роботу зі знаннями, не пов'язану з кодом, через локальну ізольовану VM

**16 січня**
- Розширення попереднього доступу на плани Pro у Claude Desktop (macOS)
- Повна локальна інтеграція MCP і доступ до локальних файлів через віртуальну машину

### Джерела

- https://support.claude.com/en/articles/12138966-release-notes
- https://fortune.com/2026/01/13/anthropic-claude-cowork-ai-agent-file-managing-threaten-startups/

## 4. Claude Desktop і плани: оновлення доступу

**Дата:** 16 січня 2026 року
**Тип:** оновлення бізнес-умов/цін

### Головне

**Claude Code у планах Team**
- Claude Code додано до всіх місць Standard у планах Team
- Демократизація доступу до агентних інструментів програмування

**Opus 4 і 4.1 застаріли**
- Моделі Opus 4 і 4.1 вилучено з селекторів моделей Claude і Claude Code
- Рекомендовано перейти на Opus 4.5 (вища продуктивність за 1/3 вартості)

### Несумісні зміни

- Повне виведення Opus 4/4.1 з ужитку: клієнти мають перейти на Opus 4.5 або на старі версії через External Researcher Access Program

### Джерела

- https://support.claude.com/en/articles/12138966-release-notes

## 5. Claude Mobile: здоров'я та дані

**Дата:** 12 січня 2026 року
**Тип:** реліз функції

### Головне

**Аналітика здоров'я та фітнесу**
- Claude тепер може читати й аналізувати дані про здоров'я/фітнес на iOS та Android (плани Pro/Max, лише США)
