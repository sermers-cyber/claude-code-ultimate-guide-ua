## Підсумок

Довідковий репозиторій найкращих практик Claude Code. Постійно оновлюється, поки розвивається Claude Code. Ключовий зміст:

- Повні довідники frontmatter для агентів (15 полів), skills (10 полів) і commands
- Таксономія глобальних налаштувань і налаштувань рівня проєкту (система Tasks v2.1.16, Agent Teams експериментально)
- 12 порад Boris Cherny щодо кастомізації (12 лют. 2026, офіційне джерело)
- Розділи «My Experience» з практичними порадами (CLAUDE.md < 150 рядків, /compact на 50% тощо)
- Архітектурний патерн Command → Agent → Skills із робочим прикладом
- Повний довідник прапорців запуску CLI
- Сервери MCP для щоденного використання (Context7, Playwright, Claude in Chrome, DeepWiki, Excalidraw)
- Області пам'яті агента (user/project/local) із патернами міжсесійного навчання
- Патерн самоеволюційного агента (агент оновлює власні skills після виконання)
