## Підсумок

Mergify створила систему розслідування тікетів підтримки, що поєднує Claude Code як оркестратор із 5 власними MCP-серверами (Datadog, Sentry, PostgreSQL, Linear, GitHub). Система паралельно виконує запити до всіх систем і формує структурований звіт для перегляду людиною.

Ключові результати (за власними даними компанії): час тріажу скоротився з ~15 хв → <5 хв; точність із першого проходу 75%.

## Нотатки заперечення (агент technical-writer)

- Оцінку 4/5 підтверджено
- Точність 75% = 25% усе ще потребують подальшої роботи людини → подано як «допомогу», а не «автоматизацію»
- Відзначено упередженість джерела (Mergify продає автоматизацію CI/CD, стаття працює на їхній бренд)
- Реальна цінність: патерн «оркестратор зі станом і MCP-адаптерами», відмінний від усіх наявних кейсів у посібнику
- Ризик відмови від інтеграції: помірний - посібник відставатиме в ракурсі ops/підтримки, коли подібних кейсів побільшає
