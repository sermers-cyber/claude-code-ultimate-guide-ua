# Оцінка: допис у соцмережах «Claude Code Hidden Feature»

**Дата**: 2026-01-27
**Оцінювач**: Claude Sonnet 4.5
**Тип джерела**: скопійований текст (допис у соцмережах без джерел)
**Вердикт**: ❌ **ВІДХИЛЕНО** (Оцінка: 1/5)

---

## Підсумок

Допис у соцмережах стверджує, що Claude Code має «приховану функцію» для паралельного запуску агентів. Він написаний агресивною маркетинговою мовою і штучно нагнітає FOMO. У дописі немає посилань, а публічно задокументовані функції подано як «секрети».

---

## Підсумок змісту

- **Головне твердження**: «прихована функція» дає змогу автоматично запускати паралельних агентів, наче «команду»
- **Описаний механізм**: feature flag, який автоматично створює агентів для кожного завдання
- **Тон**: маркетингове перебільшення («retourne internet», «tu passes à côté d'un truc énorme»)
- **Заклик до дії**: «знайдіть прапорець через Perplexity»
- **Наведені джерела**: жодних

### Фактичні виправлення

**Що є ПРАВДОЮ (і вже офіційно задокументовано):**

1. **Tasks API** (v2.1.16+): керування завданнями із залежностями - [CHANGELOG](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#2116---2026-01-22)
2. **Паралельні субагенти**: інструмент `Task` запускає незалежних агентів - [Документація](https://code.claude.com/docs/en/sub-agents)
3. **TeammateTool**: мультиагентна оркестрація (реальна, не прихована) - [Gist спільноти](https://gist.github.com/kieranklaassen/4f2aba89594a4aea4ad64d753984b2ea)
4. **CLAUDE_CODE_ENABLE_TASKS=false**: прапорець міграції, щоб **вимкнути** нову систему - [v2.1.19](https://github.com/anthropics/claude-code/blob/main/CHANGELOG.md#2119---2026-01-25)

**Що є НЕПРАВДОЮ:**

- ❌ Не «прихована» → задокументована з v2.1.16 (22 січня 2026)
- ❌ Не така вже й нова → на момент оцінювання вийшла 5 днів тому
- ❌ Прапорець нічого не «розблоковує» → він повертає стару систему
- ❌ Не ексклюзивна → доступна всім користувачам Claude Code

## Оцінка та рішення

### Оцінка: 1/5 ❌ - ВІДХИЛИТИ

**Обґрунтування:**

1. **Принципова нечесність**: публічні функції подано як «приховані»
2. **Нагнітання FOMO**: маніпулятивна мова, що створює відчуття терміновості
3. **Нуль джерел**: жодного офіційного посилання = величезний червоний прапорець
4. **Суперечить принципам посібника**: «Точність понад маркетинг» (RULES.md, рядок ~350)
5. **Нульова документальна цінність**: усі правдиві факти вже є в CHANGELOG

**Чому відхилення важливе:**

Посібник має понад 15 тис. рядків і понад 66 шаблонів, побудованих на ретельному цитуванні джерел. **Одне неякісне джерело може підірвати довіру.** Читачі мають довіряти 100% наведених джерел.

### Що виправдало б оцінку 3+:

- ✅ Посилання на офіційний CHANGELOG
- ✅ Професійний, фактичний тон
- ✅ Педагогічне пояснення (як і навіщо використовувати функцію)
- ✅ Згадка обмежень і сценаріїв використання
- ✅ Розмежування «експериментальних» і «стабільних» функцій
