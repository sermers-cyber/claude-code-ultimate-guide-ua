## Підсумок

Anthropic анонсує «Contribution Metrics» для Claude Code — аналітичну панель з інтеграцією GitHub у публічній бета-версії для планів Team і Enterprise. Допис містить оновлені внутрішні дані про продуктивність:

- **+67% злитих PR** на інженера на день в Anthropic
- **70-90% коду** написано за допомоги Claude Code по командах
- Панель відстежує PR і рядки коду, закомічені з атрибуцією Claude Code та без неї
- Консервативне вимірювання: враховується лише участь Claude Code з високою впевненістю
- Позиціонується як доповнення до метрик DORA та швидкості спринту, а не заміна

## Рішення щодо інтеграції

**Обґрунтування оцінки (4/5):**
- Офіційне першоджерело з жорсткішими метриками, ніж наявний контент посібника
- Замінює самозвітні +50% з серп. 2025 на +67% на основі PR
- Нова функція продукту (панель), яку варто задокументувати
- Оцінка не 5/5, бо: методологія розпливчаста, лише внутрішні дані, охоплення Team/Enterprise обмежує аудиторію

**Виклик (агент technical-writer):**
- Рекомендовано підвищити оцінку з 3 до 4 (прийнято)
- Виявлено 3 сліпі зони: порівняння методологій, перевірка твердження «conservative», конкурентний контекст
- Скориговано план інтеграції: окремий підрозділ (не зливати з дослідженням серп. 2025)
