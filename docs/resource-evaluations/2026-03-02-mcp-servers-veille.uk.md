# Оцінка ресурсу: огляд MCP-серверів (березень 2026)

**Дата**: 2026-03-02
**Тип**: скопійований текст (огляд / дослідницький звіт)
**Мова**: французька
**Джерело**: внутрішнє дослідження Perplexity, охоплює сервери: `github/github-mcp-server`, `exa-labs/exa-mcp-server`, `rawr-ai/mcp-graphiti`

---

## Підсумок

Дослідницький звіт, що оцінює 3 MCP-сервери з відкритим кодом для робочих процесів розробки в Claude Code за критеріями: ≥50 зірок, свіжий реліз (<3 місяців), зрозумілий README, тести/CI, конкретний сценарій використання.

Основні висновки огляду:

- **GitHub MCP Server** (`github/github-mcp-server`): 27.1k зірок (станом на 2026-07-28 вже 31 775), реліз v0.31.0 від 19 лютого 2026, офіційний проєкт GitHub, Go, віддалений MCP за адресою `api.githubcopilot.com/mcp/`, OAuth 2.1 + PAT, охоплює Issues/PRs/Projects/Enterprise
- **Exa MCP Server** (`exa-labs/exa-mcp-server`): заявлено 3.1k зірок (станом на 2026-07-28 вже 4 780, не перевірено, див. фактчекінг), без формальних релізів на GitHub, TypeScript, ключова функція `get_code_context_exa` для пошуку коду, орієнтованого на розробників
- **Graphiti MCP Server** (`rawr-ai/mcp-graphiti`): 74 зірки (станом на 2026-07-28 вже 100), граф знань для кількох проєктів на Neo4j + Docker, Python/pipx, CLI (`graphiti compose`, `graphiti up`), проєкт на ранній стадії

## Перевірка (агент technical-writer)

**GitHub MCP: що пропущено**:
- Немає попередження про приватність для віддаленого режиму `api.githubcopilot.com` (надсилає дані на сервери GitHub)
- Немає явного порівняння з Git MCP Server (два взаємодоповнювальні рівні: локальний і хмарний)
- Немає рекомендації переглянути наявну оцінку `git-mcp-server-evaluation.md` (5/5 КРИТИЧНО, так і не інтегровано)
- Оцінку скориговано: 4/5 (не 5/5)

**Exa MCP: що пропущено**:
- Кількість зірок неможливо перевірити: огляд заявляє 3.1k, пошук Perplexity знайшов ~220 зірок
- Немає формальних релізів на GitHub: версіонування лише через npm, критерій свіжості пом'якшено без чітких доказів
- Нативний WebSearch у Claude Code покриває базовий сценарій пошуку в вебі та коді без додаткової залежності від SaaS
- Оцінку скориговано: 2/5 (відхилити)

**Graphiti MCP: що пропущено**:
- 74 зірки ледь перевищують поріг; зрілість проєкту під питанням
- Kairn (уже є в посібнику, §8.2) покриває сценарій постійної пам'яті / графа знань для робочих процесів Claude Code
- Залежність від Neo4j + Docker + LLM API надто важка для більшості користувачів
- Оцінку скориговано: 2/5 (відхилити)

**Ризики неінтеграції (GitHub MCP)**:
- Користувачі посібника пропускають найкорисніший MCP для автоматизації GitHub у Claude Code
- Немає розмежування між Git (локально) і GitHub (у хмарі), а це поширене джерело плутанини
- Оцінка Git MCP була 5/5 КРИТИЧНО, але так і не потрапила в посібник; це недогляд виправлено одночасно
