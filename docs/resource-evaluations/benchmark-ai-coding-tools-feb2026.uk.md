## Резюме

**Оцінка**: 3/5 (релевантно: корисне доповнення)
**Рішення**: вибіркова інтеграція (виявлено 2 чисті внески)
**Впевненість**: середня (твердження неможливо перевірити без URL джерела)

Структурований бенчмарк, що порівнює 5 інструментів агентного програмування з детальними таблицями, фокусом на Claude Code і 6 рекомендаціями щодо документації. Реальний внесок за двома напрямками, яких бракує в посібнику: точні квоти за планами (Pro/Max) і покриття Windsurf/Zed, наразі відсутнє. Решта перетинається з наявними розділами або не піддається перевірці.

---

## Короткий зміст

- **5 порівняних інструментів**: Claude Code (насамперед CLI + sub-agents + hooks), Cursor (IDE-форк VS Code, Tab, Composer), Windsurf (мультиагентний Cascade, Wave 13), Zed (нативний Rust, локальний Ollama), Copilot Workspace (зосереджений на GitHub, issue → PR)
- **Новини**: Sonnet 4.6 запущено «15 лют. 2026» з контекстом 1M (бета), модель за замовчуванням для Pro/Free; розширення VS Code у GA; нова документація Hooks (26 лют.)
- **Квоти Claude Code**: Pro ≈ 10-40 промптів/5 год, Max 5x = 50-200/5 год, Max 20x = 200-800/5 год, ліміт ~50 вікон/місяць
- **Відмінності Claude Code**: сильні сторони = CLI + Git + sub-agents + контрольні точки + CLAUDE.md/init; слабкі сторони = немає вбудованого автодоповнення, тісні квоти Pro в інтенсивних сесіях
- **6 рекомендацій щодо документації**: (1) рамка моделей/контексту, (2) сторінка про квоти для розробників, (3) агентний стек, (4) порівняння IDE, (5) навчальний матеріал про CLAUDE.md, (6) сценарії роботи у VS Code

## Рекомендації щодо інтеграції

### Внесок №1: точні квоти за планами (ВИСОКИЙ ПРІОРИТЕТ)

- **Реальна прогалина**: числа в посібнику є, але розпорошені між `ultimate-guide.md` і `guide/core/known-issues.md`. Немає зведеної таблиці «Pro / Max 5x / Max 20x» з реальними діапазонами на 5-годинне вікно.
- **Де**: `guide/ultimate-guide.md`, розділ про ціни/обмеження (~рядки 1951-2013) + можливо `guide/core/architecture.md`
- **Як**: єдина таблиця «План → промпти Claude Code/5 год → години Sonnet/тиждень → місячний ліміт» з приміткою про sub-agents і контекст 1M як множники споживання
- **Застереження**: числа з бенчмарку (10-40 / 50-200 / 200-800) є діапазонами від спільноти, а не офіційними SLA Anthropic. Перед інтеграцією знайти джерела в GitHub issues anthropics/claude-code або в офіційній документації.

### Внесок №2: розділ Windsurf + Zed у порівнянні інструментів (СЕРЕДНІЙ ПРІОРИТЕТ)

- **Реальна прогалина**: порівняльна таблиця в рядку 885 охоплює Copilot/Cursor/Claude Code. Windsurf і Zed відсутні в основному порівнянні, попри зростання їх використання.
- **Де**: розділ Migration/Comparison (~рядок 881), розширити наявну таблицю
- **Як**: додати 2 стовпці (Windsurf + Zed) + рядок «Copilot Workspace» з коротким позиціонуванням (50-100 слів на інструмент). Узяти бенчмарк за основу, звірити з офіційною документацією.
- **Увага**: Windsurf Wave 13 + SWE-1.5 і ціни Zed за токени (+10%) є конкретними твердженнями, які перед інтеграцією треба звірити з windsurf.com/changelog і zed.dev/blog.

### Не інтегрувати

- Рекомендації 3, 5, 6 (агентний стек, CLAUDE.md, сценарії у VS Code): уже охоплено в посібнику, інтеграція = дублювання без доданої цінності.
- Рек. 4 (окрема сторінка «порівняння IDE»): у принципі доречна, але посібник не є маркетинговою сторінкою Anthropic, тож слід зберігати навчальний фокус.

## Перевірка на міцність (technical-writer)

**Скоригована оцінка: 3/5** (знижено з початкових 4/5)

**Пункти перевірки:**
- Невідоме джерело (текст без URL, автора не встановлено) частково дискваліфікує: попередні оцінки анонімних джерел, які неможливо перевірити, систематично отримують менше 4
- Запуск Sonnet 4.6 «15 лют. 2026» є точним датованим твердженням, яке варто звірити з `llms-full.txt`, перш ніж на нього спиратися
- 6 рекомендацій нерівноцінні: 2 стосуються реальних прогалин, 4 є шліфуванням наявного; ретельна оцінка має їх розділяти
- Відсутність Windsurf/Zed у посібнику є реальною прогалиною, але не критичною для цільової аудиторії (розробники в CLI, які не шукають маркетингових порівнянь)

**Ризики в разі відмови від інтеграції:**
- Низькі в короткостроковій перспективі: наявне порівняння (3 інструменти) задовольняє потреби більшості читачів
- У середньостроковій перспективі: якщо Windsurf/Zed і далі зростатимуть, їх відсутність у посібнику створить сліпу зону для довіри
