**Дата:** 2026-03-23
**Оцінювач:** Claude (Sonnet 4.6)
**Статус:** ✅ Інтегровано: розділ Configuration Quality

## 📄 Підсумок змісту

- **Caliber** це CLI-інструмент, що оцінює, генерує й постійно синхронізує конфігурації ШІ-агентів (CLAUDE.md, MCP-сервери) з кодовою базою. Без встановлення: `npx @rely-ai/caliber score`
- Оцінювання на 100% локальне й детерміноване: 6 категорій (Existence 25 + Quality 25 + Grounding 20 + Accuracy 15 + Freshness 10 + Bonus 7), 61 перевірка, жодних викликів LLM, жодних мережевих запитів
- Виявлення дрейфу базується на Git: SHA256(дерево файлів + змінені файли) + кеш вказівника git HEAD, підтримує `caliber refresh` для автоматичного оновлення документації після змін коду
- Модуль Learner перехоплює події інструментів через hooks → JSONL → інкрементальний аналіз LLM → `CALIBER_LEARNINGS.md` із дедуплікацією за 70% схожості
- **GitHub: 65 зірок (станом на 2026-07-28 уже 1 223), 12 форків, створено 2026-03-10 (13 днів), MIT, TypeScript/Node.js ≥20**

## 🔬 Технічний аналіз (після повного аудиту вихідного коду)

Повний аудит вихідного коду проведено на клоні [Caliber](https://github.com/rely-ai-org/caliber). Ключові висновки:

### Система оцінювання

**6 категорій, 61 перевірка, ~102 бали, нормалізовані до 100:**

| Категорія | Макс. | Метод |
|----------|-----|--------|
| Existence | 25 | Перевірки `existsSync()` для CLAUDE.md, skills, MCP, правил |
| Quality | 25 | Розбір вмісту: блоки коду, бюджет token, частка конкретики, виявлення дублікатів |
| Grounding | 20 | % каталогів/файлів проєкту, згаданих у конфігурації (сканування на 2 рівні) |
| Accuracy | 15 | Перевірка шляхів + коміти Git після останнього оновлення конфігурації |
| Freshness | 10 | Застарілість за Git + виявлення секретів (13 regex-шаблонів) |
| Bonus | 7 | Hooks, AGENTS.md, вивчений вміст, зовнішні джерела |

Оцінювання гібридне: наявність файлів (40%), аналіз вмісту (50%), евристики Git (10%). Уся логіка в `src/scoring/checks/*.ts`. Можна винести в окрему бібліотеку.

### Виявлення дрейфу

Три незалежні сигнали:
1. **Сигнатура дерева:** `SHA256(sorted file tree + git dirty files)`: будь-яке додавання/видалення/перейменування спричиняє інвалідацію
2. **Вказівник git HEAD:** кеш дійсний лише на тому самому коміті
3. **Git diff:** `git diff <lastSha>..HEAD` (лише код, без CLAUDE.md/skills при оцінці дрейфу)

Кеш зберігається в `.caliber/cache/fingerprint.json`. Вважається застарілим при розбіжності версії, зміні HEAD або розбіжності сигнатури.

### Модуль Learner

Події перехоплюються через hooks у `.caliber/learning/session.jsonl` → інкрементальний аналіз LLM кожні 50 подій → `CALIBER_LEARNINGS.md` (формат списку: `**[pattern|gotcha|fix|correction]** text`). Дедуплікація за 70% схожості нормалізованого тексту. Відстеження ROI порівнює частоту невдач із вивченими уроками та без них між сесіями.

### GitHub Action

`github-action/action.yml` + `index.js` (разом 266 рядків). Входи: `agent`, `fail-below`, `comment`, `auto-refresh`. Публікує в PR коментар з оцінкою, рівнем і дельтою відносно базової гілки. Валить CI, якщо оцінка < `fail-below`. Детерміновано: у самій Action немає викликів LLM.

### Примітка з безпеки

Caliber має доступ на запис до CLAUDE.md у режимі безперервної синхронізації (`caliber watch`, `caliber refresh`). Той самий клас ризику, що й у Packmind: скомпрометоване генерування конфігурації або зловмисне джерело можуть поширити інструкції в сесії ШІ. Ставтеся до виводу `caliber init` з тією ж дисципліною рев'ю, що й до оновлення плейбука Packmind.

## 🔥 Виклик (technical-writer)

Оцінку 3/5 підтверджено. Ключові зауваження:

- **Непрозорість шкали оцінювання**: 100-бальна шкала детермінована, але не задокументована для користувача (немає SCORING.md). Оцінка 74 каже менше, ніж мала б, якщо не знати шкали.
- **Сумнів щодо глибини підтримки кількох інструментів**: підтримка 4 інструментів (Claude Code + Cursor + Codex + Copilot) ризикує дати загалом прийнятні конфігурації замість глибоко специфічних для Claude Code.
- **Ризик доступу на запис применшено в README**: поверхня атаки `caliber watch` (безперервний запис у CLAUDE.md) заслуговує на явну згадку.
- **Місце в посібнику**: НЕ варто ставити поруч з AIBlueprint (каркас), це інша операційна категорія. Місце в окремому підрозділі "Configuration Quality", що з'єднує «дрейф одного проєкту» (Caliber) і «поширення в масштабі організації» (Packmind).
- **Ризик не інтегрувати**: від низького до помірного. Прогалина з виявленням дрейфу реальна, але некритична для більшості користувачів, які починають з нуля.
