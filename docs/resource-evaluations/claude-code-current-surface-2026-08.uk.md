# Поточні можливості Claude Code: Computer Use, підказки плагінів, apps gateway та артефакти

## Висновок

Поточна офіційна документація Claude Code підтверджує чотири поверхні продукту, що впливають на навчальні пріоритети посібника: Computer Use з CLI на macOS, підказки з рекомендаціями plugin, Claude apps gateway і публікацію артефактів. Ця оцінка описує задокументовану поведінку станом на прочитання 2026-08-31. Вона не стверджує локальної перевірки під час виконання, доступності на тарифах понад зазначене в документації чи сумісності поза переліченими нижче джерелами.

## Поточні наслідки для продукту

### Computer use

Computer Use відрізняється від Bash, автоматизації браузера і MCP. Офіційний порядок віддає перевагу MCP-серверу, Bash або Claude in Chrome перед керуванням екраном. Робота на реальному робочому столі створює окрему межу довіри: схвалення для кожного застосунку і зупинка клавішею `Esc` зменшують ризик, але не ізолюють схвалений застосунок чи його видимі дані. Окрема сторінка посібника: [Computer Use in Claude Code](../../guide/core/computer-use.uk.md).

### Підказки plugin

Маркер `<claude-code-hint />` є однорядковим протоколом у виводі CLI, а не prompt для моделі. Claude Code вирізає його до того, як вхід потрапить до моделі, приймає лише придатний plugin з офіційного маркетплейсу як ціль і питає користувача перед встановленням. Протокол показує в запиті команду, що надіслала маркер, але не документує доказу особи видавця між цією командою і plugin. Окрема сторінка посібника: [Plugin Distribution and Recommendation Hints](../../guide/ecosystem/plugin-distribution.uk.md).

### Claude apps gateway

Claude apps gateway є сервісом на власному хостингу, що входить до бінарного файлу `claude`. Документація описує корпоративний SSO, політики за групами IdP, роботу з обліковими даними для upstream, телеметрію OTLP і маршрутизацію до upstream. Він мусить використовувати приватну адресу, бо може доставляти налаштування клієнтам. Вхід через device flow не має шляху зі службовим token для автоматизованого CI. Розділ про шлюз в [API Gateway for Enterprise Claude Code](../../guide/ops/api-gateway.uk.md) документує підтверджений обсяг і межу перевірки.

### Публікація артефактів

Публікацію артефактів **ПІДТВЕРДЖЕНО**, а не `UNKNOWN`. Поточна офіційна сторінка про артефакти каже, що Claude Code може опублікувати вивід сесії як живу сторінку на claude.ai; новий артефакт спочатку приватний, а поширювати його можна в межах організації або за публічним посиланням залежно від тарифу і налаштованих обмежень. Публікація залежить від режиму дозволів сесії, а артефактом, що спирається на конектор, не можна поділитися публічно. Ця оцінка не розглядає придатність для конфіденційних даних, специфічне для організації зберігання чи локальну доступність. Для цих питань потрібні відповідний тариф, налаштування і докази щодо управління даними.

## Рішення для посібника

Чотири офіційні сторінки тепер мають стабільні маршрути в посібнику для цілеспрямованої навігації. Зміна навігації чи машиночитаного індексу лишається окремим завданням, бо цей worktree обмежувався документацією поточних можливостей і не змінював індексів усього репозиторію.
