## Підсумок змісту

- **Runtime воркфлоу для Claude Code**: обгортає його через hooks, маршрутизує події через Unix Domain Socket (NDJSON) до персистентного runtime на Node.js
- **Архітектура**: Claude Code → hook-forwarder (stdin) → UDS → runtime athena-flow → TUI
- **TUI (термінальний UI)**: спостережуваність інструментів, дозволів, результатів, помилок у реальному часі; збереження сесій у SQLite; керування з клавіатури з кольоровими темами
- **Система plugin**: підтримує commands, hooks, MCP servers, agents; пресети ізоляції (strict/minimal/permissive)
- **Перший воркфлоу**: автономний конструктор E2E-тестів — навігує застосунком як людина, генерує структуровані тест-кейси, створює готовий до CI TypeScript для Playwright
- **Заявлено**: самовідновлення селекторів із 94% успіху (~3 с на ремонт) — неперевірено, бенчмарка в репозиторії немає
- **Встановлення**: `npm install -g athena-flow-cli` (Node.js 20+)
- **Roadmap**: візуальна регресія, тестування API, підтримка Codex (агент-агностичне позиціонування)
- **Порівнюваний проєкт, знайдений через Perplexity**: [Ruflo](https://github.com/ruvnet/ruflo): платформа мультиагентної оркестрації для Claude Code, на кілька тижнів старша й зріліша

2. **Метрики GitHub**: зірки, активний CI, відкриті issues, остання стабільна версія
3. **Твердження про 94%**: або прибране з документації, або задокументоване відтворюваною методологією
4. **Порівняння з Ruflo**: оцінити Ruflo (github.com/ruvnet/ruflo) паралельно — зріліший, та сама категорія. Запис у посібнику має охоплювати *категорію* (runtime на основі hooks), а не лише один інструмент

Якщо інтеграція в майбутньому: створити розділ **«Hook-Based Workflow Runtimes»** у `guide/ecosystem/third-party-tools.md` — категорія, якої сьогодні не існує, що вмістила б Athena Flow + Ruflo + майбутні інструменти цього типу.

**Чого не робити:**
- Цитувати «94% success rate» без перевірюваного джерела
- Рекомендувати `npm install -g athena-flow-cli` без попереднього аудиту джерела (див. розділ безпеки посібника)
- Інтегрувати запис про один інструмент без батьківської категорії

- Прецедент: Rippletide (оцінка 072) отримав 2/5 за «неперевірювані твердження, немає тяги» — Athena Flow поєднує обидва

**Що виправдовує, чому не знижувати до 1/5:**

**Ризик неінтеграції:** незначний у короткостроковій перспективі. У середньостроковій: якщо Ruflo + Athena Flow + інші інструменти з'являться, посібник відстане в цілій категорії. Активно стежити.
