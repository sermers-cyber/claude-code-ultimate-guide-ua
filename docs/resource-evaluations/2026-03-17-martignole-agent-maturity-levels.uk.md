## Підсумок

Фреймворк зрілості з 6 рівнів (0-5 в оригіналі, тут розширено до 6) для окремих розробників, які впроваджують агентів для написання коду. Справжній внесок — дуга рівнів 3-5: базовий користувач → той, хто делегує етапи → інженер контексту → оркестратор. Чисто лягає на концепції Claude Code (Plan mode, subagents, MCP-сервери, context engineering).

## Обґрунтування оцінки

**3/5: доречне доповнення**

- Закриває реальну прогалину: у посібнику не було шкали для самостійного визначення свого рівня
- Джерело від практика (контекст продакшн-розробки), а не авторська колонка блогера
- За рівнями немає жодних емпіричних даних: це таксономія одного інженера
- Рівні 0-2 — шум для аудиторії посібника (вона вже користується Claude Code)
- Місце еталонної «моделі зрілості» займає ThoughtWorks; вищі рівні Martignole специфічніші для Claude Code
