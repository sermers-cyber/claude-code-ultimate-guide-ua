## Підсумок

Офіційна документація функції нативної пісочниці Claude Code (v2.1.0+), що охоплює примітиви рівня ОС (Seatbelt, bubblewrap), ізоляцію файлової системи й мережі, режими пісочниці, обмеження безпеки та open-source runtime.

## Ключові тези

1. **Примітиви ОС**:
   - macOS: Seatbelt (вбудовано)
   - Linux/WSL2: bubblewrap + socat (потрібно встановити)
   - WSL1: не підтримується (немає потрібних можливостей ядра)

2. **Модель ізоляції**:
   - Файлова система: читання всього (налаштовується), запис лише в робочу директорію
   - Мережа: SOCKS5-проксі з allowlist/denylist доменів

3. **Режими пісочниці**:
   - Auto-allow: команди Bash схвалюються автоматично, якщо виконуються в пісочниці
   - Звичайні дозволи: усі команди потребують схвалення

4. **Аварійний вихід**: параметр `dangerouslyDisableSandbox` для несумісних інструментів (docker, watchman)

5. **Обмеження безпеки**:
   - Domain fronting (обхід через CDN)
   - Підвищення привілеїв через Unix-сокети
   - Підвищення привілеїв через дозволи файлової системи
   - Слабкість вкладеної пісочниці (Linux)

6. **Open-source**: npm-пакет `@anthropic-ai/sandbox-runtime`

7. **Підтримка платформ**: macOS ✅ | Linux ✅ | WSL2 ✅ | WSL1 ❌ | Windows (заплановано)

## Ризики, якщо НЕ інтегрувати

1. **Інциденти безпеки** (високий)
   - Користувачі запускають `--dangerously-skip-permissions` з нативною пісочницею, вважаючи, що вони повністю захищені
   - Обхід через domain fronting → ексфільтрація облікових даних
   - Підвищення привілеїв через Unix-сокети → компрометація системи
   - **Орієнтовний вплив**: 80%+ користувачів не розуміють компромісів між Docker microVM і нативною пісочницею на рівні процесу

2. **Тертя під час впровадження** (високий)
   - Користувачі вагаються використовувати автономний режим (потрібний для продуктивності), бо не розуміють гарантій пісочниці
   - **Орієнтовний вплив**: 50%+ потенційних автономних воркфлоу не впроваджено

3. **Помилки конфігурації** (середній)
   - Користувачі додають до whitelist `*.amazonaws.com` (включно з S3-бакетами, які створюють користувачі) → хибне відчуття безпеки
   - Користувачі дозволяють запис у директорії з `$PATH` → можливе підвищення привілеїв
   - **Орієнтовний вплив**: 30%+ кастомних конфігурацій пісочниці мають проблеми з безпекою

4. **Несумісність платформ** (середній)
   - Користувачі Windows/WSL1 намагаються використати нативну пісочницю (не підтримується) → розчарування, звіти про баги
   - **Орієнтовний вплив**: 20%+ користувачів Windows спантеличені

5. **Втрачені внески спільноти** (низький)
   - Open-source runtime (`@anthropic-ai/sandbox-runtime`) не згадано → спільнота не може провести аудит чи зробити внесок
   - **Орієнтовний вплив**: 0 аудитів безпеки від спільноти, 0 внесків

6. **Довіра до посібника** (середній)
   - Офіційну, свіжу, критичну для безпеки документацію не інтегровано швидко → сигнал, що посібник не встигає за важливими функціями
   - **Орієнтовний вплив**: падіння довіри серед користувачів, уважних до безпеки
