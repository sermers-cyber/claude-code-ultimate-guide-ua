## Короткий підсумок

Google Antigravity — це **agent-first IDE** (форк VS Code), запущене наприкінці 2025 року, яке зміщує розробку від традиційного редагування коду до робочих процесів, що виконують автономні агенти. Воно втілює принципово іншу філософію, ніж Claude Code: максимальна автономія агента проти явного контролю розробника.

**Чому 3/5**: це не пряма інтеграція з Claude Code, але помітний гравець екосистеми, якого наш посібник має згадати. Філософський контраст (terminal-first vs agent-first) корисний для читачів, які обирають свій робочий процес. Міст antigravity-claude-proxy створює конкретний зв'язок.

---

## Аналіз змісту

### Ключові факти (перевірено)

1. **Архітектура**: agent-first IDE (форк VS Code) з трьома поверхнями: Editor, Agent Manager, інтеграція з браузером
2. **Кілька моделей**: одночасно використовує Gemini 3 Pro, Claude 4.5, Liquid AI для різних завдань
3. **Екосистема skills**: репозиторії спільноти з 58 до 856+ skills (перевірені репозиторії GitHub: rmyndharis/antigravity-skills, sickn33/antigravity-awesome-skills)
4. **Ціни**: $20/місяць (у пакеті) або $80-90/місяць
5. **Міст до Claude**: npm-пакет `antigravity-claude-proxy`: проксі-сервер, що надає Anthropic-сумісний API на базі Cloud Code від Antigravity

### Порівняння філософій

| Вимір | Claude Code | Google Antigravity |
|-----------|-------------|-------------------|
| **Парадигма** | Terminal-first, нативно для CLI | Agent-first, нативно для IDE |
| **Контроль розробника** | Явне схвалення кожної правки | Вища автономія, агенти діють самостійно |
| **Модель контексту** | На рівні кодової бази через CLAUDE.md | Кілька поверхонь (редактор + браузер + термінал) |
| **CI/CD** | Нативно (headless, конвеєри) | Ще не зріле |
| **Профіль ризику** | Передбачуваний, консервативний | Вища автономія = вищий ризик вийти за межі |
| **Кілька агентів** | Agent Teams (v2.1+) | Вбудована оркестрація кількох агентів |
| **Skills** | `.claude/skills/` (YAML frontmatter) | На основі каталогів, інший формат |
| **Ціни** | Підписка Max plan | $20-90/місяць |
