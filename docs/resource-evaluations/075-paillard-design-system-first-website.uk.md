# Оцінка ресурсу: Boris Paillard: «Son site custom en 2h avec Claude Code»

**Джерело**: [LinkedIn Pulse](https://www.linkedin.com/pulse/son-site-custom-en-2h-avec-claude-code-m%C3%A9thodes-et-prompts-paillard-7q8je/)

**Автор**: Boris Paillard — колишній викладач Le Wagon, співзасновник mixt.care
**Оцінка**: 3/5

---

## Підсумок

Воркфлоу створення кастомного вебсайту приблизно за 2 години з Claude Code, зосереджений на підході «design-first». Основна теза: Claude Code виконує ваш дизайнерський смак — він його не замінює. Ви маєте визначити дизайн-систему до промптингу, інакше кожна згенерована сторінка дрейфуватиме.

Метод із чотирьох кроків із конкретними промптами, опублікованими в статті:
1. **brand-book.html**: палітра кольорів із семантичними ролями, шрифти, CSS-змінні
2. **ui-kit.html**: базові компоненти, задокументовані з Tailwind CSS
3. **Повна розробка сайту**: анімації прокручування, sticky-зображення, statement-футери
4. **Умовні форми** (бонус) — багатокрокові форми на основі JSON з Google Apps Script

Конкретний проєкт: mixt.care (персоналізована дерматологія). Стек: Tailwind CSS + vanilla JS (Intersection Observer).

---

## Обґрунтування оцінки

**3/5 — релевантно, інтегрувати як приклад із практики.**

Метод із чотирьох кроків структурно обґрунтований, а 4 промпти конкретні й придатні до використання. Ключова думка (еталонні HTML-файли як персистентний контекст Claude Code) не задокументована в посібнику й справді придатна для повторного використання.

Однак: немає покриття WCAG/доступності, немає відмінності від Cursor/Copilot, немає репозиторію GitHub для перевірки результатів і немає обговорення підтримуваності після MVP. Технічні розділи посібника потребують суворіших джерел.

---

## Виявлена прогалина → вжита дія

**Прогалина**: у посібнику не було документації патерну «Design Reference File» — збереження `brand-book.html` і `ui-kit.html` у корені проєкту як постійних файлів контексту для Claude Code. Цей патерн забезпечує дизайнерську узгодженість усіх згенерованих сторінок без повторного промптингу.

**Дія**: додано `examples/claude-md/design-reference-file.md` — окремий шаблон патерну з:
- Рекомендованою структурою проєкту
- Фрагментом CLAUDE.md для активації автоматичного посилання на дизайн-систему
- Промптом для brand-book.html із вбудованим аудитом WCAG
- Промптом для документації ui-kit.html
- Промптом аудиту кольорів (відповідність WCAG 2.1, симуляція дальтонізму, пропозиції виправлень)

Жодних змін у `ultimate-guide.md` — патерн задокументовано як приклад, а не піднято до розділу посібника. Оцінка не виправдовує центрального розміщення.

---

## Чого стаття НЕ охоплює

- Доступності WCAG / коефіцієнтів контрасту для згенерованої палітри
- Підтримуваності після MVP за 2 години (технічний борг, еволюція компонентів)
- Чому саме Claude Code, а не Cursor чи Copilot
- Немає репозиторію GitHub чи живого коду для перевірки заявленого результату
