## Підсумок

Пояснення простою мовою, що охоплює: що таке token і що вміщують 1M token (кодові бази, юридичні документи, наукові статті), твердження, що 1M контексту став GA 13 березня для Opus 4.6, порівняння цін з OpenAI GPT-5.4 / Google Gemini 3.1 Pro / Meta Llama 4, вплив на воркфлоу Claude Code (менше compaction, сесії з усією кодовою базою), корпоративні сценарії (перевірка відповідності вимогам, міграція кодової бази, реагування на інциденти), ефект «загублене посередині» як постійне обмеження, оцінку MRCR v2 (78.3% у Opus 4.6) і цитати Jon Bell (CPO Codeium) та Anton Biryukov (Ramp).

## Фактчекінг

| Твердження | Статус | Примітки |
|-------|--------|-------|
| 1M контексту GA 13 березня 2026 | **Не підтверджено** | Perplexity показує, що «бета» досі активна; 13 березня відповідає промоакції щодо використання, а не анонсу GA |
| Фіксована ціна $5/$25 за MTok, без надбавки за будь-якої довжини | **ХИБНО** | Надбавку 2x на вхід / 1.5x на вихід понад 200K token підтверджено (awesomeagents.ai, puter.com); це центральна теза статті |
| Базова ціна Opus 4.6 $5/$25 за MTok | Підтверджено | Узгоджується в кількох джерелах цін |
| Sonnet 4.6 $3/$15 за MTok | Підтверджено | Узгоджується в кількох джерелах цін |
| Кешовані зчитування $0.50/MTok (знижка 90%) | Правдоподібно | Стандартна знижка Anthropic на кешування |
| Записи в кеш $6.25/MTok | Правдоподібно | Стандартні ціни Anthropic на кешування |
| OpenAI GPT-5.4: подвійна ставка понад 272K | **Не перевірено** | Першоджерела не знайдено |
| Google Gemini 3.1 Pro: надбавка понад 200K | Частково підтверджено | Google справді бере надбавку; точні цифри відрізняються від статті |
| MRCR v2: 78.3% у Opus 4.6 | **Розбіжність** | Посібник цитує 76% із блогу Anthropic; стаття, можливо, посилається на інший варіант чи переглянутий прогін бенчмарку |
| Jon Bell (Codeium): на 15% менше compaction | **Неможливо перевірити** | Незалежного підтвердження не знайдено |
| Цитата Anton Biryukov (Ramp) | **Неможливо перевірити** | Незалежного підтвердження не знайдено |
| 600 зображень/PDF на запит (раніше 100) | **Не перевірено** | В офіційній документації API не підтверджено |
| Haiku обмежено 200K | Підтверджено | Узгоджується з відомими характеристиками |

**Критичний висновок**: відмінне твердження статті: «ставка Anthropic на фіксовану ціну, без надбавки незалежно від довжини». Це фактично хибно. Anthropic бере 2x за вхід і 1.5x за вихід понад 200K token. Увесь конкурентний аналіз цін, побудований на цій передумові, ненадійний.

## Порівняльний аналіз

| Аспект | Цей ресурс | Наш посібник |
|--------|--------------|-----------|
| Основи token (що таке token) | Охоплено, зрозуміло для початківців | Не охоплено: розраховано на розробників |
| Можливості контексту 1M | Загальні сценарії | Охоплено з бенчмарками MRCR + таблицями вартості |
| Ціни порівняно з конкурентами | Охоплено, але фактично хибно щодо фіксованої ціни | Частково охоплено (порівняння з Gemini, рядок 2053) |
| Події compaction | Згадує скорочення на 15% (неперевірна цитата) | Охоплено глибоко (architecture.md, рядки 391-438) |
| Ефект «загублене посередині» | Згадано з посиланням на arxiv:2307.03172 | Явно не охоплено |
| Корпоративні сценарії | Гіпотетичні, без виміряних даних | Охоплено в кількох розділах |
| Бенчмарк MRCR v2 | 78.3% (розбіжність із нашими 76%) | 76% із блогу Anthropic |
| Вплив на воркфлоу Claude Code | Добре обрамлення (фаза пошуку = 100K+ token) | Охоплено через compaction + context engineering |

## Нотатки виклику

Рецензія technical-writer погодилася, що оцінка 2/5 виправдана. Початкову пропозицію 3/5 знижено, бо фактчекінг руйнує ключову цінність статті: хибні дані про ціни не можуть доповнювати посібник, що прагне точності. Анекдот Povilas Korop (83% використання контексту на проєкті Laravel) є приємною реальною точкою даних, але він анекдотичний і недостатній, щоб змінити оцінку.

Ключовий висновок рецензії: справжній пункт дій «виправити застарілу інформацію в посібнику» не залежить від цього ресурсу. Якщо 1M контексту справді GA, наш посібник досі каже «бета» в рядках 2028-2070, і це треба виправити незалежно від цієї статті.

## Рішення

**Не інтегрувати.**

### Конкретні винятки

- Таблиця порівняння цін (центральне твердження про фіксовану ціну хибне)
- Корпоративні сценарії (гіпотетичні, без виміряних даних)
- Неперевірні цитати (Jon Bell, Anton Biryukov)

### Незалежні пункти дій, що випливли з цього рев'ю

1. **Перевірити статус GA для 1M** за офіційною документацією Anthropic / журналом змін API
2. **Якщо GA підтверджено**: оновити `guide/ultimate-guide.md`, рядки 2028-2070 (зараз там «бета»)
3. **Якщо GA підтверджено**: перевірити, чи змінилася взагалі структура надбавки за 200K
4. **Розглянути додавання**: одного рядка про ефект «загублене посередині» в `guide/core/context-engineering.md` (добре задокументоване обмеження, arxiv:2307.03172, незалежно від цієї статті)

### Варто незалежно перевірити

Шаблон воркфлоу Ramp (пошук у Datadog + Braintrust + БД + вихідному коді = 100K token ще до написання першого виправлення) є корисною ілюстрацією того, чому великі context window важливі для реальних інженерних воркфлоу; варто додати, якщо незалежне джерело це підтвердить.
