## 📄 Підсумок ресурсу

**Тип**: local-first вебзастосунок (Go + Svelte 5 + SQLite FTS5)

**Ключові моменти**:
1. **Повнотекстовий пошук** по сесіях за кілька місяців через SQLite FTS5 — миттєво знаходить конкретні обговорення
2. **Аналітика використання**: теплові карти активності, метрики швидкості, розподіл використання інструментів, статистика по проєктах
3. **Моніторинг у реальному часі**: стежить за каталогами сесій через Server-Sent Events, транслює повідомлення наживо
4. **Підтримка кількох CLI**: Claude Code + Codex + Gemini CLI (унікально в цій галузі)
5. **Local-first**: єдиний бінарний файл Go, ліцензія MIT, без облікових записів і хмари; експорт сесій як HTML або GitHub Gist

**Технічний стек**:
- Бекенд: Go (56,8% кодової бази)
- Фронтенд: Svelte 5 + Vite + TypeScript
- Сховище: SQLite з повнотекстовим пошуком FTS5
- Реальний час: Server-Sent Events (вбудований вебсервер)

## 🎯 Оцінка: 3/5

**Обґрунтування**: реальна прогалина в посібнику — жоден із задокументованих інструментів не поєднує повнотекстовий пошук і візуальну аналітику (теплові карти, швидкість) в локальному вебінтерфейсі.

- `claude-code-viewer`: базовий переглядач сесій, без пошуку, без аналітики
- `session-search.sh`: лише пошук у CLI, жодного UI, без аналітики
- `ccboard`: дашборд із фокусом на вартості, повнотекстовий пошук не підтверджено

AgentsView заповнює цю прогалину. Однак репозиторій створено 19 лютого 2026 року (за 4 дні до цього оцінювання), він мав 49 зірок (станом на 2026-07-28 — 4581, після перейменування на kenn-io/agentsview) і лише двох контриб'юторів. Занадто свіжий для 4/5 (висока цінність) без усталеного прийняття. Авторитет Wes McKinney (творця pandas) — сильний позитивний сигнал.

## 📍 Рекомендації щодо інтеграції

### Основна: `guide/ops/observability.md` — зовнішні інструменти моніторингу

Додати рядок у порівняльну таблицю (після ccboard):

```markdown
| **AgentsView** | Local web app | FTS search + activity heatmaps + velocity metrics + real-time monitoring. Multi-CLI (Claude/Codex/Gemini). No cost tracking. | `github.com/wesm/agentsview` |
```

Додати до Decision Guide:
```
Want search + visual analytics in one local UI?  → AgentsView
```

### Додаткова: `guide/ecosystem/third-party-tools.md` — керування сесіями

Додати короткий запис після `claude-code-viewer` з явним розмежуванням:

| Інструмент | Фокус | Пошук | Аналітика |
|------|-------|--------|-----------|
| claude-code-viewer | UI-переглядач | Ні | Ні |
| AgentsView | Пошук + аналітика | ✅ FTS5 | ✅ Теплові карти, швидкість |
| session-search.sh | Пошук у CLI | ✅ Швидкий | Ні |

## 🔥 Виклик (technical-writer)

Агент-виклик рекомендував **3/5** (замість початкових 4/5) з таких причин:

1. **Оцінка**: 4/5 вимагає перевірюваних сигналів прийняття. Репозиторію 4 дні, 49 зірок → 3/5 правильно.
2. **Розміщення скориговано**: `observability.md` (аналітика/моніторинг) — правильне місце, а не `third-party-tools.md`. Посібник прямо зазначає, що third-party-tools.md — це «не саморобні скрипти моніторингу (див. Observability)». AgentsView — аналітичний дашборд.
3. **Перетин із ccboard**: суттєвіший, ніж оцінювалося спочатку. Потрібно явно задокументувати різницю: ccboard = вартість + перегляд сесій; AgentsView = FTS-пошук + аналітика поведінки.
4. **Бракувало в початковому оцінюванні**: тип моделі (тепер підтверджено: відкритий код MIT), точний стек (підтверджено Go, а не Rust), твердження «nothing leaves your machine» — маркетингове (не перевірено аналізом трафіку).

**Прийнято**: оцінку скориговано до 3/5. Розміщення змінено на `observability.md`.
