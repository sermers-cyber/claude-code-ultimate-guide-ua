# Оцінка ресурсу №080: Goose (Block), ШІ-агент програмування з відкритим кодом

**Джерело:** [block.github.io/goose](https://block.github.io/goose) / [github.com/block/goose](https://github.com/block/goose)
**Тип:** інструмент із відкритим кодом (Apache 2.0), ШІ-агент програмування, що працює на машині користувача
**Автор:** Block (раніше Square), підтримується інженерною командою Block
**Оцінено:** 2026-03-17
**Зрілість на момент оцінки:** офіційний запуск у січні 2025, 33 166 зірок (станом на 2026-07-28 уже 51 819), 3 058 форків

---

## Підсумок

- **ШІ-агент програмування на машині користувача**: локальний CLI + десктопний застосунок, не хмара. Автоматизує складні інженерні завдання наскрізно
- **Незалежний від моделі**: працює з Claude (рекомендовано для виклику інструментів), GPT-4o, Gemini, Groq, локальними моделями (Ollama), понад 20 провайдерів
- **Recipes (рецепти)**: версіоновані, поширювані, параметризовані багатокрокові воркфлоу. Відрізняються від «файлів правил»: рецепти визначають, що роблять агенти, а не як вони поводяться
- **Оркестрація субагентів**: запуск спеціалізованих агентів автономно або через підрецепти, з динамічним перемиканням моделей залежно від завдання/вартості
- **Підтримка 1 700+ MCP-серверів** (перший агент із відкритим кодом, що підтримав MCP, січень 2025)
- **Goose Grant Program**: Block фінансує розробників розширень для Goose (запущено в липні 2025)
- **Custom Distributions**: команди можуть створювати брендовані дистрибутиви Goose із наперед налаштованими провайдерами, розширеннями та брендингом
- **Підтримується Block** (Square, Cash App): інституційні інженерні ресурси, а не сольний проєкт

## Що потрібно оновити в §11.1

### 1. Статистика (застаріла)

| Поле | Поточний посібник (січень 2026) | Фактично (березень 2026) |
|-------|--------------------------|-------------------|
| Зірки GitHub | 15 400+ | 33 166 (станом на 2026-07-28 уже 51 819) |
| MCP-сервери | 3 000+ (таблиця) проти 1 700+ (неузгодженість) | 1 700+ (за документацією Goose) |
| Релізи | 100+ | ~175+ (оцінка, швидкий темп релізів) |

**Виправлення**: оновити таблицю метрик і усунути неузгодженість 3 000 проти 1 700 щодо MCP.

### 2. Recipes: відсутні

Recipes є еквівалентом слеш-команд і skills Claude Code, поєднаних разом. Вони:
- Версіоновані, поширювані як окремі воркфлоу
- Імпортуються через deeplinks
- Параметризовані (повторно використовуються в різних контекстах)
- Можуть спільно використовуватися командами

Це безпосередньо стосується розділу посібника, що докладно документує команди та skills. Доречний один абзац із перехресним посиланням на §3 (команди) і §4 (skills).

### 3. Оркестрація субагентів: відсутня

Дорожня карта Goose за липень 2025 запровадила оркестрацію субагентів: запуск спеціалізованих субагентів (Planner, Architect, Frontend Dev, Backend Dev) із динамічним перемиканням моделей на кожного агента. Приклад із Berkeley Agentic AI Summit: 7 агентів спільно створили full-stack застосунок менш ніж за годину.

Це перетинається з власними мультиагентними патернами Claude Code (§9). Абзац-виноска з порівнянням до інструмента Agent у Claude Code допоможе читачам зрозуміти архітектурну різницю (Claude Code: один агент + запуск через Tool проти Goose: мультиагентні підпотоки, визначені рецептом).

### 4. agentskills.io: перевірити живий статус

Абзац «Skill Portability» посилається на agentskills.io. **Перевірено, працює** (2026-03-17). Зміни не потрібні.

## Виклик (technical-writer agent)

**Оцінку підтверджено: 4/5 (прохід оновлення)**

Ключові пункти:
- 15.4k → 33k зірок: занижений удвічі показник свідчить, що розділ не підтримувався. Це ерозія довіри, а не просто промах у метриці.
- Розбіжність щодо MCP (3 000 проти 1 700): одне з чисел хибне. Виправити до публікації будь-якого оновлення.
- Recipes і субагенти відсутні: найближча аналогія Goose до skills і мультиагентності Claude Code. Їх слід задокументувати.
- Ризик неоновлення: низька терміновість для читачів, помірна для довіри до посібника як актуального довідника.
- Обсяг: оновлення на 30 хвилин, а не реструктуризація.
