## Підсумок

Vitals — це plugin для Claude Code (v0.1 alpha, MIT, стандартна бібліотека Python + git), який знаходить гарячі точки коду за допомогою складеної метрики: `git churn × structural complexity × coupling centrality`. Потім Claude читає позначені файли й дає семантичний діагноз замість сирих метрик.

**Ключові моменти**:
1. Обчислює churn × складність × центральність зв'язаності: жоден лінтер не робить такої комбінації
2. Claude читає файли з верхівки списку: діагноз звучить як «цей клас відповідає за маршрутизацію, кешування, обмеження частоти запитів І метрики на 7 137 рядках», а не просто «висока складність»
3. Фонове відстеження правок, згенерованих AI, через hooks PostToolUse
4. Нуль залежностей, нуль API-ключів: лише стандартна бібліотека Python + git
5. v0.1 alpha: основне виявлення працює, відстеження трендів заплановано на v0.2+
