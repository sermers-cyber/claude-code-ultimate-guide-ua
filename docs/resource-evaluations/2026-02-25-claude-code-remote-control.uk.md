## 1. Підсумок змісту

Remote Control дає змогу продовжити локальну сесію Claude Code з телефона, планшета чи вебоглядача (claude.ai/code або мобільний застосунок Claude на iOS/Android).

**Два режими активації:**
- `claude remote-control` - нова підкоманда CLI
- `/remote-control` або `/rc` - slash-команда з активної сесії

**Ключова архітектура:**
- Виконання на 100% локальне - усю роботу робить термінал
- Мобільний/вебінтерфейс - це віддалене вікно в локальну сесію
- Лише вихідний HTTPS, нуль вхідних портів, короткоживучі облікові дані з обмеженими правами

**Доступність:** Research Preview на планах Pro і Max. НЕДОСТУПНО на Team, Enterprise чи з API-ключами.

**Функції:** QR-код + URL сесії для швидкого підключення, автоматичне ввімкнення через `/config`, команда `/mobile` з посиланнями на завантаження застосунку.

**Обмеження:** 1 віддалена сесія за раз, термінал має лишатися відкритим, мережевий тайм-аут ~10 хв.

## 5. Заперечення (технічне рев'ю)

**Скоригована оцінка: 4/5** (було 5)

**Причини зниження:**
- Research preview, не GA → ризик задокументувати вміст, що зміниться
- Обмеження планами Pro/Max → більшість професійних користувачів (Team/Enterprise) не мають доступу
- Офіційна документація Anthropic уже доступна → посібник не є першим джерелом для ранніх користувачів

**Пропущене в початковій оцінці:**
- Різниця між процесом у CLI (`claude remote-control` з прапорцями `--verbose`, `--sandbox`) і slash-командою (`/rc` без прапорців)
- Вплив на корпоративні середовища з проксі/VPN/суворим фаєрволом
- Команда `/mobile` для завантаження застосунку Claude (згадана в документації, але не в нашому посібнику)
- Порівняння з наявними альтернативами (SSH + мобільний термінал, tmux, VS Code remote)

**Ризики відмови від інтеграції:**
- Короткостроково (1-2 тижні): низькі, ранні користувачі читають документацію Anthropic
- Середньостроково (1 місяць): помірні, якщо функція стане GA
- Довгостроково: високі, якщо remote-control стане стандартним режимом взаємодії

**Головний ризик: надмірно задокументувати нестабільну preview-функцію** → рішення: документувати з чітким застереженням «Research Preview»

### Додана цінність порівняно з офіційною документацією

Завдяки відгукам спільноти посібник може дати **оригінальний вміст**, якого немає в документації Anthropic:

1. **Обмеження slash-команд у віддаленому режимі** (`/new`, `/compact` сприймаються як текст) - не задокументовано
2. **Патерн кількох сесій у tmux** для обходу обмеження однієї сесії
3. **Архітектура постійного сервера**: tmux + віддалена VM + remote-control
4. **Аналіз безпеки від спільноти**: поверхня RCE, наслідки для CISO, найкращі практики (захищена робоча станція)
5. **Порівняння альтернатив**: happy.engineering, OpenClaw, SSH-тунелі, налаштування на VPS
