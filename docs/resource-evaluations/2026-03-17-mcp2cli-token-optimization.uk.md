## Короткий підсумок

mcp2cli перетворює MCP-сервери, специфікації OpenAPI та схеми GraphQL на CLI-команди часу виконання, прибираючи вставляння схем інструментів із промптів LLM. Проєкт заявляє 96-99% економії токенів завдяки відмові від накладних витрат на схеми та ще 40-60% завдяки кодуванню TOON для виводу у вигляді масивів. Проєкт створено 8 днів тому, він має 1 261 зірку та інтеграцію зі skill для Claude Code. Архітектурне спостереження слушне: вставляння схем інструментів MCP є задокументованим чинником витрат в агентних воркфлоу. Проте інструмент надто новий, щоб рекомендувати його для продакшену. Є й структурна невідповідність внутрішній архітектурі MCP у Claude Code: Claude Code керує MCP-з'єднаннями нативно, тож підхід mcp2cli з усуненням схем погано лягає на стандартний воркфлоу Claude Code.

## Зміст ресурсу

- **Основний механізм**: перетворює визначення MCP-серверів, специфікації OpenAPI та схеми GraphQL на CLI-інструменти часу виконання без жодної генерації коду; під час виклику звертається до відповідного сервера
- **Заяви про економію токенів**: скорочення на 96-99% завдяки прибиранню схем інструментів із промптів; ще 40-60% завдяки TOON (Tree-Optimized Output Notation) для виводу у вигляді масивів
- **Можливості**: підтримка OAuth, кешування специфікацій, керування секретами, режим `bake` (пакетні команди), інтеграція з jq для фільтрації
- **Skill для Claude Code**: `npx skills add knowsuchagency/mcp2cli --skill mcp2cli` встановлює його як skill для прямого використання в сесіях
- **Підтримувані джерела**: MCP-сервери (stdio, HTTP/SSE), OpenAPI 2.x/3.x, схеми GraphQL
- **Контриб'ютори**: 3 | **Відкриті issues**: 0 | **Останній коміт**: 2026-03-17

## Оцінка ризиків

**Структурна невідповідність Claude Code**: Claude Code керує MCP-з'єднаннями всередині власного середовища виконання. Головна цінність mcp2cli, тобто заміна вставляння інструментів MCP викликами CLI, не стосується стандартного воркфлоу Claude Code, де схеми інструментів вставляє хост. Задуманим шляхом інтеграції є skill для Claude Code (`npx skills add`), але він позиціонує mcp2cli як допоміжний інструмент, а не заміну нативного MCP. Користувачі, які чекають «встановив mcp2cli і заощадив 96% токенів у Claude Code», будуть розчаровані. Реальний сценарій використання ближчий до такого: застосовувати mcp2cli у скриптах, hooks або поза Claude Code, де ви самі контролюєте вставляння інструментів.

**Зрілість**: 8 днів від створення. Жодної історії використання в продакшені. 0 відкритих issues може означати, що інструмент надійний, а може означати, що його ще не перевіряли під навантаженням. Стек залежностей Python (typer, httpx, pydantic) зрілий, але поверхня інтеграції з довільними MCP-серверами широка.

**Заяви про економію токенів**: цифра 96-99% посилається на зовнішній допис у блозі й не спирається на контрольований бенчмарк відносно визначеної бази порівняння. Економія від кодування TOON правдоподібна для виводу з великою кількістю масивів, але незалежно не перевірена.
