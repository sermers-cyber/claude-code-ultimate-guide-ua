## 1. Підсумок змісту

Розлога стаття (~9 хв читання), що крок за кроком показує побудову мінімального агента на кшталт Claude Code у чотири етапи: базовий виклик API, контекстне вікно (історія повідомлень), виклик інструментів і агентний цикл, що поєднує все це. JavaScript/Node.js, Anthropic API (Claude Sonnet 5). Код наведено для кожного етапу, включно зі схемою інструмента `searchCode` і спрощеним циклом агента. Розглядає `stop_reason`, зв'язування через `tool_use_id` і попереджає про ризик prompt injection, коли вивід інструмента повертається в контекст без фільтрації.

**Ключові твердження**: агент = LLM + контекст + інструменти + цикл + умова зупинки; виклик інструмента — це запит, а не пряме виконання, і застосунок вирішує, чи його виконувати; цикл повторюється, доки `stop_reason` не перестане бути `tool_use`.

### Обґрунтування

**Сильні сторони**: реальний технічний зміст (не рекламний допис), робочий код, супровідний репозиторій на GitHub, розглядає prompt injection, чого багато аналогічних англомовних туторіалів ледь торкаються.

**Слабкі сторони**:
- **Жодної прогалини не заповнено**: `guide/core/architecture.md` §1 «The Master Loop» (рядок 109) уже документує той самий механізм (цикл, `tool_use`, `stop_reason`) з офіційним джерелом Anthropic рівня Tier 1. Стаття лише повторно, з навчальною метою, демонструє те, що посібник уже пояснює з надійнішим джерелом.
- **Суперечить мовному правилу репозиторію**: зміст на 100% французькою, тоді як цей репозиторій повністю англомовний (запам'ятоване тверде правило). Французьке джерело не можна цитувати як посилання в посібнику без перекладу, а це не має сенсу для туторіалу, цінність якого саме в тому, щоб його читали як є.
- **Неоригінальний навчальний патерн**: формула «агент = LLM + контекст + інструменти + цикл + умова зупинки» та її демонстрація в 4 послідовних кроках — усталений жанр із середини 2025 року, популяризований Thorsten Ball (команда Amp) у «How to Build an Agent» (https://ampcode.com/blog/how-to-build-an-agent), який широко цитують як еталон жанру. Пошук у мережі (2026-08-05) виявив щонайменше 6 аналогічних туторіалів, опублікованих між травнем і липнем 2026 року, з тією самою структурою.
- **Автора вже оцінювали на 2/5**: попередній допис цього ж автора в LinkedIn (команда `/insights`, оцінка від 2026-02-06, див. [kajan-siva-insights-command.md](./kajan-siva-insights-command.uk.md)) визнали таким, що не має придатного до використання технічного змісту. Ця стаття значно ґрунтовніша, але підтверджує закономірність: доступний зміст, але ніколи не найщільніше джерело на свою тему.

**Порівняння з нашими критеріями**:
- Прорив / нова можливість? ❌
- Небачена технічна глибина? ❌ (уже охоплено, джерело слабше за офіційне)
- Практичні приклади? ✅ (робочий репозиторій на GitHub)
- Заповнює прогалину посібника? ❌
- Підтвердження спільнотою? ⚠️ (не вимірювалося, сильного сигналу не знайдено)

## 4. Рішення щодо інтеграції

### Рішення: **НЕ ІНТЕГРУВАТИ** ❌

**Обґрунтування**:
1. Жодної прогалини не заповнено, механізм уже задокументовано з надійнішим джерелом.
2. Французький зміст, несумісний із мовним правилом репозиторію (лише англійська).
3. Жанр «побудуй власного агента, щоб зрозуміти» заслуговує на запис у `guide/roles/learning-with-ai.md` § External Resources, але з канонічним англомовним джерелом цього жанру, а не з цим.

### Альтернативна дія

Додано **Thorsten Ball, «How to Build an Agent»** (https://ampcode.com/blog/how-to-build-an-agent) до `guide/roles/learning-with-ai.md` § External Resources замість цієї статті: той самий навчальний жанр (зрозуміти агентний цикл, будуючи його), англійською, найцитованіше джерело жанру.
