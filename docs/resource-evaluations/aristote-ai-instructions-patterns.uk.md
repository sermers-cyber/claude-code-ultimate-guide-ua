## Виявлені й закриті прогалини

### 1. Політика розкриття ШІ-коду
**Прогалина**: не було командного патерну врядування щодо видимості коду, згенерованого ШІ.
**Виправлення**: додано розділ «AI Code Disclosure Policy» наприкінці розділу 3.5.
**Зміст**: поріг >10 рядків, шаблон PR, поступове посилення вимог за рівнями, попередження про антипатерн.

### 2. claude-mem з Gemini (оптимізація витрат)
**Прогалина**: посібник казав «AI summarization via Claude», пропускаючи альтернативу Gemini 2.5 Flash ($14/місяць проти $102 для Haiku, -86%).
**Виправлення**: додано блок «Cost optimization — use Gemini instead of Claude» у розділ claude-mem.
**Джерело даних**: `claude-mem-analysis-corrected.md` (553 сесії, ~400/місяць, виміряні витрати).

### 3. Співіснування hooks з claude-mem
**Прогалина**: інструкції зі встановлення не попереджали про ризик перезапису масиву hooks.
**Виправлення**: додано «Critical installation gotcha — hooks coexistence» з прикладами JSON до/після.
**Джерело**: `claude-mem-install-prompt.md` (6 наявних hooks, явний чекліст їх збереження).

### 4. Fail-open у claude-mem (v9.1.0+)
**Прогалина**: не згадувалася поведінка з погляду надійності, коли воркер не працює.
**Виправлення**: додано блок «Reliability: fail-open architecture» з інструкціями з перезапуску.
