## Зміст

prismantis перемальовує те, що Claude Code показує в терміналі. Відповіді отримують кольорові таблиці, підсвічування синтаксису Prism для 24 мов, блок-схеми mermaid, діаграми послідовностей, станів, класів і ER, графіки `xychart-beta`, кругові діаграми та блоки `figure`, намальовані так, як написано. Рядки інструментів стають однорядковими підсумками, а редагування — картками diff. Вивід slash-команд і власні промпти користувача теж отримують новий стиль. Кожен блок має кнопки копіювання, а `/prismantis copy` покриває роботу лише з клавіатури.

Він побудований на API модів, що з'явився в Claude Code 2.1.287 (1 жовтня 2026): hook `ui.render` отримує кожен фрагмент транскрипту перед відмальовуванням і повертає те, що слід намалювати замість нього. Допис мейнтейнера про запуск (https://www.catchkill9.dev/posts/prismantis.html) датує перший реліз 2 жовтня 2026.

Єдине, що він надсилає моделі, — це опційна примітка `diagramHints`, яка додається до кожного промпту й повідомляє Claude, що вміє малювати термінал. README наводить близько 630 токенів на промпт (близько 275 для основної частини, близько 360 для частини з фігурами) і ще близько 80, коли увімкнено `latex`, підраховано токенізатором Claude.

## Вивід валідатора (коміт `dc51f35`, v0.38.2)

`claude plugin validate` пройшов з одним попередженням щодо директорії plugin (немає іконки). Релевантні рядки:

- `hooks:` містить `ui.render` для повідомлень асистента, повідомлень користувача, рядків інструментів і виводу команд, а також `tool.call`, `prompt.submit`, `turn.complete`, `session.start` і `command.run{command=prismantis}`
- `calls:` містить `$.process.run` (через допоміжний засіб буфера обміну й верстку LaTeX), `$.ui.copy`, `$.fs.read`, `$.fs.stat`, `$.config.set` і `$.session.messages`
- `env writes: nothing`; змінні середовища, які читаються, — це змінні визначення термінала (`TERM_PROGRAM`, `SSH_CONNECTION`, `TMUX`, `KITTY_WINDOW_ID` тощо)
- П'ять блокувальних hooks без `.catch` (`tool.call`, `prompt.submit`, `ui.focus`, `ui.scroll` на його панелі налаштувань, `prismantis.markdown`). Це повідомлення валідатора, а не спостережена відмова

Те, що `tool.call` є блокувальним hook, означає, що мод стоїть на шляху викликів інструментів. Ніщо в цій оцінці не показує, що він змінює виклики інструментів; README описує лише відмальовування. Саме таку декларацію варто перечитувати під час кожного оновлення.

## Місце відносно наявного покриття посібника

Посібник пояснює моди в `guide/ultimate-guide.md` (Claude Mods v2.1.287+) на прикладах Anthropic, але без прикладу від спільноти. `guide/ecosystem/third-party-tools.md` перелічує замінні інтерфейси в розділі Alternative UIs (Claude chic, Toad, Conductor). prismantis не є ні тим, ні іншим: він зберігає власний інтерфейс Claude Code і змінює те, як його відмальовано. Жоден наявний запис не охоплює рендеринг у терміналі, точність копіювання в Slack чи вартість у токенах для мода, який додає контекст моделі.

Примітка `diagramHints` — це також конкретний задокументований випадок, коли plugin додає контекст до кожного промпту, що пов'язується з матеріалом посібника з context engineering: вартість нараховується за кожен промпт, на рівні користувача, і не видна в транскрипті.

## Рішення

**Інтегровано** в `guide/ecosystem/third-party-tools.md`, новий розділ «Terminal rendering (mods)», з рядком для персони в «Recommendations by persona». Запис подає вартість `diagramHints` як цифру з README, пояснює, коли вимикати підказки, показує перевірку валідатором та її обмеження, і датує відповідь мейнтейнера на issue #319.

**Не зроблено**: перехресне посилання з розділу про моди в `guide/ultimate-guide.md`. Hook проти ознак ШІ-тексту в репозиторії оцінює весь файл після редагування, а цей файл уже містить довгі тире в прозі, тож редагування було відхилено. Додати перехресне посилання, щойно їх буде виправлено.

**Відкриті прогалини в доказах**: виміряти фактичну вартість у токенах на промпт (`/context` з `diagramHints` і без) та перевірити рендеринг у застосунку Desktop і VS Code.
