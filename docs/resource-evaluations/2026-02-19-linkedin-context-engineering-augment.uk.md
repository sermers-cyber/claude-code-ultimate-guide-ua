## Рішення

### Оцінка: **2/5**: НЕ рекомендовано для інтеграції

**Причини**:
1. Концепцію «Context Engineering» уже краще задокументовано в посібнику (блог Anthropic, ArXiv, розділ методологій)
2. Продукт, що просувається (Augment Context Engine MCP), розглянуто в окремій оцінці (оцінка 3/5) зі значно кращим фактичним висвітленням
3. Анонімне особисте свідчення («удвічі швидше на ML-конвеєрі на 30 тис. рядків») неможливо перевірити - додавання його до посібника знизило б довіру
4. Єдина унікальна практична цінність - «Оновіть CLAUDE.md, щоб завжди використовувати MCP для індексування» - це одне речення, яке можна за бажання додати до примітки про інтеграцію Augment

**Один елемент, який можна виокремити** (необов'язково):
Якщо/коли Augment Context Engine буде інтегровано (згідно з рекомендацією щодо Ресурсу 2), додати патерн інструкції для CLAUDE.md:
```markdown
> **CLAUDE.md tip**: Add an instruction to always use the Context Engine MCP for
> repository questions: "Use augment_search for any question about the codebase structure."
```
Це дрібне практичне доповнення, яке не виправдовує повної інтеграції цього допису.
