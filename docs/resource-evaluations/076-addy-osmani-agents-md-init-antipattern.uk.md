## 1. Підсумок змісту

Критика на основі досліджень робочого процесу автогенерації `/init` для файлів контексту AGENTS.md / CLAUDE.md, що синтезує дві академічні статті 2026 року з практичними архітектурними рекомендаціями.

**Ключові твердження**:
- **Дослідження ETH Zurich**: файли контексту, згенеровані LLM, знижують успішність завдань на 2-3% і роздувають витрати на 20%+, бо агенти й так можуть виявити те, що містять ці файли
- **Lulla et al. (ICSE JAWs 2026)**: файли контексту, написані людьми, скоротили реальний час виконання на 28,64%, а споживання токенів на 16,58% — але лише тому, що містили справді невиявлювану інформацію
- **Фільтр виявності (discoverability filter)**: єдиний критерій додавання рядка — чи може агент знайти це, читаючи код; якщо так, видаліть
- **Ефект якоріння «pink elephant»**: згадка технології в CLAUDE.md зміщує агента до неї в кожній сесії, навіть якщо вона застаріла або рідко використовується
- **Статичні монолітні файли архітектурно хибні**: вони завантажують той самий контекст незалежно від типу завдання, марнуючи токени на нерелевантні інструкції
- **Фреймворк ACE (ICLR 2026)**: динамічний шар маршрутизації перевершив статичні підходи CLAUDE.md на 12,3% на бенчмарках агентів
- **Автоматизована оптимізація Arize AI**: ітеративне навчання промптів дало +5,19% точності між репозиторіями, +10,87% в межах репозиторію
- **Зміна ментальної моделі**: CLAUDE.md як діагностичний інструмент тертя кодової бази, а не постійна конфігурація

**Глибина**: ~3 500 слів, синтез досліджень + практичні архітектурні рекомендації. Довіра до джерела висока — Osmani є директором Google Cloud AI, стаття цитує рецензовані статті 2026 року.

## 4. Рекомендації щодо інтеграції

### Де інтегрувати

**Основне: §3.1 Memory Files (CLAUDE.md) — рядок ~4589**

Додати окремий підрозділ «The Discoverability Filter» одразу після наявного розділу «Minimum Viable CLAUDE.md»:

```markdown
### The Discoverability Filter

Before adding any line to CLAUDE.md, apply this test: **can the agent discover
this by reading the codebase?** If yes, don't add it.

Two 2026 research studies quantify the cost of ignoring this: LLM-generated
context files (the output of `/init`) reduce task success by 2-3% and inflate
costs by 20%+ because they duplicate what agents find by exploring the repo
anyway (ETH Zurich, 2026). Human-authored files that contain genuinely
non-discoverable information perform better: -28.64% wall-clock time,
-16.58% token consumption (Lulla et al., ICSE JAWs 2026).

What earns a line:
- Tooling preference that can't be inferred: `Use uv, not pip`
- Operational landmine: `legacy/ is deprecated but imported by prod — do not delete`
- Non-obvious convention: `auth module uses custom middleware — do not refactor to Express standard`

What does not earn a line:
- Directory structure (agent reads it in the first tool call)
- Tech stack (agent reads package.json / go.mod / Cargo.toml)
- Testing conventions (agent reads existing tests)
```

**Додаткове: документація команди `/init` — рядок ~21308**

Додати примітку-попередження поруч зі списком команд про те, що автоматично згенерований вивід, як правило, надлишковий і може шкодити продуктивності.

**Третинне: нове попередження «Context Anchoring» у §3.1**

Додати callout про ефект pink elephant / якоріння: згадка технології в CLAUDE.md зміщує агента до неї в кожній сесії. Застарілі записи гірші за відсутність записів.

**Опційно: розділ просунутих патернів**

3-шарова архітектура динамічної маршрутизації (файл протоколу + файли persona/skill + субагент супроводу) могла б розміститися в §4 (агенти) або §9 (просунуті воркфлоу) як архітектурний патерн для команд, що запускають агентів у масштабі.

### Пріоритет

**Високий**: використання `/init` поширене, антипатерн кількісно оцінений, а посібник уже дає правильну пораду без доказів на її підтримку. Додавання даних посилює довіру до посібника.
