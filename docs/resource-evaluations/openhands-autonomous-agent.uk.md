## 📄 Зміст

- **Раніше OpenDevin**, open-source платформа хмарних агентів для коду, яку підтримує All Hands AI
- **Делегування субагентам**: головний агент-планувальник будує граф залежностей (Tier 0 виконується паралельно, Tier 1 стартує щойно розв'язано його конкретну залежність, не чекаючи повного завершення Tier 0)
- **Злиття керує «integrator»**: об'єднує файли, розв'язує шляхи імпорту, з'єднує виклики API з фронтендом, запускає повний набір тестів
- **Ізольована пісочниця**: виконання в захищеному середовищі, вбудована можливість аудиту
- **OpenHands Cloud/Enterprise**: «Agent Control Plane» для керування в масштабі (запобіжники, бюджети, внутрішній маркетплейс plugins), функції доступні лише в платній пропозиції, а не в open-source ядрі

## 🔥 Перевірка

**Перевірене заперечення**: «Хіба OpenHands — це не просто SWE-agent із більшою кількістю зірок?»

**Відповідь**: ні, структурна відмінність полягає в паралельному виконанні за графом залежностей (SWE-agent послідовний, розрахований на одну GitHub issue за раз) і в наявності автоматизованого шару інтеграції/злиття. Це найближчий OSS-кандидат до патерну «ізольована паралельна збірка + злиття» з доповіді WeScale/Maleus, а єдиний прямий пропрієтарний конкурент — Devin.

**Ризик відмови від інтеграції**: читач, який шукає OSS-аналог Devin для власного хостингу, не знайде його в посібнику, хоча він існує і зріліший за більшість уже згаданих альтернатив.
