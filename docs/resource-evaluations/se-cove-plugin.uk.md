## Підсумок змісту

### Що таке SE-CoVe?

Адаптація Chain-of-Verification від Meta до програмної інженерії для Claude Code.

**Конвеєр**:
1. Baseline: генерує початкове рішення
2. Planner: створює запитання для перевірки на основі тверджень
3. Executor: відповідає на запитання незалежно (ніколи не бачить baseline)
4. Synthesizer: порівнює висновки, виявляє розбіжності
5. Output: видає перевірене рішення

**Ключова інновація**: верифікатор працює без доступу до чорнового коду (запобігає упередженню підтвердження).

## Метрики продуктивності (з наукової статті)

**Джерело**: Dhuliawala et al., «Chain-of-Verification Reduces Hallucination in Large Language Models», ACL 2024 Findings.

| Тип задачі | Метрика | Покращення | Обчислювальна вартість |
|-----------|--------|-------------|-------------------|
| Генерація біографій | FACTSCORE | +28% (55,9→71,4) | -26% обсягу виводу (16,6→12,3 факту) |
| QA без зовнішніх джерел (closed-book) | F1 Score | +23% (0,39→0,48) | ~2x споживання token |
| Запитання на основі списків | Precision | +112% (0,17→0,36) | Менше відповідей загалом |

**Модель**: Llama 65B (узагальнення на GPT-4/Claude/Sonnet не перевірено)
