## Унікальні уроки для вилучення

### 1. Метрики pass@k і pass^k
- Формальний підхід до верифікації:
  - pass@k: хоча б одна з k спроб успішна
  - pass^k: усі k спроб мають бути успішними
  - Приклад: k=3 → 91% pass@k, 34% pass^k
- Застосування: емпірично вимірювати ефективність skill

### 2. Воркфлоу plugin Hookify
- Створення hook у розмові (опишіть потребу → згенерується JSON)
- Знижує бар'єр порівняно з написанням JSON вручну
- Патерн: природна мова → структурована конфігурація

### 3. Субагенти в пісочниці
- Обмеження інструментів на агента (security-reviewer не може Edit)
- Запобігає випадковим руйнівним діям
- Реалізація: визначте `tools: [Read, Grep]` у конфігурації агента

### 4. Метод cascade (кілька інстансів)
- Керування кількома інстансами Claude: «Обходьте зліва направо, від найстарішого до найновішого»
- Фокус максимум на 3-4 завданнях
- Запобігає накладним витратам на перемикання контексту

### 5. Патерн Stop hook
- Автосумаризація наприкінці сесії (а не після кожного повідомлення)
- Фіксує: успіхи, невдачі, недосліджені шляхи
- Живить повторно використовувані skills

### 6. Skill creator з історії git
- Витягання патернів із реальних комітів
- Реалізація як plugin або локально
- Патерн: `git log` → визначення skill
