# Оцінка: agentskills.io, відкрита специфікація Agent Skills

**Дата**: 2026-02-01
**Джерело**: [agentskills.io](https://agentskills.io/home) | [GitHub: agentskills/agentskills](https://github.com/agentskills/agentskills) (8,2 тис. зірок, станом на 28.07.2026 вже 23 547) | [GitHub: anthropics/skills](https://github.com/anthropics/skills) (60,1 тис. зірок, станом на 28.07.2026 вже 164 580)
**Мейнтейнер**: Anthropic (відкрита розробка, внески спільноти)
**Тип**: відкрита специфікація + еталонна реалізація + офіційна бібліотека skills
**Ліцензія**: Apache 2.0 (специфікація + відкриті skills), source-available (document skills)

---

## Короткий зміст

- **Формальна специфікація** для Agent Skills: формат SKILL.md, YAML frontmatter, правила іменування, структура каталогів, модель поступового розкриття (progressive disclosure)
- **26+ підтримуваних платформ**: Claude Code, Claude.ai, GitHub, Cursor, VS Code, OpenAI Codex, Gemini CLI, Goose, Roo Code, Amp, Spring AI, Databricks, Factory, Mistral Vibe, TRAE, Firebender, Letta та інші
- **anthropics/skills** (60,1 тис. зірок): офіційний репозиторій Anthropic з прикладами skills (документи DOCX/PDF/PPTX/XLSX, творчі, для розробки, корпоративні) + інтеграція плагіна Claude Code
- **skills-ref CLI**: офіційний інструмент валідації та генерації XML-промптів (`skills-ref validate`, `skills-ref to-prompt`)
- **Посібник з інтеграції**: документація для додавання підтримки skills у будь-якого агента (на основі файлової системи або інструментів)

## Оцінка релевантності: 4/5

**Обґрунтування**:

1. **Підтверджено велику прогалину**: посібник документує skills як функцію Claude Code, не згадуючи, що це **відкритий міжплатформний стандарт**, який підтримує Anthropic. Для посібника, що претендує на статус довідника, це суттєвий пропуск.
2. **60,1 тис. зірок**: `anthropics/skills` є репозиторієм Anthropic з найбільшою кількістю зірок. Посібник згадує його мимохідь (`npx add-skill anthropics/skills` у 2 рядках), не описуючи ні вмісту, ні масштабу.
3. **agentskills.io відсутній**: формальна специфікація (правила іменування, поступове розкриття, посібник з інтеграції) ніде в посібнику не з'являється. А це ж джерело істини для функції, яку посібник документує.
4. **Сумісність як вагомий аргумент**: сказати користувачеві «ваші skills для Claude Code працюють також у Cursor, VS Code, Codex, Gemini CLI» означає дати інформацію з високою доданою цінністю.
5. **Чому не 5/5**: посібник уже добре документує skills для щоденного використання в Claude Code. Типовому користувачеві формальна специфікація для роботи зі skills не потрібна. Прогалина радше концептуальна (бракує контексту), ніж практична (бракує інструкцій).

## Перевірка на міцність (самокритика)

### Аргументи за +1 до оцінки (5/5):
- Посібник претендує на роль ГОЛОВНОГО довідника з Claude Code. Не згадати офіційну специфікацію функції, якій присвячено 800+ рядків, є прикрою прогалиною.
- 60,1 тис. зірок: це не нішевий проєкт. Це найпопулярніший репозиторій Anthropic.
- Сумісність (skills переносяться між 26+ інструментами) є важливим аргументом на користь, який посібник повністю пропускає.
- Поля `context` і `agent`, задокументовані в посібнику, НЕ входять до офіційної специфікації: потенційне джерело плутанини для читачів.

### Аргументи за -1 до оцінки (3/5):
- Пересічному користувачеві Claude Code формальна специфікація байдужа. Він хоче створити skill, який працює.
- Посібник уже добре документує практичний воркфлоу.
- agentskills.io є специфікацією для розробників агентів, а не для кінцевих користувачів.
- 60,1 тис. зірок anthropics/skills роздуті початковим ажіотажем: багато пасивних зірок.

### Вердикт перевірки:
Оцінку 4/5 збережено. Аргумент «специфікація для розробників агентів» слушний, але посібник уже документує внутрішню архітектуру (guide/core/architecture.md), hooks, протокол MCP: він не обмежується «інструкціями для користувача». Відсутність офіційної специфікації є реальною прогалиною, не критичною для щоденного використання, але суттєвою для повноти. Сумісність і anthropics/skills явно заслуговують на згадку.

### Пропущені моменти:
- **Модель загроз SafeDep** (safedep.io/agent-skills-threat-model) документує вразливості в специфікації (8-14% skills). Доречний аспект безпеки для `guide/security/security-hardening.md`.
- Блог Anthropic ["Equipping Agents for the Real World"](https://anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills) є первинним джерелом, на яке слід посилатися.
- Claude.ai також напряму підтримує skills (не лише Claude Code): потенційний аспект для cowork.

### Ризики в разі відмови від інтеграції:
**Помірні.** Читач, який відкриє для себе специфікацію agentskills.io, зрозуміє, що посібник описує skills як ізольовану функцію Claude Code, хоча вони міжплатформні. Втрата довіри щодо повноти.
