## Вердикт

logseq-wiki — нативний для Logseq порт obsidian-wiki, який сам є реалізацією патерну LLM Wiki від Andrej Karpathy: агент один раз компілює джерела у взаємопов'язані сторінки й підтримує їх актуальними, замість того щоб щоразу заново виводити відповіді через RAG. Порт змінює формат (властивості Logseq `key:: value` замість YAML frontmatter, посилання з простором імен `[[wiki/...]]`) і зберігає конвеєр: завантаження, видобування, розв'язання, схема.

Як інструмент він не заслуговує на місце в посібнику. Це порт одного автора з мінімальним поширенням, а патерн, який він реалізує, уже охоплено розділом про OKF в основному посібнику. Натомість він заслуговує на місце як приклад для аналізу. Його автономне завдання завантаження поєднує в одному запланованому запуску всі чинники, що перетворюють особисту базу знань на приймач prompt injection. Розділ посібника про отруєння пам'яті охоплював лише випадок спільної командної пам'яті.

## Що робить код, із джерелами

1. **Автономний запуск з усіма наданими дозволами, що живиться стороннім вмістом.** [`run_auto.sh` рядок 79](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/run_auto.sh#L79) запускає `claude -p "$PROMPT" --dangerously-skip-permissions`. Заголовок скрипту стверджує «No human in the loop». Його вхід — зібрана історія переглядів YouTube користувача, після чого сесія завантажує транскрипти сторонніх відео. [Prompt](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/auto-prompt.md) наказує сесії писати сторінки, комітити й пушити у віддалений репозиторій сховища.
2. **Авторство агента навмисно прибрано.** Той самий prompt забороняє трейлер `Co-Authored-By: Claude` у комітах сховища. Походження сторінок, написаних агентом, губиться на рівні git.
3. **Налагоджувальна точка доступу браузера відкрита для будь-якого джерела.** [`run_auto.sh` рядок 47](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/run_auto.sh#L47) запускає Chrome з `--remote-debugging-port=9222 --remote-allow-origins='*'` в окремому профілі, де є сесія YouTube із виконаним входом. Шаблон-зірочка вимикає перевірку походження, яку Chrome застосовує до WebSocket-з'єднань DevTools. Можливість експлуатації з вебсторінки тут не тестувалася.
4. **Захід пом'якшення, що існує, але не на відкритому шляху.** `wiki-ingest` підтримує режим проміжного зберігання (`WIKI_STAGED_WRITES=true`), який надсилає написані LLM сторінки та патчі до `wiki/_staging/` для рев'ю через `wiki-stage-commit`. Змінної немає в `.env.example`, тож проміжне зберігання за замовчуванням вимкнене, а автономний prompt пише безпосередньо в `wiki/<theme>/`.
5. **Документація, що суперечить коду.** [Коментар у launchd plist](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/ingest-youtube-history/scripts/com.logseq-wiki.yt-history.plist#L7) описує завдання як «semi-auto, no ingest». Скрипт, який він запускає, виконує повне завантаження, коміт і push.
6. **Фільтрування секретів лише через prompt.** [`claude-history-ingest` рядок 254](https://github.com/ystreibel/logseq-wiki/blob/339072e5d10db29a07d611b611e1122c74b3ac02/.skills/claude-history-ingest/SKILL.md#L254) читає транскрипти Claude Code (`~/.claude/projects/*/*.jsonl`) і покладається на інструкцію «Skip anything that looks like secrets». Жоден детермінований сканер не запускається до запису сторінок у сховище.

## Ідеї, варті уваги, але не інтегровані

- **Порівняння походження між інструментами** (`memory-bridge`): сторінки позначаються історією агента, з якої вони походять, а режим diff показує, що відомо з історії одного інструмента й чого немає в історії іншого. Новаторсько, але це один репозиторій без доказів використання.
- **Пакети контексту, обмежені токенами** (`wiki-context-pack`): сторінки, ранжовані за релевантністю, пакуються в межах бюджету токенів для наступного агента. У принципі вже охоплено поступовим розкриттям у `memory-systems.md`.
