## Що він робить

**Розв'язувана проблема**: Нативна команда `--resume` обмежена поточною робочою текою. Коли ви переносите проєкт або хочете відгалузити сесію в нову теку, сесія стає недоступною.

**Запропоноване рішення**:
1. **Глобальний пошук**: знаходить сесії в усіх проєктах із фільтрацією за ключовими словами
2. **Інтерактивний вибір**: фільтрує результати, виключає сесії поточної теки
3. **Автоматична міграція**: копіює `.jsonl` + теку subagents, генерує новий UUID
4. **Команда відновлення**: надає `claude --resume <new-id>` для негайного використання

**Технічна реалізація**:
- Використовує ripgrep для швидкодії
- Підтримка фільтрації (`cleanupPeriodDays: 90` для великих історій)
- Bash-скрипти: `search.sh` + `migrate.sh`
- Синтаксис команди: `/claude-migrate-session <source> <target>`
