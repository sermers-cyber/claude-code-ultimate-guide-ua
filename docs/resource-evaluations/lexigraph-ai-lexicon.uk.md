## Джерело та обсяг

[Lexigraph](https://www.lexigraph.org/fr/) керує Anthony Capirchio, а публікує The Operating Shift. Його [редакційний метод](https://www.lexigraph.org/fr/a-propos/) розкриває суттєве написання чернеток за допомогою моделей у межах визначених людьми словника, таксономії та правил письма, з названою редакційною відповідальністю.

Офіційний репозиторій [lexigraph-corpus](https://github.com/TheOperatingShift/lexigraph-corpus) експортує вміст як дані за ліцензією [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Його README явно виключає вихідний код вебсайту. `CITATION.cff` вказує версію 1.0.0, випущену 27 серпня 2026 року. Архів, завантажений для цього рев'ю, містить:

|---|---:|---|
| Двомовні терміни | 88 | `data/termes.jsonl` |
| Типізовані зв'язки між термінами | 260 | Поля зв'язків термінів; також представлені в `data/graphe.json` |
| Порівняння | 19 | `data/frontieres.jsonl` |

| Ролі | 15 | `data/metiers.jsonl` |

Кількості — це спостереження щодо завантаженого експорту, а не твердження, що в ньому представлено кожен компонент вебсайту чи що кожне визначення технічно правильне. Рев'ю охоплює його структуру та вибрані релевантні записи, а не вичерпний фактичний аудит усіх 88 термінів.

## Що додає цінності посібнику

Lexigraph розміщує терміни на чотирьох поверхах: модель, harness, агент, організація. Його записи поєднують коротке визначення, обговорення частих плутанин, технічне пояснення, датовані приклади, зв'язки та запитання. Сторінки порівнянь пов'язують цей словник із конкретними рішеннями.

Це доповнює [продуктовий глосарій](../../guide/core/glossary.uk.md) і [операційні шари](../../guide/core/agent-harness.uk.md#0-чотири-шари-чотири-відповідальності) посібника. Він їх не замінює: runtime harness, репозиторний harness і оркестратор відповідають на інші інженерні запитання, ніж навчальні поверхи Lexigraph.

Корисне доповнення — компактна точка входу для читачів, яким потрібно розрізнити поняття, перш ніж переходити до докладних довідників. Наявний посібник уже охоплює їхні реалізації. Копіювання повного глосарію дублювало б це охоплення й імпортувало б застереження, яких джерело не завжди робить.

## Висновки, що обмежують пряме повторне використання

### Експорт не відтворює весь вебсайт

Усі 19 французьких об'єктів порівняння мають порожні масиви `criteres`. Перевірена [сторінка Agent or Assistant](https://www.lexigraph.org/fr/vs/agent-assistant/) містить таблицю порівняння та чотири ситуації, яких немає в експортованих полях цього об'єкта. В архіві також немає ресурсів інфографіки чи експорту керованих маршрутів. [Колекція інфографіки](https://www.lexigraph.org/fr/infographies/) сайту — окремий шлях повторного використання; [planche про harness](https://www.lexigraph.org/fr/infographies/le-harnais/) пропонує SVG, PNG, PNG у форматі слайда та інтерактивне вбудовування.

### Позиції відповідей дають підказку

У французькому файлі запитань індекси відповідей трапляються 59 разів на позиції 0, 209 — на позиції 1 і 53 — на позиції 2. Отже, якщо завжди обирати другий варіант, виходить 209/321, або **65,1%**, без читання запитання. Це властивість експортованого порядку; порядок відображення на сайті не тестувався.

Перш ніж використовувати цей банк для оцінювання, перевірте відповіді, перемішайте варіанти зі збереженням відповідності правильній відповіді та проаналізуйте дистрактори. Ці словникові запитання не є бенчмарком для coding agents чи безпеки продакшену. Жодних запитань Lexigraph у цій зміні не імпортовано.

Щоб відтворити структурні висновки, клонуйте публічний репозиторій і запустіть із його кореня:

```python
import json
from collections import Counter
from pathlib import Path

def records(path):
    return [json.loads(line) for line in Path(path).read_text(encoding="utf-8").splitlines() if line.strip()]

questions = records("data/qcm/fr.jsonl")
counts = Counter(q["answer"] for q in questions)
print("Questions:", len(questions), "Correct-answer positions:", dict(sorted(counts.items())))
print("Always second:", f"{counts[1] / len(questions):.1%}")
comparisons = records("data/frontieres.jsonl")
print("Empty French criteria:", sum(not row["fr"]["criteres"] for row in comparisons))
```

### Корисні спрощення потребують меж

- [Запис Subagent](https://www.lexigraph.org/fr/sous-agent/) трактує початково порожній контекст і відсутність комунікації/спільного стану як загальні властивості. Успадкування контексту, доступ до транскрипту, зберігання та комунікація залежать від runtime і конфігурації. Не переносьте ці твердження як універсальні визначення.
- [Порівняння Context or Memory](https://www.lexigraph.org/en/vs/context-memory/) пропонує закрити й знову відкрити розмову, щоб розрізнити збереження. Збережена/відновлена історія може пережити цю операцію, не демонструючи окремого механізму довготривалої пам'яті. Натомість перевірте поведінку зберігання та завантаження.
- [Порівняння Model or Product](https://www.lexigraph.org/en/vs/model-product/) використовує заміну постачальника як діагностичну межу. Поведінка моделі й harness взаємодіє; сама лише заміна моделі не може встановити, кому належить збій. Зберігайте одиницю оцінювання посібника «модель–harness».
- [Порівняння Workflow or Agent](https://www.lexigraph.org/en/vs/workflow-agent/) допомагає виявити адаптивний вибір дій, але заздалегідь написаний воркфлоу може містити крок агента. Пауза для схвалення не прибирає агентності, а «assistant» — це також продуктова роль. Класифікуйте фактичне рішення, а не назву.
- Твердження, що harness детермінований, потребує уточнення на рівні компонентів: він може викликати ймовірнісну маршрутизацію, вибір чи рев'ю на основі моделі. Письмові правила також не набувають детермінованого застосування лише через те, що розміщені поза моделлю.

Ці спостереження виправдовують переписування пояснень замість дослівного копіювання тестів джерела. Твердження про продукт перевірено за документами Anthropic [How Claude Code works](https://code.claude.com/docs/en/how-claude-code-works) і [Permissions](https://code.claude.com/docs/en/permissions); ролі протоколу — за [архітектурою MCP](https://modelcontextprotocol.io/docs/learn/architecture). Докладні настанови з безпеки та оцінювання залишаються в наявних довідниках цього посібника.
