## Підсумок

Синтез 10 порад від команди Claude Code (Boris Cherny і колеги з Anthropic). Охоплює паралелізацію, перепланування, правила, що самовдосконалюються, skills як інституційні знання, воркфлоу виправлення багів, філософію промптингу, налаштування термінала, патерни субагентів, skills для баз даних і воркфлоу навчання.

## Оцінка: 4/5

**Рейтинг**: висока цінність — 3 нові патерни + доповнення до наявних розділів

### Обґрунтування

**Сильні сторони**:
- Первинне авторитетне джерело (справжня команда Claude Code в Anthropic)
- 3 справді нові патерни, не охоплені в посібнику:
  1. **Промптинг як провокація**: філософія промптингу через виклик із конкретними патернами
  2. **Модель як шлюз безпеки**: використання Opus як фільтра дозволів на основі hook
  3. **Shell-аліаси для worktrees**: практична оптимізація навігації
- Збагачує наявний кейс Boris Cherny ширшим контекстом команди
- Конкретні, практичні приклади (а не абстрактні поради)

**Слабкі сторони**:
- Значне перекриття з наявним вмістом (~50%):
  - Паралелізація через worktrees: уже детально охоплено
  - CLAUDE.md як пам'ять, що накопичується: уже задокументовано в кейсі Boris
  - Система skills: уже задокументовано (хоча приклади команди додають цінності)
  - Перепланування, коли застряг: Plan Mode уже охоплено
- Допис у блозі — це синтез, а не первинне джерело (оригінал — тред у Twitter)
- Деяким порадам бракує деталей реалізації (наприклад, шлюз безпеки на Opus концептуальний)
