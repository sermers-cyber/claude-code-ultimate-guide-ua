## Резюме для керівництва

Entire CLI це **агентно-нативна платформа**, що фіксує сесії ШІ-агентів (Claude Code, Gemini CLI) як версіоновані чекпоінти в Git-репозиторіях. Запущена 10-12 лютого 2026 з фінансуванням $60M колишнім CEO GitHub Thomas Dohmke, вона дає:

- **Чекпоінти з можливістю перемотування**, що зберігають prompt + міркування + використання інструментів + стани файлів
- **Шар управління** зі шлюзами схвалення, областями дозволів, журналами аудиту
- **Передачу між агентами** зі збереженням контексту (Claude → Gemini → власні агенти)
- **Сховище на основі Git** в окремій гілці (без забруднення історії main)

**Ключові відмінності:**
- Єдиний інструмент із відтворенням сесій (закриває задокументовану прогалину в third-party-tools.md)
- Функції управління, створені спеціально для відповідності вимогам (SOC2, HIPAA, FedRAMP)
- Замінює застарілий git-ai (репозиторій 404), задокументований у посібнику
