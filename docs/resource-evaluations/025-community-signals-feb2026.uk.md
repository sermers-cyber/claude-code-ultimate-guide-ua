## Підсумок змісту

- **977 GitHub issues** створено за 30 днів (616 багів / 242 FR / 205 дублікатів). Медіанний час до закриття ≈ 1 год — переважно автозакриття дублікатів, а не показник справжнього вирішення.
- **Топ-5 больових точок**, що збігаються на кількох каналах: збої 500 бекенду, незрілий Remote Control (обмеження Pro/Max + баги UX), непрозорі квоти, пошкодження `.claude.json` у мультиінстансних запусках, фрагментований онбординг/автентифікація на Windows.

- **Сильне прийняття** попри баги: чітка відповідність продукту ринку серед просунутих користувачів, дуже позитивні гілки на Reddit про продуктивність. Оцінений run-rate $2.5B ARR за сторонніми джерелами (⚠️ неперевірювано).
- **Слабкі сигнали**: безпека (CVE + preview «Claude Code Security»), роль «AI orchestrator» змінюється, coding from anywhere, моніторинг квот як стороння підекосистема, перетворення CLI на платформу.

## Рекомендації щодо інтеграції

### Інтегрувати — підтверджені реальні прогалини (високий пріоритет)

**1. Усунення помилок 500**
- Файл: `guide/ultimate-guide.md` (новий підрозділ «Troubleshooting» або `guide/troubleshooting.md`)
- Зміст: розрізнення серверної помилки та локальної конфігурації, посилання на `status.anthropic.com`, найкращі практики відновлення, fallback на Bedrock/Vertex із мінімальною конфігурацією
- **Позначити як volatile**: застаріє, якщо Anthropic покращить надійність бекенду

**2. Пошкодження `.claude.json` і мультиінстансність**
- Файл: `guide/ultimate-guide.md` (розділ Configuration) + посилання з `known-issues.md`
- Зміст: ризики паралельного запису, рекомендовані патерни (один worktree на інстанс, локальний gitignore для `.claude.json`, регулярний бекап), зв'язок із `examples/scripts/sync-claude-config.sh`

**3. Remote Control — документація + обмеження**
- Файл: `guide/ultimate-guide.md` (розділ Remote/Mobile або новий розділ)
- Зміст: таблиця підтримуваних планів, відомі обмеження UX (переривання, розриви з'єднання), обхідний шлях Tailscale + Tmux для просунутих користувачів
- **Позначити як beta**: функція активно розвивалася на момент звіту

### Інтегрувати — корисні доповнення (середній пріоритет)

**4. Прозорість квот + ccusage**
- Розширити розділ про ціни/ліміти таблицею Opus vs Sonnet vs Haiku за планами, вплив auto-memory / plan mode / subagents
- Згадати `ccusage` (інструмент моніторингу від спільноти) — уже відзначений офіційним @claude_code

**5. Відсутні CVE 2025 у threat-db**

- CVE-2026-21852 → підозрілий формат (⚠️ див. фактчекінг), не інтегрувати без підтвердження NVD
- Preview «Claude Code Security» → вторинне неофіційне джерело LinkedIn, чекати на анонс Anthropic
- Run-rate $2.5B ARR → неперевірювана стороння оцінка, поза межами технічного посібника
- «Офіційний playbook спільноти» → роль Anthropic, а не стороннього посібника
- Динамічні «Known issues this month» → супровід неможливий на нашому рівні

## Виклик (агент technical-writer)

**Скоригована оцінка**: 4/5 збережено

**Піднятi критичні пункти:**

- **Структурна упередженість вибірки**: 977 issues надмірно представляють вимовних просунутих користувачів. Тихий відтік користувачів, що покинули інструмент, ніколи не з'являється в GitHub Issues. Не слід вважати ці сигнали репрезентативними для всієї бази.
- 4 з 6 рекомендацій є **оборонними**: quick wins (перевірені обхідні шляхи для квот, патерни проти пошкодження `.claude.json`) мають більшу негайну цінність, ніж runbook.
- Runbook для помилок 500 має **низький маргінальний вплив**: досвідчені користувачі вміють користуватися `status.anthropic.com`. Пріоритет — `.claude.json` і Remote Control.
- «Незрілий» Remote Control — судження без точки відліку: задокументувати дату GA функції, щоб контекстуалізувати обмеження.
- Рекомендація «офіційні патерни GitHub/Discord/Slack» → змішує роль посібника з анімацією спільноти Anthropic.

**Реальні ризики неінтеграції:**
- Ерозія довіри до посібника, якщо в ньому немає найуживаніших обхідних шляхів від спільноти
- Користувачі втрачають роботу через пошкодження `.claude.json` без документації щодо відновлення
