## 📄 Зміст

### Згадані технології

- **Remotion**: React-фреймворк для програмного створення відео (JSX → кадри → FFmpeg → MP4)
- **Agent Skills**: Remotion опублікував офіційні skills, доступні через `npx skills add remotion-dev/skills`
- **MCP Server**: Remotion пропонує MCP-сервер для прямого доступу LLM до документації
- **Документація**: документація Remotion має функцію «Copy as Markdown»

### Теза статті

> «Бар'єр знизився від "вивчити After Effects" до "описати, що хочеш"»

Автор подає Remotion + Claude Code як «зміну парадигми» для виробництва відео.

1. **Масштабованість**: Remotion — один фреймворк серед сотень. Додавання кожного skill із маркетплейсу створило б нескінченний список, який неможливо підтримувати.

5. **Самостійна знаходжуваність**: розробник, якого цікавить Remotion, знайде skills через маркетплейс skills.sh.

## 🔥 Перевірка (агент technical-writer)

### Оцінку підтверджено: 2/5 ✅ (або навіть 1/5)

Агент technical-writer підтвердив оцінку 2/5 і навіть запропонував 1/5 з таких причин:

#### Аргументи опонента

1. **Оцінка правильна або навіть щедра**: коментарі на Reddit дискредитують статтю. Якщо продемонстровані приклади зроблено в After Effects, стаття **фактично оманлива**.

2. **«Зміна парадигми» = маркетингова вода**: «описати, що хочеш» замість вивчення After Effects? Це рекламна обіцянка КОЖНОГО no-code інструмента з 2015 року. Нічого нового.

3. **Небезпечний прецедент**: документування ОДНОГО фреймворку відкриває двері для всіх інших. Чому Remotion, а не детально Supabase? Three.js? Next.js? Цей слизький шлях зруйнував би підтримуваність посібника.

4. **MCP Remotion = хибний напрям**: розділ про MCP у посібнику документує загальні сервери з високою доданою цінністю (Serena, grepai, Context7). MCP Remotion розв'язує **НІШЕВУ** проблему.

5. **Ризик відмови від інтеграції = НУЛЬ**: посібник документує, **як користуватися skills.sh**. Розробник на Remotion сам знайде skill через маркетплейс.

#### Критика початкової оцінки

> «Твоя справжня помилка: ти витратив час на розгляд інтеграції, хоча червоні прапорці з Reddit мали одразу дискваліфікувати джерело. Стаття на Medium, що демонструє, можливо, сфабриковані приклади = ненадійне джерело = автоматичне відхилення.»

#### Рекомендація опонента

**Не інтегрувати.** Переоцінити через **6 місяців**, якщо:
- Remotion досягне **5K+ встановлень** на маркетплейсі skills.sh
