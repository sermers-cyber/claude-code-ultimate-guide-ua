# Оцінка ресурсу: Context Hub (andrewyng/context-hub)

**Дата**: 2026-03-16
**Джерело**: допис у LinkedIn (текст) + https://github.com/andrewyng/context-hub
**Тип**: CLI-інструмент із відкритим кодом
**Автор**: Andrew Ng (andrewyng)
**Оцінка**: 2/5

---

## Підсумок змісту

- **Що це**: CLI-інструмент (`chub`), який дає агентам для написання коду кураторську версіоновану документацію API у вигляді markdown-файлів
- **Основні команди**: `chub get openai/chat --lang py` для отримання документації API; `chub annotate <id> "note"` для постійних анотацій, що зберігаються між сесіями
- **Корпус**: 602+ записи документації (станом на 2026-03-16), що охоплюють OpenAI, Anthropic, Stripe, AWS та інших
- **Цикл зворотного зв'язку спільноти**: користувачі голосують за якість документації (`chub feedback`), і покращення потрапляють до мейнтейнерів
- **Інтеграція з Claude Code**: підтримка SKILL.md, щоб покласти його в `~/.claude/skills/`
- **Ліцензія**: MIT, 6 342 зірки (станом на 2026-07-28 вже 13 861)

---

## Оцінка: 2/5

**Обґрунтування**: одна справді нова можливість (постійні анотації до зовнішньої документації API між сесіями), яку Context7 не може відтворити. Усе інше перетинається з наявним покриттям у посібнику: Context7 уже працює з версіонованою документацією бібліотек, `@url` нативно підтягує актуальну документацію в контекст Claude Code, а патерни проти галюцинацій уже задокументовано. Сценарій з анотаціями реальний, але розв'язує вузьку проблему. Немає бенчмарків із продакшену, немає незалежної перевірки.

## Нотатки перевірки (агент technical-writer)

**Основні заперечення:**

1. **Зірки ≠ впровадження**: 6 342 зірки забезпечило соціальне посилення від Andrew Ng, а не перевірка в продакшені
2. **Перетин із Context7 не доведено**: `chub get openai/chat --lang py` проти `query-docs` у Context7 — оцінка не доводить конкретної прогалини
3. **Анотації — єдиний новий аспект**: і його поховано серед іншого, хоча це єдина можливість, яку Context7 не може відтворити
4. **Подача як захисту від галюцинацій — натяжка**: документація, яку підтримує спільнота, створює проблему довіри, якої Context7 уникає (офіційні джерела)
5. **Пропущено нативну альтернативу `@url`**: Claude Code уже нативно підтягує актуальну документацію, що послаблює аргумент про «прогалину»
6. **Пропущено ризик підтримки**: відставання оновлень при зміні API на противагу живому пошуку в Context7
7. **Ризик неінтеграції**: низький: наявне покриття в посібнику (Context7, `@url`, grepai) закриває більшість сценаріїв
