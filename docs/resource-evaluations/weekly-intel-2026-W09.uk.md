## 📄 Підсумок змісту

- **Claude Code v2.1.63** (27 лютого): нові вбудовані slash-команди `/simplify` + `/batch`, HTTP hooks (POST JSON → URL), спільна конфігурація/автопам'ять для worktrees одного репозиторію, нова змінна середовища `ENABLE_CLAUDEAI_MCP_SERVERS=false`, низка виправлень критичних витоків пам'яті
- **Термінове виведення моделей з ужитку**: `claude-3-haiku-20240307` позначено застарілою 19 лютого, вилучення з API **20 квітня 2026** (за 7 тижнів), рекомендована заміна: `claude-haiku-4-5-20251001`
- **Придбання Vercept** (24 лютого): стартап у сфері комп'ютерного зору та автоматизації GUI, команда приєднується до Anthropic для посилення computer use — контекстна новина, негайних змін API немає
- **Оновлення щодо виведення Opus 3**: Opus 3 лишається доступним через окремий канал + Substack «Claude's Corner» — для посібника це анекдотично
- **Anthropic проти Department of War**: червоні лінії (жодного масового стеження, жодної автономної зброї) — поза технічними межами
- **Cowork: plugins + заплановані завдання** (24-25 лютого): marketplace plugins, адміністративні засоби контролю, заплановані завдання — аудиторія не розробники, поза межами
