# Дистриб'юційні матеріали

Ці матеріали перетворюють одну частину Claude Code Ultimate Guide на обмежений навчальний формат. Публікація залишається окремою від виробництва: готовий файл усе одно потребує схвалення, місця призначення та датованого запису про канал.

| Матеріал | Стан | Сторінки-джерела | Запис про публікацію |
| --- | --- | --- | --- |
| [Слайди навчального шляху](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/docs/distribution/claude-code-learning-path-slides.pptx) | Готово, візуально перевірено, тест на переповнення пройдено | [Навчальний шлях](../../guide/learning-path/README.uk.md), [Best-of-N](../../guide/workflows/best-of-n.uk.md), [Computer Use](../../guide/core/computer-use.uk.md) | [`slides-en`](../../machine-readable/distribution-channels.yaml) |
| [Серія відео з швидкими перемогами](quick-win-video-series.uk.md) | Виробничі брифи готові, відео не записано | [Індекс робочих процесів](../../guide/workflows/README.uk.md), [skill learning-path](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/examples/skills/learning-path/SKILL.md) | [`youtube-fr`](../../machine-readable/distribution-channels.yaml) |

У нотатках доповідача кожного слайда є блок `[Sources]`. Відеобрифи називають для кожного епізоду сторінку посібника, спостережувану перевірку, атрибутоване місце призначення та дослідницьке джерело.

Для живого воркшопу чи запису [супровідний проєкт Proofpack](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/examples/learning-project/README.md) надає наскрізну вправу, що лежить в основі навчального шляху.

## Перед публікацією

1. Перезберіть або знову відкрийте матеріал і перевірте фінальний результат.
2. Переконайтеся, що посилання на посібник і далі працюють у поточній версії.
3. Отримайте схвалення для названого каналу.
4. Змініть статус каналу в [`distribution-channels.yaml`](../../machine-readable/distribution-channels.yaml).
5. Запишіть URL доказу розміщення та дату перевірки.
6. Запустіть 30-денне вікно вимірювань, визначене [робочим процесом дистрибуції](../workflows/guide-distribution.uk.md).

Китайська публікація залишається заблокованою, доки вільно володіючий мовою рецензент не підтвердить локалізований текст. [Реєстр перекладів](https://github.com/FlorianBruniaux/claude-code-ultimate-guide/blob/main/machine-readable/translations.json) фіксує власність і актуальність; він не надає права на публікацію.
